## 4. 本轮最高优先级问题

### S1-6-01｜严重｜病态多方向拟合被标记为有效

- **位置**：`04_PSF估计\esf_lsf_estimation.py:453-533,611-638`。
- **证据**：`joint_fit_motion_params()` 只要求边缘数不少于 3；第 517～520 行仅计算条件数，第 522～529 行无论条件数和残差如何都返回 `valid=True`。构造 3 条相同法线边缘、FWHM 为 3/4/5 的输入，得到 `condition=∞, L=2, w0=2, valid=True`。理想阶跃 `L=10,30°` 同样得到 `condition=∞` 却 `status=ok`。
- **影响**：单方向或秩亏数据不可能联合辨识长度、方向和基线宽度，但程序会输出看似精确的 PSF 参数并允许进入反卷积，错误核会制造振铃和重影。
- **建议**：对方向覆盖、矩阵秩、条件数、残差、参数边界和 bootstrap 方差设置预注册门禁；例如 `rank<2`、`condition>阈值`、方向覆盖不足或置信区间过宽时返回 `valid=False/insufficient_direction_diversity`。不得用“边缘数量≥3”替代独立方向数量。

### S1-6-02｜严重｜已知角度接口未实现，单方向仍强制给“长度”

- **位置**：`04_PSF估计\esf_lsf_estimation.py:536-545,579-602,611-638`。
- **证据**：`motion_angle_known` 只出现在签名和文档中，函数体未引用。本轮对同一 `L=10,30°` 阶跃分别传 `None` 与 `30`，全部输出完全相同：`L=2.207, angle=3°, condition=∞`。边缘不足 3 条时，第 586～589 行把单一方向 FWHM 直接写入 `estimated_length` 并标记 `valid=True`。
- **影响**：单边缘只给出 PSF 的法向投影宽度；未知运动方向时不能恢复真实二维线段长度。接口会让调用者误以为已利用真值方向或完成了长度反演。
- **建议**：已知角度模式应固定 θ，只拟合 `L,w0`；未知角度且方向不足时只返回 `projection_width`，不返回 `estimated_length`。为两种模式建立不同结果 schema 和断言。

### S1-6-03｜严重｜ESF/LSF 在理想阶跃和自然图像上均未通过

- **位置**：`04_PSF估计\esf_lsf_estimation.py:641-716,719-753`；算法主体 `345-638`。
- **数值证据**：理想竖直阶跃 L=10/30° 输出 L=2.207、angle=3°、condition=∞、`ok`；L=20/0°输出 L=7.151、condition=∞、`ok`；L=25/0°输出单方向 L=1.508、`valid=True`。自然图分场景长度 MAE：building 9.73 px、forest 8.78 px、professors 8.53 px；角度 MAE 分别为 46.5°、65.3°、41.8°。12 个自然条件总体长度 MAE 9.01 px、角度 MAE 51.2°，却全部标记 `ok`。
- **影响**：当前文件不能作为有效 PSF 估计器，更不能作为创新性实验结果。其错误不是小样本统计波动，而是解析层门禁失败。
- **建议**：先停止接入复原。以连续斜边、已知静态 PSF/像素孔径和线段面积积分核建立参数化测试，按运动长度、运动角、边缘法线正交扫描；无噪声已知角度长度 MAE 达到 <0.5～1 px、未知角度误差达到预注册门限且病态样本正确拒识后，再进入自然图像。

### S1-6-04｜严重｜边缘几何、质量权重与拟合实现不可信

- **位置**：`04_PSF估计\esf_lsf_estimation.py:367-448,475-505`。
- **证据**：第 379 行 `np.where` 给出行优先像素顺序，不是沿轮廓的路径；第 389～393 行却用相邻数组元素累计“路径长度”和首尾点估计直线性。第 413～415 行循环计算每条剖面的 contrast，但第 441 行只保存最后一条通过剖面的 contrast。第 478～479 行计算权重，第 493 行构造 `W`，第 495 行却直接对未加权的 `A,fwhms` 调用 `np.linalg.lstsq`，`W` 完全未使用。
- **影响**：边缘质量分数不能代表真实几何和剖面质量，所谓加权拟合实际未加权；纹理、交叉和伪边缘主导参数估计。
- **建议**：用有序轮廓或 RANSAC/总最小二乘拟合直线；逐剖面记录平台斜率、对比度、单调性、邻近边缘距离、拟合残差和宽度方差；段级用中位数/稳健 M 估计汇总；实际使用 `sqrt(W)A` 与 `sqrt(W)y` 或稳健非线性最小二乘。

### S1-6-05｜严重/回归｜留一验证会覆盖结果后崩溃，schema 已漂移

- **位置**：`04_PSF估计\psf_estimation_template.py:526-569`；产物 `results\04_PSF估计\leave_one_image_out_results.csv`。
- **证据**：新记录字段为 `matched_psf_gain`、`kernel_mismatch_loss_db`（第 541～544 行），汇总仍读取 `oracle_gain`、`estimation_loss_db`（第 567～568 行），必然触发 `KeyError`。CSV 在第 558～563 行已经固定覆盖后才进入错误代码。现有 CSV 仍含 `estimated_angle/angle_error/oracle_*` 旧列；代码第 395 行应写 `same_image_leaky_demo_results.csv`，磁盘上却只有旧 `psf_estimation_results.csv`。
- **影响**：失败运行会破坏上一次结果后退出；现有数字不能证明由当前代码成功生成。论文表格与源码失去数据谱系。
- **建议**：定义单一 schema 常量；先写同目录临时文件，回读验证列、行数、有限值和 SHA-256，再原子替换；汇总使用内存中的未四舍五入值；异常时不发布；旧 CSV 明确归档为历史诊断产物。

### S1-6-06｜严重｜“完整盲复原”仍接入被证伪的全局梯度基线

## 8. 物理模型、实验设计与创新性

1. 理想阶跃沿法线的 LSF 是二维 PSF 沿切线积分的一维投影。单一方向只约束一个投影；对参数化直线核也需要方向分散的多个独立投影。
2. 静态光学 PSF、像素孔径、去马赛克、缩放、潜在边缘宽度和运动 PSF在成像链中卷积，其 FWHM一般不满足 `w=w0+L|cosΔ|`。应拟合完整 ESF/LSF卷积模型或验证所用近似。
3. 自然边缘的纹理、曲率、遮挡、饱和、双边、交叉和非线性响应都会改变 ESF；边缘质量评分、拒识和不确定度是方法成立的必要部分。
4. 当前只适用于空间不变、均匀线性运动。真实相机抖动常为二维轨迹并空间变化，论文必须限定模型。

最低验证应分三层：解析/数值层（连续斜边、已知静态PSF、参数扫描与断言）；合成自然图层（按基础场景严格划分，包含未见参数、噪声、压缩和模型失配）；真实/标定层（斜边靶、运动平台或公开基准，记录完整相机链路和许可）。指标应包含长度/角度/核误差、拒识率、置信区间覆盖、统一裁边的PSNR/SSIM、振铃和运行时间；统计单位是基础场景而非同图多个退化版本。

窄范围文献核验表明，“由锐边/边缘轮廓估计 PSF”“由多方向边缘约束二维 PSF”“直接由模糊 edge profiles 估计相机运动”均已有明确先例：

- Joshi、Szeliski、Kriegman（CVPR 2008）：[PSF Estimation using Sharp Edge Prediction](https://vision.ucsd.edu/publications/2008/psf-estimation-using-sharp-edge-prediction)。
- Vasu、Rajagopalan（CVPR 2017）：[From Local to Global: Edge Profiles to Camera Motion in Blurred Images](https://openaccess.thecvf.com/content_cvpr_2017/html/Vasu_From_Local_to_CVPR_2017_paper.html)。
- 斜边 SFR/ESF/LSF 属于成熟成像测量背景：[ISO 12233:2024](https://www.iso.org/cms/live/live/en/sites/isoorg/contents/data/standard/08/86/88626.html?browse=tc)。

因此，“ESF/LSF + 多方向投影”本身不足以构成新颖贡献。潜在贡献必须明确超过已有工作，例如可验证的自然边缘评分、方向覆盖可辨识条件、带拒识的置信区间、静态PSF/像素孔径与运动联合建模、核不确定度向复原误差传播，或在明确真实场景上对强基线的稳定优势。当前代码尚未实现或证明这些差异。

- 当前直接投稿：不建议，SCI四区也有较高拒稿风险。
- 仅让代码运行或继续调全局梯度查表：不足以改变投稿判断。
- 完成解析门禁、正确拒识、多方向联合估计、独立场景测试、真实数据、基线/消融和完整复现后，才适合重新评估四区/三区目标。
