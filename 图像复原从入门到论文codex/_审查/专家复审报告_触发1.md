## 三、最高优先级问题

### S1-A：实验不是盲复原，存在同场景清晰真值泄漏

**证据**

- `05_完整盲复原流程\blind_restoration_template.py:417-427`：先由清晰图生成长度 10、角度 25° 的模糊图；随后在第 423–424 行明确“用这张图自己”建立查找表，再称为“盲复原”。
- `04_PSF估计\psf_estimation_template.py:290-314`：对每张清晰图先建立该图自己的查找表，再用同一清晰图生成测试模糊图。
- `06_实验与论文写作\论文大纲.md:7, 21-25, 93-101` 与 `项目总结.md:34-49` 将上述循环验证写成“0 误差”“已验证创新”“盲复原与非盲复原持平”。

**影响**

查找表已经编码了待测场景的清晰梯度分布；这正是盲场景中不可获得的信息。它不能证明方法能从未知模糊图识别 PSF，也不能与真正盲反卷积公平比较。论文审稿时这会被视为验证协议根本错误。

**建议**

1. 若保留同场景清晰参考，必须把任务改名为“参考式/标定式固定角度均匀运动模糊长度估计”，停止使用“盲复原”。
2. 若坚持盲复原，训练/标定与测试必须按场景隔离；最低要求是 leave-one-image-out，更规范的是按公开数据集图像与相机/场景划分训练、验证、测试。
3. 测试阶段不得访问对应清晰图、真实核或由其生成的图像特定查找表；清晰图只能用于最终指标计算。

**证据**

**证据**

### S1-E：边缘方向理论写反，且当前特征不是 ESF/LSF

**证据**

- `04_PSF估计\01_知识点.md:53-76` 写成“沿运动方向的边缘最宽，最宽边缘方向就是运动方向”。若“边缘方向”指边缘切线，结论相反：过渡宽度由运动向量在**边缘法线**上的投影决定；切线与运动平行时法向投影接近零，切线与运动垂直时过渡最宽。
- `06_实验与论文写作\论文大纲.md:50-63` 的实现仍是全图梯度阈值、距离变换平均宽度及全局选中像素的平均梯度，不是逐边缘法线的 ESF 10%–90% 宽度，也没有 LSF 拟合。
- `04_PSF估计\01_知识点.md:80-90, 108-125` 的 `L≈W-W0`、`R≈(W-W0)/2`、`L∝1/G` 只在非常受限的理想边缘、定义和成像条件下才可能近似成立，不能作为一般识别公式。

**影响**

按当前文档实现角度估计会产生约 90° 的语义混乱；全局梯度统计被纹理、对比度、边缘数量、噪声与 JPEG 强烈影响，缺乏 PSF 可辨识性。

**建议（论文方法的正确主线）**

1. 检测近似直、孤立、无遮挡、无饱和的边缘段，估计其切线与法线方向。
2. 沿法线对齐采样并做亚像素 binning，得到单调 ESF；对 ESF 求导得到 LSF，使用稳健拟合与质量评分。
3. 理想阶跃边缘经二维 PSF 模糊后，其 LSF 对应 PSF 沿边缘切线方向积分得到的一维投影，即 PSF 的 Radon 投影。单一方向只能给出一维投影，不能唯一识别任意二维核。
4. 聚合多个法线方向的高质量边缘，联合估计参数化运动核的长度与角度；若要估计一般二维 PSF，需要足够多方向投影、非负/和为 1/紧支撑等约束及正则化。
5. 明确自然图像边缘不是理想阶跃造成的模型偏差，并通过合成斜边、真实标定靶和自然图像三层实验验证。

## 六、选题与创新性建议

### 6.1 可投稿的研究问题应如何收缩

不建议继续以“全图过渡区平均梯度 → 一维查表 → 固定角度 PSF”作为论文核心创新。该统计量不能把图像内容与模糊核分离，且一张自然图像的单一全局标量不可能稳定识别二维 PSF。

较合理的两条路线：

- **路线 A（较稳妥）**：题目改为“基于多方向边缘 ESF/LSF 投影约束的参数化运动模糊核估计与图像复原”。限定空间不变、均匀线性运动核，估计长度与角度；贡献放在边缘质量筛选、亚像素 ESF 对齐、多方向稳健融合与不确定度评价。
- **路线 B（工程型）**：明确是有清晰参考或标定靶的模糊参数测量，题目改成“基于边缘扩散函数的成像系统运动模糊标定”。这不再声称盲复原，但更容易做到严谨可复现。

### 6.2 建议的创新点表达

只有完成独立测试后，才能考虑如下贡献表述：

1. 提出带质量评分的自然边缘 ESF/LSF 提取方法，抑制纹理、曲率、饱和和多边缘干扰。
2. 建立边缘法线方向与 PSF Radon 投影之间的显式模型，以多方向一致性联合估计运动长度和角度。
3. 输出 PSF 参数置信区间或失败判据，并研究估计不确定度对复原质量的传播。
4. 在公开合成基准、真实运动模糊数据和斜边标定数据上，与经典与近期方法公平比较。

“简单可解释”可以作为优势，但不能替代可辨识性证明、独立实验和基线对比。

## 七、建议的实验协议

1. **数据划分**：至少使用公开清晰图数据构造合成集，并按原图划分 train/validation/test；测试原图绝不参与标定。增加公开真实模糊集或自行采集并提供配对/近似真值协议。
2. **核覆盖**：长度、角度、曝光轨迹、散焦半径、噪声、边界、相机响应、压缩分别分层采样；同时包含模型失配核。
3. **评价**：核参数误差、核相似度、PSNR、SSIM，以及边缘重建误差；统一裁边、颜色空间、data range 和图像保存格式。
4. **基线**：至少包含已知核非盲上界、无复原输入、经典盲反卷积、一个现代优化或学习基线，以及当前全局梯度查表作为消融基线。
5. **消融**：边缘筛选、法线对齐、ESF 平滑、LSF 拟合、多方向融合、正则化和失败判据逐项移除。
6. **统计**：逐图保存原始结果；报告均值/中位数/标准差/95% 置信区间、失败比例与显著性；不得只展示成功图。
7. **可复现**：锁定环境、配置和 seed；每次运行使用唯一目录，写 `config.yaml`、`metrics.csv`、日志、代码版本与输入文件哈希；合成及中间图使用 PNG/TIFF。

## 八、按优先级的可执行整改清单

### P0：在继续写论文前

1. 撤回并修正所有“盲复原已完成”“0 误差”“严格单调”“已验证创新”表述。
2. 修复 PSF 长度定义与实现，建立 PSF 单元测试；全量重新生成数据和结果。
3. 用 leave-one-image-out 重写验证流程，禁止同图清晰真值建表；增加“低于模糊输入即失败”的门禁。
4. 将特征改为逐边缘法线 ESF/LSF，不再把全图梯度掩码距离均值称为过渡区宽度。
5. 先实现固定线性运动核的长度+角度联合估计，并给出多方向可辨识性说明。

### P1：形成可信实验

1. 扩展到公开数据集和数百张独立测试图；补真实数据。
2. 建立不可覆盖的运行目录及数值结果文件；禁止以 JPEG 参与指标计算。
3. 增加基线、消融、噪声/压缩/模型失配鲁棒性与统计检验。
4. 修复非单调插值、截断、路径、I/O 强校验、输入范围和环境锁定。

### P2：投稿准备

1. 完成系统文献综述，重点覆盖 edge spread function、line spread function、slanted-edge MTF、PSF/Radon 投影、自然边缘盲去卷积与核不确定度。
2. 建立数据来源/许可清单、项目 LICENSE、复现实验入口和最小验证测试。
3. 论文摘要和贡献只使用独立测试实际支持的结论，明确适用条件与失败模式。

## 九、最终判断

本项目目前适合作为教学原型和研究假设探索，但还不是完成的论文方法。最大风险依次是：任务并非真正盲复原、PSF 不可辨识、实验泄漏、核心单调假设不成立、PSF 真值生成器不一致、结果不可追溯。优先解决这些问题，比继续增加复原滤波器或美化结果图更重要。

如果采用多方向边缘法线 ESF/LSF 与 PSF 投影模型，并以严格独立数据验证长度和角度联合估计，选题仍有机会发展成一篇范围清晰、可解释、实验可信的论文；若继续依赖同图清晰参考的全局梯度查表，则应诚实改名为参考式模糊标定，而不应以盲图像复原投稿。
