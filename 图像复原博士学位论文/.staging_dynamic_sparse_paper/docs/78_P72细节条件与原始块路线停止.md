# P72 参考细节可用性：停止原始像素块转移路线

2026-09-10，audit_p72_detail.py完成P72_detail_v0。固定P69对应3069个，未重检索，12训练图，8bit中心256。对输入和GT块逐通道去均值后取内部梯度，以输入-GT梯度平方误差除GT梯度能量，GT只作离线标签。

整体参考误差低于查询的比例48.55%，查询/参考误差中位数1.04158/1.04716，GT结构余弦中位数.05173。即使按GT结构相似度选最高四分位（仅诊断，不可推理使用），参考较好比例52.41%，GT结构余弦中位数.32774；不能显示稳定清晰细节供给。

该指标混合模糊、噪声、曝光和配准影响，不是标定模糊程度。结果不否定学习特征空间中的非局部方法，但不足支持当前“原始16块Top1参考直接提供更清晰高频”的假设。

## 决定

停止P69–P72原始块相关性/间隔门控路线，不继续追加标签、阈值、随机种子或训练该模块。负结果保留，不包装成创新。公开主干与P66可用基线不受此决定影响，数据集不更换。

## 下一步

将P68–P72汇成可复用的研究设计约束：需要学习特征对应、允许拒绝参考、不能默认参考更清晰；先例已有最大相似度软门控，因此不能只在公式上加一个系数。下一项仅核对参考论文的非局部表示模块和现有公开实现可复现性，形成“原方法复现/明确改进假设/资源预算”对照表，选定具体、有先例对照的机制后再实施。不得无依据自动跳到生成式模型、视频、双像素或另一个数据集；若无法提出可辩护的实质差异，向用户报告研究路线决策需求，而非无限进行小诊断。
