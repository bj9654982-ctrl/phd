# P32：匹配活动与固定场景诊断

日期：2026-09-07。诊断完成；未更新权重，未访问官方测试集。原始记录见 results/runs/P32_mechanism_v0。

## 问题与边界

P31的D分支整体均值最高，但GOPR0378_13组D−C为−0.068236 dB，未通过预先固定的分组门槛。本轮检查模块是否实际工作，不修改该门槛，不追加训练。

使用P31各分支最终权重。训练侧取固定4张128×128中心裁块，做一次前向和反向，没有优化器更新；开发侧重放GOPR0378_13_00/000096的256×256中心裁块。B/C/D的PSNR与SSIM均和P31逐图记录相差小于1e−5。此图不是P28最差图000102，也不是独立测试样本。

## 实际算子定义的澄清

当前D是“正向Top6候选、反向Top1返回检查”：位置i先在24个固定偏移候选中选6个j，只有j的首选目标是i才保留该边。并不要求j也是i的首选，因此不是严格的双方Top1配对。历史“硬Top1互惠”简称应按此解释；P29严格Top1玩具测试不能代替实际算子的这一行为测试。没有更改P31实现或权重。

被拒绝的注意力权重置零，剩余权重不重新归一化。因此保留的权重总量越小，聚合修正通常越弱；它不是匹配正确率。

## 结论与下一步

事实：D在这些样本上过滤后权重很少，修正较小，但梯度不是零；P31失败结论保持不变。假设：硬返回条件与不归一化共同造成过强抑制，可能限制模块作用。尚不能证明这是分组退化的原因。

下一步先补一个实际算子的确定性语义测试，覆盖“正向非首选但反向首选仍接受”、拒绝后不归一化、无匹配保留原特征。然后冻结一个单变量对照方案，以相同初始化的冻结主干隔离模块学习，比较C/D，而不是立即改阈值、多seed或延长所有分支训练。新训练前需写清步数、耗时上限和判断标准；本轮没有启动该训练。正式论文核心方法尚未验证成功。
