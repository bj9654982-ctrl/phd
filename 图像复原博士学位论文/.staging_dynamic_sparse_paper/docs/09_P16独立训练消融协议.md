# P16：外层残差门与强度监督的独立训练消融

状态：2026-09-05 运行前协议，尚未启动训练。

P15 两种子相对局部平均提高 0.08005 dB，但它同时改变了两个因素。此阶段回答：
收益来自外层乘门、来自监督改变共享特征，还是两者的配合？这些结论决定论文能
如何解释方法，而不能由门值与输入 PSNR 的相关性直接推出。

四组都使用固定三尺度支持域、相同 Top-K、相同融合门预测头。C10 与 C11 的
残差形式为 `F + g * residual`，C00/C01 为 `F + residual`。监督均使用融合门
`g` 的空间均值，教师只在训练阶段由配对输入 PSNR 计算。

两项待运行实验从同一 B0 重新开始，种子 3407，3000 步，batch 6，256 裁剪，
原图像均匀采样、AdamW 学习率 0.0002、频域权重 0.1，仍按每 375 步总体开发
PSNR 选择检查点。沿用原始训练顺序、增强及 1718/385 录像组划分。按最近速度，
两项约 16–18 分钟。

预先指定报告内容：

- 外层门在无监督时的效应 C10-C00、在有监督时的效应 C11-C01。
- 监督在无外层门时的效应 C01-C00、在有外层门时的效应 C11-C10。
- 两个主效应及交互效应 C11-C10-C01+C00；同时报告录像组与强度层次。
- 各变体相对同种子局部对照的总体、SSIM、分组指标和训练预算。

若某因素独立贡献接近零或为负，应据实收缩贡献表述；只有组合有益时只能主张
组合效果，不能写成两个因素各自都有效。C11 相对局部仍沿用 P15 的开发筛选线，
不因消融结果调整阈值。逐帧 bootstrap 仅作描述，相邻帧不作为独立显著性样本。

机制结论清楚后安排第三种子与完整分辨率检查，再按 TMT 边界文档进行跨退化
评价。P16 本身不使用 GoPro 官方测试或 TMT 测试场景调参。
