# 实验路线与闸门

## 总目标

完成一篇与参考论文相近层次的中文图像复原论文，形成以下可交付成果：

1. 一个清晰且与近邻工作可区分的模块；
2. 可复现的训练、测试和复杂度统计代码；
3. 标准数据集上的公平对比；
4. 完整消融、可视化、失败案例和效率分析；
5. 中文论文初稿、图表和投稿材料。

## P0：环境与查新

任务：

- 验证 `torch-gpu` 环境和 RTX 3060；
- 阅读参考论文的模块、实验表和作者自述局限；
- 检索动态稀疏注意力、非局部采样和运动引导去模糊近邻工作；
- 冻结研究问题、符号、输入输出和最小贡献。

通过条件：

- CUDA 冒烟测试通过；
- 查新矩阵至少覆盖 10 篇直接相关论文；
- 能用一张表说明“已有方法做了什么、本文多做了什么、用什么实验证明”。

## P1：基线闭环

任务：

- 建立 GoPro 数据加载、裁剪、增强、PSNR/SSIM 与推理脚本；
- 先让小模型过拟合 1 个 batch，再训练小样本；
- 复现一个公开基线或官方权重结果。

通过条件：

- 单 batch 过拟合无 NaN，PSNR 持续上升；
- 固定 8 张验证图重复测试结果完全一致；
- 正式基线与官方协议差距不超过约 0.2 dB，或找到有证据的协议差异。

## P2：最小模块实验

候选比较：

1. 局部卷积基线；
2. 固定窗口非局部表示；
3. 通用 Top-K 稀疏注意力；
4. 只用运动方向条件；
5. 运动方向 + 长度；
6. 运动条件 + 动态有效采样预算（完整候选模块）。

通过条件：

- 在相近参数量和训练预算下，完整模块对固定采样基线稳定提升；
- 提升不能只来自更多参数或更长训练；
- 至少 3 个随机种子的平均提升达到 0.15 dB，且没有明显速度失控。

若未通过，先分析采样位置、门控分布和梯度，不直接扩大网络。

## P3：完整实验

计划数据：

- GoPro：训练与标准测试；
- HIDE：跨数据集泛化；
- RealBlur-J/R：真实模糊验证；
- 可选小规模合成方向模糊集：只用于验证采样是否沿运动方向工作。

计划指标：PSNR、SSIM、LPIPS、参数量、MACs/FLOPs、RTX 3060 推理时间和峰值显存。

通过条件：

- 至少两个测试域上有一致收益；
- 主张“更高效”时必须报告实测延迟和显存；
- 提供失败案例，不隐去重度饱和、超大位移和真实噪声问题。

## P4：论文证据闭环

- 方法图中的每条分支必须在消融表中出现；
- 摘要中的每个定量结论必须能定位到表格；
- 结论不能超过实验覆盖范围；
- 比较方法更新到投稿前一年；
- 图表、代码配置、随机种子和模型权重一一对应。

## P5：投稿准备

- 按目标期刊体例排版；
- 完成保密审查和版权声明等材料；
- 做重复率、引用、图片授权和代码匿名化检查；
- 投稿前重新核对期刊最新范围、费用和审稿要求。
