# P75接入资源协议（执行前固定）

目的：验证参考启发式分支接在encoder_level3输出（192通道、1/4尺度），能否保持公开起点并在12GB卡上运行。该位置同时影响后续下采样与跳跃连接，不是仅改瓶颈。

两支顺序运行、不并发：局部window4/pool1；非局部window32/pool4；均4头、相同参数结构与种子。局部对照也是空间注意力，不是卷积对照；参数相同不意味着计算量相同。非局部覆盖更大但KV采样更稀，两因素尚未解耦。

只用合成随机4×3×128×128，分别一个前后向，BF16，公开权重同SHA。输出投影与FFN末层零初始化；要求加分支前后输出逐元素严格一致，参数梯度有限、输出层梯度非零、主干权重未改变。内部QKV起点零梯度是零输出层导致的正常暂时现象，不伪称第一步所有层均获得有效学习信号。

不创建优化器，不访问数据集，不作恢复质量结论；总10分钟上限，失败不自动减batch/换配置。记录峰值分配显存（不含未来AdamW状态）和单次耗时（非稳态benchmark）。未核验256验证显存与完整优化器预算前不能直接启动训练。
