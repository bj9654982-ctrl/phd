# P44采样复核与统一协议建议

2026-09-09。只读源码、既有日志并计算采样键，无权重更新，无测试集访问。

## 已核查

GoProPairDataset显式传入split=train，按录制组包含/排除；训练与开发构造为互斥组。裁剪及翻转对blur/sharp同步，随机增强仅用torch随机数；SeededPairs按样本种子设置torch RNG。validate进入eval、结束train，适用于P40/P43端到端分支；冻结主干脚本在validate后显式eval。未发现本轮范围内的划分或模式错误；不等于完成全部数据审计。

StepBatches(1718,4,0,1000)产生4000次曝光，覆盖1718图，每图2或3次。P31/P40/P43沿用该序列，因此重新使用了原训练前1000步的样本索引与增强种子，而不是从绝对步10000续接。与StepBatches(1718,4,10000,11000)的增强种子交集为0。重复来自既定实现，不是发现测试泄漏；它也未被证明是退化原因。各分支仍享有相同曝光，但不能把短筛查描述成原训练的连续轨迹。

P26原始续训本身有明显波动：6000步28.993985、7000步28.070402、8000步29.274356dB；9000步29.257442、10000步29.368879dB。因此P43保留优化器后仍有退化，并不能仅由是否重置解释。现有证据尚不足以证明恒定学习率、图块大小或特定场景是唯一原因。

## 后续统一协议建议（尚未开始新训练）

1. 若目标是继续训练而非复刻旧短筛查，所有比较分支统一采用绝对步10000之后的同一序列，并明确与旧协议不同；保留旧实验，不跨协议拼接优劣排名。
2. 主干统一保留P26 AdamW状态；新增模块使用独立新参数组、空优化器状态。同名参数加载并验证形状、状态计数、lr/wd，不能直接按新整网顺序加载旧状态。
3. 先用无数据的状态映射单元测试验证上述逻辑，不做新模型训练；再决定是否值得重跑一次对照。这样避免同时改变采样、优化器、模块和学习率后无法解释。
4. 暂不添加新模块、不修改grid、不调整学习率或扫参数。正式新协议应说明相对基线和相对训练起点的双重判断，并保留原生尺寸/多种子验证为后续要求。

本轮结论：优化器状态和绝对采样位置需要在论文中准确描述，现有方法候选仍未得到稳定收益证据；这次复核不是新的复原贡献，也不推翻P40失败结论。
