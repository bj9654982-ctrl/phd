# P61 DPDD阶段证据汇总与下一步成本

2026-09-10。当前无GPU训练。本文件用于论文实验设计与如实记录，不是可投稿结果章节。

## 已建立的证据

数据：350训练/74验证的官方名单配对，848张单图输入/GT解码通过，16位RGB、1680×1120。精确像素重复未发现；不保证无近重复或配准误差。测试未访问。

基线：随机初始化Restormer在1000和4000步中心256验证PSNR仍低于输入，SSIM后者略正。近清晰区域损伤、周期残差及重散焦细节不足均有固定样本记录。没有证明网络收敛，更没有证明数据集不适用。

采样：从同4000步起点做两组×两个采样流。筛选相对全部候选的PSNR差分别+.036043和+.001330dB，第二流SSIM下降，未重复达到门槛。不能只报告第一流。作者已有的清晰度筛选不是我们的创新。

目前缺少：充分可靠基线、独立可验证核心贡献、充分训练对照、全图评价与最终封存测试。已有产物可作为方法开发记录，不能据此宣称论文已完成。

## 官方能力核验资源

作者[散焦说明](https://github.com/swz30/Restormer/tree/main/Defocus_Deblurring)提供公开模型链接。当前main的[单图推理脚本](https://raw.githubusercontent.com/swz30/Restormer/main/Defocus_Deblurring/test_single_image_defocus_deblur.py)使用single_image_defocus_deblurring.pth和checkpoint['params']，3通道单图；[读取实现](https://raw.githubusercontent.com/swz30/Restormer/main/Defocus_Deblurring/utils.py)为默认OpenCV 8位读取后除255。此处main来源未固定到本地vendor旧commit，实际使用前须固定版本和哈希。

预训练能力核验必须单列8位读取协议，同时计算同协议输入基准；不能和当前16位指标无说明混排。不调用作者默认测试脚本，因为它会读封存测试和额外LPIPS模型。只用开发集固定裁剪和已有主干加载，核验模型能力，不计作我们训练结果或创新。权重还未下载、文件可访问性/大小还未验证。

## 成本判断

本机P54约3000更新/34.54分钟，含验证保存；P58/P60约2000更新/18.6分钟。直接线性外推300k仅能给约46–58小时的固定小裁剪粗估，未包含官方多GPU有效batch及渐进大裁剪成本，绝非规范复现工期承诺。故不能在一小时自动预算内声称完成官方训练。
