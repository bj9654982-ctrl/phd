# P31四分支筛查协议（运行前固定）

2026-09-07。A原基线、B fixed、C content、D reciprocal按顺序串行运行，各1000步。不并行争用GPU，不根据结果调参或提前择优停止。所有分支从P26 step10000主干重新加载，优化器全部重新初始化；主干全部训练。batch4/BF16、patch128、L1、AdamW lr3e-4/weight_decay1e-4、clip1、seed3407不变。逐样本种子与StepBatches(1718,4,0,1000)确定同样4000图块曝光。新增总曝光16000图块，而非同一模型续训4000步。

B新增24576参数，C/D新增49152参数；B不是严格等容量对照。C/D相同模块初始化种子，输出投影零初始化。运行前每组用同一固定训练batch检查与无模块主干输出逐值等价，不使用开发图训练。预测参数不同但初始函数相同。

每组在0和1000步评价完整385张开发中心256裁剪，保存逐图浮点RGB PSNR/SSIM、末次检查点及训练记录。评价不访问test，不进行事后选步。D对C检验互惠约束增益，D对A检验超出继续训练的收益；B/C只是描述辅助。筛查门槛预定为D−A及D−C整体PSNR均≥0.02dB、SSIM均非负，且三个录制组D−C平均PSNR均非负。门槛只决定是否值得下一步多seed验证，不是显著性检验或论文成功标准。失败完整保留，不自动改阈值。

每100步记录吞吐和进度，异常或非有限梯度停止；总壁钟预算两小时，达到预算即保存中断检查点并停止剩余分支，不自动延长。缓存资源探针估计总训练38分钟，另留初始化、数据、8次验证与保存开销；实测超过预算不能继续。
