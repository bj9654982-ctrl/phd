# P8–P11 阶段决策：轨迹模块与互补残差路线

## 结论先行

当前证据不支持把“动态稀疏非局部轨迹模块”作为论文的主要性能贡献。它在两组严格匹配控制中的边际贡献仅为 +0.00341 dB 和 -0.00204 dB，明显低于预设 +0.02 dB 门槛。

同时，P5 的轻模糊保护与 P8 的重模糊专家表现出稳定互补性：零训练加法组合曾达到 +0.09971 dB，三个录像组均为正。但该组合对中度模糊退化 -0.06176 dB；保守三路公式仍未解决这一问题。因此，互补残差是可继续验证的信号，但还不是可投稿结果。

## 为什么不能继续调标量门

P7 门只使用 B0 修正幅度估计模糊强度。在 train 内校准组上三分类准确率为 70%，但真实中度样本仍会被高置信地送往轻、重两端。P11 已证明：只对这个标量做平方、死区或阈值变换，不能识别“高置信但错误”的样本。继续查看开发结果后调指数会扩大开发集过拟合，不能形成可信论文证据。

## 推荐路线

推荐把暂定主线调整为“模糊不确定性感知的互补残差复原”，下一阶段只做一次 P12：冻结 B0、P5 和局部重模糊专家，用小型 CNN 根据模糊图及三个分支残差直接预测 B0/P5/专家三路权重。路由器只在 8 个 train 录像组拟合，在另 3 个 train 录像组早停和校准，最后一次评估 3 个开发录像组，并显式加入中度保护条件。

若 P12 不能同时满足整体 +0.075 dB、SSIM 不降、每个录像组不低于 -0.01 dB，以及重/中/轻三层保护条件，则停止该候选，转向更强公开骨干和新的方法假设。

## 若坚持原题

如果论文必须继续使用“动态稀疏非局部去模糊”作为标题，就不应把当前轨迹块强行写成有效创新。需要重新设计能够产生至少 +0.02 dB 匹配边际的核心模块，并重新执行局部控制、参数量控制、多随机种子和公开测试；预计工作量显著高于互补残差路线。
