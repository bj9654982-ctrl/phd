# P55 官方配置审计（2026-09-10）

只读对照固定作者版本68dc6ac472db26f16361150cb7a96a1bc87da93f。未训练、未改数据、未读test。

## 核对结果

1. **不是选错单图网络结构。** 官方Single_8bit配置的network_g与当前相同：3通道、dim48、blocks[4,6,6,8]、refinement4、heads[1,2,4,8]、WithBias、dual_pixel_task=false。AdamW的lr3e-4、wd1e-4、betas以及L1也一致。[作者配置](https://raw.githubusercontent.com/swz30/Restormer/68dc6ac472db26f16361150cb7a96a1bc87da93f/Defocus_Deblurring/Options/DefocusDeblur_Single_8bit_Restormer.yml)

2. **预算远非官方复现。** 官方300000步、8GPU、初始每GPU batch8，128→384渐进裁剪，前92000步学习率保持3e-4。当前单GPU/batch4/4000步/固定128远小于它。当前未降学习率不能单独被认定错误，也不能将4000步判为收敛。[同一配置](https://raw.githubusercontent.com/swz30/Restormer/68dc6ac472db26f16361150cb7a96a1bc87da93f/Defocus_Deblurring/Options/DefocusDeblur_Single_8bit_Restormer.yml)

3. **训练采样不同。** 作者先切512块、步长204，按GT多尺度Sobel清晰度组合分数去掉每图最低30%块，再训练；当前整图均匀抽128，无清晰度筛选。作者验证预处理也取中心256，与当前尺寸一致。筛选针对低纹理GT，而非直接删除“模糊难样本”；不能把它解释为挑好分数。[作者预处理](https://raw.githubusercontent.com/swz30/Restormer/68dc6ac472db26f16361150cb7a96a1bc87da93f/Defocus_Deblurring/generate_patches_dpdd.py)

4. **输入协议必须区分。** 固定版本Options目录经GitHub API只读确认只有Single_8bit和DualPixel_16bit。猜测Single_16bit的URL实际404，不可声称存在该配置。当前16位单图归一化是自定义协议，不是官方Single_8bit的严格复现；但更高位深本身不证明导致失败。双像素16位是不同输入任务，不能为了套配置而悄悄改用左右视图。[作者目录](https://github.com/swz30/Restormer/tree/68dc6ac472db26f16361150cb7a96a1bc87da93f/Defocus_Deblurring/Options)

## 下一步与边界

不恢复原配置盲目续训，不直接扩大至300k。优先对**训练集**固定均匀选取的12张做GT纹理采样审计，比较现行128抽样与作者512候选块筛选后的纹理分布，记录计算时间和退化程度；不使用验证GT决定哪些训练图入选，不读取test。只读实现作者评分时要处理全平坦图归一化分母为零，并明确该保护性差异。

若审计确认采样确有明显分布变化，再冻结一次“仅改变采样策略”的匹配短对照，统一起点、状态、步数和验证，不能同时更改位深/损失/学习率/模型并把收益归因采样。失败则停止该假设，不无限试参。官方长期预算差距仍是主要限制，不能许诺该修正必然成功。
