## 一、第2章 MSANet（最核心、最可迁移到去模糊）

> 论文原文定位：2.1–2.5 节（PDF 第37–58页）。这是一篇**判别式、非对称编码器-解码器多尺度复原网络**，与 MPRNet / Restormer / Uformer 同一范式，只是用卷积+可变形卷积实现，**改任务到去模糊几乎只需换数据**。

### 1.1 设计动机（对去模糊同样成立）

现有多尺度架构只关注**跨尺度互补**，忽略了**尺度内特性**。作者指出：

- **浅层高分辨率特征**：细节多（边缘/纹理）但噪声多、上下文少 → 需要"保细节、滤噪声"。
- **深层低分辨率特征**：噪声少、上下文多，但分辨率太低会破坏结构 → 需要"保分辨率、扩感受野"。
- 结论：不同尺度**不能用同构子网络**，要按尺度特性设计各自分支。

> **对GOPRO去模糊的启发**：动态模糊的"细节-噪声"困境可类比为"细节-拖影"困境。高分辨率分支去保留锐利边缘、低分辨率分支去建模大尺度运动模糊的全局上下文，这一分工对运动模糊同样有效。

### 1.2 整体网络结构（关键维度）

- **非对称编码器-解码器**，4 个尺度。
- **编码器**：4 个残差模块（RB）。第1个 RB 保持分辨率不变提初始特征；其余 3 个每个**分辨率减半、通道数加倍**。
- **通道数（4 个尺度）**：**32 → 64 → 128 → 256**（编码器方向）；解码器方向对称回 128 → 64 → 32。
- **子网络分支**：
  - 底部 2 个子网络 = **高分辨率分支**：交替堆叠 AFeB + AMB，设计得**更深**（通道少、参数少，所以堆深）。
  - 顶部 2 个子网络 = **低分辨率分支**：主要由 AMB 组成，设计得**更浅**（通道多，提效）；除最底层外，每个顶部子网络的**第一个和最后一个模块都是 AFeB**，用于自适应控制输入/输出特征。
- **解码器**：4 个 AFuB 模块 + 最后一个卷积层输出。
  - 前 3 个 AFuB：分辨率 ×2、通道 ÷2，把细粒度细节迁到粗粒度上下文。
  - 最后 1 个 AFuB：**分辨率和通道都不变**，直接从**含噪/含模糊输入**采样细节——作者明确说这是"**全局跳跃连接的有效替代**"，目的是**避免把输入噪声（模糊）直接灌到输出**。这一点对去模糊非常关键（避免模糊残留）。

### 1.3 三个核心模块（可直接复现）

#### （1）AFeB —— 自适应特征模块（Adaptive Feature Block）
用途：**自适应保留细节、滤除噪声/拖影**。
- 本质是**可调制可变形卷积（Deformable Conv v2）**：先预测偏移量 (Δx, Δy) 和调制权重 Δw，再对输入特征做采样加权聚合。
- 结构：`Conv(算偏移) → 调制可变形卷积 → LeakyReLU → Conv → 残差连接`
  - 公式：`f_out = f_i + F_conv(F_ReLU(f_{i+1}))`
- 作用：让网络自己"学哪里该采、采多大权重"，天然适配非均匀运动模糊。

#### （2）AMB —— 自适应多尺度模块（Adaptive Multi-scale Block）
用途：**不改变分辨率地扩大感受野、聚多尺度上下文**。
- 4 路**并联空洞卷积**，膨胀率 = **1, 2, 3, 4**；每路先**通道压缩**，使各路通道之和 = 输出通道数（控算力）。
- 拼接后做**双重自适应缩放**：
  - 通道维：`ch = 2·σ(F_fc(avg_pool(x)))` → 通道注意力（SE 风格）。
  - 空间维：`sp = 2·σ(F_conv(mean(x)))` → 空间注意力。
  - 乘性调制后：`x = sp · (ch · x)`。
- 结尾：`LeakyReLU → Conv → 残差`。
- > **对去模糊的启发**：并行空洞卷积（d=1~4）扩大感受野，正是运动模糊核大小不一所需要的；双重通道+空间注意力可直接搬进去模糊主干。

#### （3）AFuB —— 自适应融合模块（Adaptive Fusion Block）
用途：**跨尺度把细粒度细节迁到粗粒度上下文**（粗到细融合）。
- 先把粗特征用**转置卷积**上采样到细特征分辨率。
- 再用**粗特征提供上下文、细特征提供细节**，预测偏移量与权重，用**调制可变形卷积**把细细节"采样注入"粗特征：`f_coarse += Σ w_j · f_fine(x+Δx)·Δw_j`。
- 结尾：`Conv → LeakyReLU → Conv → 残差`。

### 1.4 模块卷积超参（2.4.1 节，精确）

- 所有 Conv / LeakyReLU（除非另注）：**K=3, S=1, P=1**，LeakyReLU 负斜率 **0.2**。
- RB：下采样时 `K=3,S=2,P=1`（否则 `K=1,S=1,P=0`）；后接两个 `K=3,S=1,P=1` 卷积，中间插 LeakyReLU，带残差。
- AMB：4 路空洞卷积 **d=1,2,3,4**；自适应缩放卷积 **K=7,S=1,P=3**。
- AFuB：上采样用转置卷积 **K=3,S=2,P=1**；不上采样时换成 **K=1,S=1,P=0**。

### 1.5 损失函数（2.3.1 节）

- 主损失：**像素 L_p 范数** `L = ‖y − ŷ‖_p`，**p=1 或 2**。
- 训练策略差异：
  - **真实噪声** → 用 **L1 损失**，训 **100 epoch**。
  - **合成噪声** → 用 **L2 损失**，训 **300 epoch**。
- **没有**感知损失、对抗损失、频域损失（这章纯回归损失）。

### 1.6 训练策略（2.4.2 节，精确）

| 项目 | 设置 |
|------|------|
| 框架 | PyTorch，Ubuntu 20.04，**单张 RTX 3090** |
| 优化器 | **Adam**（默认超参） |
| 初始学习率 | **1e-4** |
| 学习率调度 | **余弦退火（Cosine Annealing）衰减到 0** |
| Batch Size | **16** |
| Patch Size | **128 × 128** |
| 数据增强 | 随机裁剪 + 随机翻转 + 随机旋转 |
| 训练轮数 | 真实噪声 100 epoch / 合成噪声 300 epoch |

### 1.7 评价指标

- **PSNR（dB，越大越好）**、**SSIM（0~1，越大越好）**。论文**未使用 LPIPS**。

## 二、第5章 TAO（扩散模型 + 测试时自适应，思想可借）

> 定位：5.1–5.5 节（PDF 第107–129页）。这是一篇**开集图像复原（OIR）**工作，思路是"拿一个在 ImageNet 上预训练的无条件扩散模型当通用先验，测试时用轻量适配器自适应当前退化"。**不做 GOPRO，但其测试时自适应与分阶段引导思想对真实模糊（无配对数据/跨域模糊）有借鉴价值。**

### 2.1 框架三组件

1. **PDM（预训练扩散模型）**：ImageNet 预训练的**无条件**图像扩散模型，**T=1000** 步去噪。把任何退化都当作"未知未见退化"。
2. **TDA（测试时退化适配器）**：一个**4 层卷积**的轻量网络 φ(·)，把生成的清晰图 ŷ₀ 映射回退化域，与真实退化图 y 做**域对齐**。
3. **AIR（适配器引导复原）**：把去噪过程分 3 阶段，用不同损失项动态引导。

### 2.2 损失函数（本章最全，可借鉴）

**适配器 φ 的总损失（式5-9）：**
`L_φ = λ1·L_rec + λ2·L_pec + λ3·L_adv`
- `L_rec`：重构 L2，保持内容一致（式5-7）。
- `L_pec`：**感知损失**（VGG 特征 L2，式5-8）。
- `L_adv`：**对抗损失**（式5-5/5-6），配一个判别器 D。消融显示 **VGAN-S（Sigmoid+BCELoss）最优**，WGAN 最差（13.61dB）。

**AIR 三阶段引导（去噪步按 t 划分）：**
- **阶段一 t∈[999,700]**（全局结构）：`G = γ1·‖y − φ(x̂0)‖₂²`（MSE），γ1 用**线性预热（Linear Warmup）**。
- **阶段二 t∈[700,50]**（语义内容）：`G = γ2·G_mse + γ3·G_pec + γ4·G_adv`（MSE + 感知 + 对抗）。
- **阶段三 t∈[50,0]**（细节）：`G = γ5·TV(总变分损失)`，并**保留阶段二损失**防信息丢失。

> 消融（表5.5）：统一 MSE 全程引导仅 20.49dB；用 AIR 三阶段达 **22.29dB**。去掉阶段二掉点最多（21.06dB）。阶段切换点 700 / 50 最优（表5.6）。

### 2.3 训练/推理策略（测试时优化）

- 适配器 + 2 个判别器均为 4 层卷积；**每个去噪步用 Adam（lr=1e-3）更新**。
- 感知特征取 **VGG-16 前 9 层**。
- 硬件：PyTorch + RTX 3090。
- 仅微调损失权重 λ1~3、γ1~5 和引导力度 s 来适配不同退化。

### 2.4 实验数值（去雾/低光/去噪，非去模糊）

| 任务 / 数据集 | 方法 | PSNR | SSIM |
|---------------|------|------|------|
| 去雾 / RESIDE-HSTS | **TAO** | **22.29** | **0.877** |
| 去雾 / HSTS | DehazeNet（最强有监督） | 23.96 | 0.902 |
| 低光 / LOL | **TAO** | **17.10** | **0.804** |
| 低光 / LOL | MBLLEN（最强） | 18.03 | 0.809 |

### 2.5 第5章创新点

1. **首次形式化定义"开集图像复原 OIR"**，指出本质是测试-训练分布偏移。
2. 用**测试时自适应（TTA）+ 无条件扩散先验**解决未知退化，无需针对退化训练。
3. AIR **分阶段引导**（全局→语义→细节），与扩散过程的时间动态性匹配。

## 三、其余三章简要（与去模糊弱相关）

### 第3章 CLEARER（多尺度神经架构搜索）
- 可微分多分辨率搜索空间；损失里加**参数量正则**（λ1, λ2 控复杂度）。
- 搜索：SGD（动量0.9，wd=3e-4，lr 余弦 0.025→0.001）更新网络权重；Adam（lr=3e-4）更新架构参数；patch 64×64；最大 10k 迭代（前 1k 只训权重）。重训 100k 迭代。
- 仅需 **2×V100 约1小时**完成搜索。
- **任务**：去噪（BSD500/BSD68/Set12）+ 去雨。**无去模糊。**
- 借鉴点：若想自动化设计去模糊多尺度主干，可复用其多分辨率搜索空间。

### 第4章 FPL（面向长尾像素分布的超分）
- 把超分重构不均（高频难、低频易）视为**长尾分布学习**；引入静态+训练时结构先验，用**焦点像素学习（FPL）**重加权高频像素梯度。
- 训练：DIV2K；batch 16，LR patch 32×32；Adam；lr 按模型规模 1e-3 / 2e-4；余弦退火。
- **任务**：超分（Set5/14、BSD100、Manga109、Urban100）。**无去模糊。**
- **对去模糊的借鉴点**：运动模糊恢复中"锐边/高频细节难重建"同样是长尾问题，FPL 的高频像素重加权思路可直接迁移到 GOPRO（让网络更聚焦被模糊抹掉的边缘）。

### 第6章 YOLY（无监督无训练单图去雾）
- 三个子网络 J-Net/T-Net/A-Net 把雾图解耦为场景辐射层/传输层/大气光层，自监督重组。
- **任务**：去雾（RESIDE / I-HAZE / O-HAZE）。**无去模糊，借鉴价值低。**

## 四、对「GOPRO 动态场景去模糊」的改进灵感汇总

> 该论文**没有 GOPRO 直接结果**，以下是从其各章方法中提炼、**可迁移到你 GOPRO 实验**的点。

### 4.1 可直接复现的模块（来自第2章 MSANet）
1. **非对称编码器-解码器 + 4 尺度通道（32/64/128/256）**：直接做 GOPRO 去模糊主干，把去噪数据换成 GOPRO（2103 张训练对）。
2. **AMB 并行空洞卷积（d=1~4）+ 通道&空间双重注意力**：天生适配大小不一的运动模糊核。
3. **AFuB 用"输入直采细节"替代全局跳跃连接**：**关键**——可避免把模糊输入的拖影直接残差到输出，缓解去模糊常见的"残留模糊"。
4. **AFeB 调制可变形卷积**：让网络自适应对齐被运动模糊扭曲的边缘，适合非均匀模糊。

### 4.2 可借鉴的创新/训练策略
1. **L1 训练 + Adam(1e-4) + 余弦退火 + batch16 + patch128 + 随机翻转旋转**（第2章验证有效的配方），可直接作为 GOPRO 去模糊的训练基线。
2. **FPL 高频像素重加权**（第4章）：解决运动模糊中锐边/高频细节"学不动"的问题。
3. **分阶段引导损失**（第5章 AIR）：若用扩散模型做去模糊，可按去噪步分"全局结构→语义→细节"施加 MSE/感知/TV。
4. **对抗损失选 VGAN-S（Sigmoid+BCELoss）**（第5章消融结论）：比 WGAN/LSGAN/Hinge 更稳，加对抗损失提 GOPRO 视觉效果时可参考。

### 4.3 关于"GOPRO SOTA 数值"的说明（重要）
- **本论文未在 GOPRO 上做实验，因此无 GOPRO PSNR/SSIM 数值可引。** 上表所有数值均为去噪/去雾/低光/超分数值，**不能**当作 GOPRO 成绩使用。
- 若你需要 GOPRO 上的 SOTA 参照系（Restormer / Uformer / SwinIR / MPRNet / NAFNet 等），这些**属于本论文之外的外部文献**，建议直接查对应原文，不要从本论文笔记里套数。需要的话我可以另起任务，用联网检索整理一份 GOPRO 测试集 SOTA 对照表。
