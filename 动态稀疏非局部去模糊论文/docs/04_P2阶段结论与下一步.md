# P2 阶段结论与下一步

## 一句话结论

第一版 MT-NLR 在单一直线合成模糊上有效，但在 256/64 GoPro 迷你闭环中没有稳定超过相同初始化的卷积 B0，因此当前不能形成论文贡献，停止继续扩展该模块。

## 证据表

| 实验 | 最佳 PSNR/dB | 相对 B0/dB | 结论 |
|---|---:|---:|---|
| B0 紧凑 U-Net | 25.0642 | 0 | 迷你基线 |
| MT-NLR 正权重聚合 | 25.0419 | -0.0222 | 不通过 |
| MT-NLR 方向细节 | 25.0340 | -0.0301 | 不通过 |
| MT-NLR 三候选轨迹 | 24.9915 | -0.0727 | 不通过 |
| 合成 oracle 轨迹 | 21.6824 | +0.1506（相对合成 B0） | 仅诊断通过 |
| 合成冻结预测轨迹 | 21.6641 | +0.1323（相对合成 B0） | 仅诊断通过 |

## 可以保留的技术资产

1. 公平初始化、恒等模块插入和可恢复训练管线；
2. 稠密双角方向—长度几何头及合成门槛；
3. oracle 几何覆盖接口，可用于后续模块因果诊断；
4. 配对梯度损失方向伪标签及其失败证据；
5. 17 项 CUDA、数据和轨迹采样测试。

## 下一阶段顺序

1. 使用完整 2103 对 GoPro 训练集建立强开发基线，不再用 256 对、5000 步结果代表模型上限；
2. 开发阶段先固定 100 个跨场景验证样本，最终只在方案冻结后评估完整 1111 对测试集；
3. 强基线明显超过模糊输入后，再比较候选改进；
4. 新候选必须先以低成本消融证明收益，不复用“单一直线合成有效”等同“真实动态模糊有效”的论证。

## 研究诚信边界

- `summary.json` 中的 `passed` 只表示相对模糊输入提升达到管线门槛，不表示超过 B0；
- 合成 oracle 和预测轨迹实验是定位证据，不是论文主结果；
- P2 负结果必须保留，不挑选早期单点宣称有效；
- 在完整训练协议、至少三个随机种子和完整测试集完成前，不宣称方法优于现有工作。
