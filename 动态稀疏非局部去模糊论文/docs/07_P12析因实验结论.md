# P12 条件机制 2×2 析因实验结论

## 1. 为什么要做完整四格实验

P12-E 在同一 P12-D 权重上关闭条件输出，发现固定融合门反而提高平均 PSNR。但这种推理期干预会把模型放到训练时没有见过的状态，只能说明检查点对条件输出的依赖，不能替代从相同起点独立训练的消融。

因此补齐两个缺失组合，四个模型均从同一 B0 初始化，参数量、数据顺序、损失和 3000 步预算完全一致：

| 变体 | 尺度先验 | 局部—非局部门 |
|---|---|---|
| C | 均匀 | 固定 0.5 |
| S | 自适应 | 固定 0.5 |
| G | 均匀 | 自适应 |
| D | 自适应 | 自适应 |

## 2. 四个独立训练结果

| 变体 | PSNR (dB) | 相对 C | SSIM |
|---|---:|---:|---:|
| C | 28.95143 | 0 | 0.849042 |
| S | 28.96109 | +0.00967 | 0.849148 |
| G | 28.96761 | +0.01619 | 0.849258 |
| D | **28.96808** | **+0.01665** | **0.849277** |

D 的数值最高，但只比 G 高 0.00047 dB。该差值的图像级描述 bootstrap 区间为 [-0.00032,+0.00125] dB，且三个录像组的 D-G 为 -0.00074/+0.00140/+0.00156 dB。因此不能把 D 相对 G 的极小差值当作完整尺度自适应的有效贡献。

## 3. 主效应与交互

尺度效应：

- 固定门条件：`S-C = +0.00967 dB`。
- 自适应门条件：`D-G = +0.00047 dB`。
- 两者平均的尺度主效应：`+0.00507 dB`。

融合门效应：

- 均匀尺度条件：`G-C = +0.01619 dB`。
- 自适应尺度条件：`D-S = +0.00699 dB`。
- 两者平均的融合门主效应：`+0.01159 dB`。

交互效应 `D-S-G+C = -0.00920 dB`。其绝对值略低于预设的 0.01 dB 明显交互线，但负号清楚表明两个组件的收益存在重叠：先启用其中一个后，另一个的边际贡献会缩小。

按预设规则，尺度主效应和门主效应都获得一致支持；但尺度效应只是刚过 +0.005 dB，且在已有自适应门时几乎消失。门效应更大、在两个尺度条件下都为正，是当前更可靠的条件机制。

## 4. 分层检查

| 分层 | 尺度主效应 | 门主效应 | D-G |
|---|---:|---:|---:|
| GOPR0372_07 | +0.00400 | +0.00913 | -0.00074 |
| GOPR0378_13 | +0.00184 | +0.00954 | +0.00140 |
| GOPR0385_11 | +0.01048 | +0.01814 | +0.00156 |
| 重模糊 | +0.00416 | +0.00799 | +0.00060 |
| 中模糊 | +0.00270 | +0.00524 | +0.00164 |
| 轻模糊 | +0.00691 | +0.01715 | -0.00028 |

门主效应在三个录像组和三档强度中全部为正。D-G 在各层都接近零，进一步说明尺度条件在门控存在时没有稳定的额外价值。

## 5. 当前冻结模型与论文表述边界

下一阶段冻结 G，而不是 D。G 保留三项结构：固定的多尺度支持域、内容相似度 Top-K 稀疏聚合、逐像素局部—非局部融合门；删除在现有门控下几乎无边际的动态尺度先验。这样模型更简单，结论也更符合消融证据。

当前可以写成开发阶段发现：

> 多尺度非局部表示提供主要收益，内容 Top-K 的单独增益较小；退化条件融合门在匹配训练中产生更稳定的附加收益，而动态尺度先验与融合门存在明显的收益重叠。

仍不能写成论文最终结论。原因是目前只有一个训练种子，而且 G 相对局部控制在 `GOPR0372_07` 仍约低 0.02326 dB，未通过预设的跨录像组保护线。

## 6. 第二随机种子协议

- 随机种子：7813，在运行前固定。
- 只训练两个模型：局部控制 A 与候选 G。
- 其余协议保持：同一 P3 B0、1718/385 数据、batch 6、256 patch、相同损失和 3000 步预算。
- 通过条件：种子 7813 上 `G-A >= +0.02 dB`，且三个录像组的最差 `G-A >= -0.01 dB`。
- 不根据结果更换种子、阈值或录像组。
- 通过后才接入 TMT 静态 `blur -> gt`；GoPro 官方 test 继续保持未访问。

图像级 bootstrap 仅是描述性区间，因为相邻视频帧不是独立样本；最终稳定性优先依据独立训练种子和录像组分层。
