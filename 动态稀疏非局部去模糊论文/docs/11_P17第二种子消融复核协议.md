- 两个种子各自的四个条件效应、两个主效应、交互项，PSNR 与 SSIM 都报告。

- C01/C11 均列出原数值筛选线：总体相对局部 ≥ +0.02 dB，整体 SSIM 不降，
  每录像组、每代理层次均不低于 −0.01 dB。P16 的小差距不转化为新的通过阈值。
- 不新增因素显著性或非劣性界限；根据两个种子的效应符号、大小和分组权衡讨论。
