## 看图学什么

已检查case1、case2、case4的六列比较图，所有模型使用相同放大位置，没有额外锐化。

- 车窗场景：公开模型的背景树木与杆件边缘更接近真值，当前三种小模型仍有明显拖影。这里差距不只是分数变化。
- 车尾重度模糊：公开模型恢复了更明确的尾灯内部结构和轮胎轮廓，但仍有平滑与细节误差。不能把视觉更清晰等同于所有细节真实恢复。
- 船上人物：公开模型的轮廓和远岸结构更清晰，但真值中衣服的细条纹没有充分恢复。高PSNR仍可能掩盖局部纹理缺失，因此必须同时看真值和细节图。

“学习先验”指模型从训练样本中学习清晰图像与模糊输入之间的规律，不是把丢失信息无条件找回来。本例存在训练重叠，不能据此排除记忆训练图像的影响，也不能证明未见图像一定同样有效。

## 下一步研究决策

1. 保留旧实验及P21未通过结论，不把C01门监督宣布为成功创新。本轮也不自动扩大到385图或开启长训练。
2. 下一阶段先固定可比训练协议：公开方法若用于正式对比，应在相同训练/开发划分下训练，不直接用含开发图的公开权重冒充公平基线。先做小规模资源与收敛试验，再决定完整预算。
3. 在有足够复原能力的基线上，只验证一个明确假设：非局部特征匹配能否改善重度拖影/重复纹理，并减少错误匹配。用“无模块/固定匹配/提出模块”的同预算消融，而不是同时变动训练量、参数量和损失。
4. 模块必须带来可重复的质量或质量—成本收益，才值得进入正式独立测试和论文撰写。如果未成立，保留负结果并修改假设，不包装微小数值提升。

现有小模型可保留作轻量实验台，不需要删掉重来；但不能把当前CNN主干加一个非局部块称作完整Restormer或完整Transformer。
