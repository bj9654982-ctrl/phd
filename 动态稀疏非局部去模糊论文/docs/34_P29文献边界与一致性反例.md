# P29文献边界与一致性反例

## 文献核查范围

2026-09-07初步检索，不是穷尽性新颖性证明。

- [NLSA，CVPR2021](https://openaccess.thecvf.com/content/CVPR2021/html/Mei_Image_Super-Resolution_With_Non-Local_Sparse_Attention_CVPR_2021_paper.html)：官方索引摘要已有非局部稀疏注意力用于超分辨率。页面直开403；本轮未完成全文核查，不据此描述内部实现细节。
- [DRSformer，CVPR2023](https://arxiv.org/abs/2303.11950)：已打开作者arXiv摘要，明确提出为去雨保留有用注意力的可学习Top-k。可见“减少不相关聚合”与“Top-k选择”不是可直接独占的创新点；该文并非本项目固定空间偏移实现，不能把两者说成完全相同。
- [Learning Dense Correspondence via 3D-Guided Cycle Consistency，CVPR2016相关官方条目](https://openaccess.thecvf.com/content_cvpr_2016/html/Zhou_Learning_Dense_Correspondence_CVPR_2016_paper.html)：检索摘要已说明循环一致性监督；直开403，完整标题与方法细节在正式文献表前仍需全文核对。因此循环一致性本身不能宣传为新概念。

结论：目前尚无足够证据支持论文新颖性。固定候选、Top-k、往返一致性组合仅是实验假设，不写“首次提出”。下一轮需继续核查最接近的原始全文，再决定模块定位。

## 最小一致性检查

本轮只实现一个合成对应关系检查器。对位置i的最优匹配p(i)，非自匹配且p(p(i))=i时判定互为匹配。独立batch计算，索引越界拒绝；这不是完整非局部模块，没有梯度训练。

五项确定性检查覆盖互相匹配、三点循环、自匹配、错误但互相匹配、batch隔离。关键反例：错误配对也可以形成两点循环，因而一致性通过不能证明语义或纹理对应正确。重复纹理和并列相似度可能进一步造成这种问题；不得把一致性掩码命名为真实可靠性标签。

## 对下一项实现的影响

先保留A/B/C/D消融的实验目的，但D只能叫“一致性抑制候选”，不能预设可以保护所有清晰结构。硬argmax/互惠掩码不可微，其内部不应宣称可端到端学习；相似度权重、投影仍可有梯度，需单独测试。若以后改为软循环权重，是新的明确算子定义，不得与硬规则混称。

固定几何分支B若不使用query/key，那么“名义参数相同”也不代表有效可训练容量相同。正式协议须报告总参数与实际参与梯度的参数，或将B定位为几何控制而非严格容量控制，不能以无用参数凑公平。

下一步是全文核查与确定单一算子定义、边界/并列处理，再执行真实训练图资源和反向检查；尚未开始新模型训练。本轮合成检查不证明任何真实图像质量收益。
