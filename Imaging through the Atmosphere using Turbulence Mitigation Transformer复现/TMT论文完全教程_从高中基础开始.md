# 第一篇：基础篇——从高中数学到图像处理的语言

## 第1章：什么是数字图像？

### 1.1 从模拟图像到数字图像

你用手机拍一张照片，手机里存的是什么？是一堆数字。

想象一下，你拿一张网格纸盖在照片上，每个小格子里取一个平均颜色，用数字表示。这就是**数字化**。

- **像素（Pixel）**：每个小格子就是一个像素，是图像的最小单位。
- **分辨率**：横向有多少像素 × 纵向有多少像素。比如1920×1080，就是横向1920个像素，纵向1080个像素，总共约207万个像素。
- **灰度图**：每个像素只有一个数值，表示亮度。0是纯黑，255是纯白，中间是灰色。
- **彩色图（RGB）**：每个像素有三个数值，分别表示红(Red)、绿(Green)、蓝(Blue)的亮度。每种颜色0-255，三个组合起来就能表示约1677万种颜色。

### 1.2 图像的数学表示

一张灰度图，可以看成一个二维函数：

```
I(x, y) = 位置(x, y)处的亮度
```

其中x是横坐标，y是纵坐标，I是亮度值。

如果是彩色图，就是三个二维函数：

```
I_R(x, y) = 红色通道亮度
I_G(x, y) = 绿色通道亮度
I_B(x, y) = 蓝色通道亮度
```

在计算机里，图像就是一个**矩阵**（或者说二维数组）。比如一张3×3的灰度图：

```
| 100  150  200 |
|  80  120  160 |
|  60   90  120 |
```

这就是9个数字，每个数字代表一个像素的亮度。

### 1.3 视频是什么？

视频就是一连串的图像，按时间顺序排列。

```
I(x, y, t) = 时刻t、位置(x, y)处的亮度
```

如果视频有T帧，那就是T张图像叠在一起，形成一个三维数据。

**这很重要**，因为TMT论文处理的就是视频（多帧图像），不是单张图。它利用多帧之间的信息来复原图像。

### 1.4 图像的常见操作

- **裁剪**：只取图像的一部分
- **缩放**：把图像变大或变小
- **翻转**：左右翻转或上下翻转
- **旋转**：把图像转一个角度
- **滤波**：改变像素的值（比如模糊、锐化）

这些操作在后面的"数据增强"部分会用到。

## 第2章：高中数学复习

别怕，这里只复习后面真正会用到的部分，不考的一律不讲。

### 2.1 函数

函数就是"输入一个数，输出一个数"的机器。

```
y = f(x)
```

比如 f(x) = x²，输入2，输出4；输入3，输出9。

**多元函数**：输入多个数，输出一个数。

```
z = f(x, y)
```

比如图像亮度 I(x, y)，输入位置x和y，输出亮度。这就是二元函数。

### 2.2 导数：变化率

导数描述"函数变化得有多快"。

比如你开车，位置随时间变化是 s(t)，那么速度就是位置对时间的导数：

```
v(t) = ds/dt
```

意思是：在很小的一段时间dt内，位置变化了ds，速度就是ds除以dt。

**偏导数**：对于多元函数，只让一个变量变，其他变量固定，求导。

```
∂I/∂x = 图像在x方向的亮度变化率
∂I/∂y = 图像在y方向的亮度变化率
```

这在后面讲"梯度"、"光流"时会用到。

### 2.3 积分：累加

积分就是"把很多很小的东西加起来"。

比如你开车，速度是v(t)，那么从时间a到时间b，你开了多远？

```
距离 = ∫(a到b) v(t) dt
```

意思是：把时间分成很多小段dt，每段走了v(t)×dt，全部加起来。

**二重积分**：对二维函数积分。

```
∫∫ I(x, y) dx dy = 整张图的亮度总和
```

### 2.4 指数函数和对数

- 指数函数：f(x) = e^x（e≈2.71828，是一个常数）
- 对数函数：f(x) = ln(x)，是指数函数的反函数

这两个在后面讲"损失函数"、"概率分布"时会用到。

### 2.5 三角函数

- 正弦函数：sin(x)
- 余弦函数：cos(x)

这两个函数是周期性的，像波浪一样。它们是傅里叶变换的基础，下一章会详细讲。

**欧拉公式**（非常重要，后面会反复用）：

```
e^(ix) = cos(x) + i·sin(x)
```

其中i是虚数单位，i² = -1。

这个公式把指数函数和三角函数联系起来了，非常神奇。傅里叶变换就是基于这个公式。

## 第3章：线性代数入门

线性代数是深度学习的"普通话"，所有神经网络的运算本质上都是矩阵运算。

### 3.1 标量、向量、矩阵、张量

- **标量（Scalar）**：一个数，比如 3、5.7
- **向量（Vector）**：一排数，比如 [1, 2, 3]
- **矩阵（Matrix）**：一个二维的数表，比如：
  ```
  | 1 2 3 |
  | 4 5 6 |
  ```
- **张量（Tensor）**：更高维的数表。三维张量可以理解为"矩阵的列表"，四维张量就是"三维张量的列表"。

在PyTorch（深度学习框架）里，所有数据都是张量。

### 3.2 向量

向量就是一排数，可以理解为空间中的一个点或者一个箭头。

比如二维向量 v = [3, 4]，表示从原点出发，向右走3，向上走4。

**向量的长度（范数）**：

```
||v|| = √(3² + 4²) = 5
```

就是勾股定理。

**向量加法**：对应位置相加

```
[1, 2] + [3, 4] = [4, 6]
```

**数乘**：每个数都乘以同一个数

```
2 × [1, 2] = [2, 4]
```

**点积（内积）**：对应位置相乘再相加

```
[1, 2] · [3, 4] = 1×3 + 2×4 = 11
```

点积很重要，它可以衡量两个向量"有多像"。点积越大，两个向量方向越接近。

### 3.3 矩阵

矩阵就是一个二维数表。

比如一个2×3的矩阵（2行3列）：

```
A = | 1 2 3 |
    | 4 5 6 |
```

**矩阵加法**：同形状的矩阵，对应位置相加

**数乘**：每个元素都乘以同一个数

### 3.4 矩阵乘法（最重要！）

这是整个深度学习最核心的运算，一定要搞懂。

规则：A是m×n的矩阵，B是n×p的矩阵，那么C = A×B是m×p的矩阵。

C的第i行第j列 = A的第i行 和 B的第j列 的点积。

例子：

```
A = | 1 2 |    B = | 5 6 |
    | 3 4 |        | 7 8 |

C = A × B

C[0,0] = A第0行 · B第0列 = 1×5 + 2×7 = 19
C[0,1] = A第0行 · B第1列 = 1×6 + 2×8 = 22
C[1,0] = A第1行 · B第0列 = 3×5 + 4×7 = 43
C[1,1] = A第1行 · B第1列 = 3×6 + 4×8 = 50

C = | 19 22 |
    | 43 50 |
```

**注意**：
1. 矩阵乘法不满足交换律：A×B ≠ B×A
2. 第一个矩阵的列数必须等于第二个矩阵的行数

为什么矩阵乘法这么定义？因为它可以表示"线性变换"——把一个向量变成另一个向量。

在神经网络里，每一层的运算本质上就是矩阵乘法：

```
输出 = 输入 × 权重矩阵 + 偏置
```

### 3.5 矩阵的转置

把矩阵的行和列互换，就是转置，记作 A^T。

```
A = | 1 2 3 |    A^T = | 1 4 |
    | 4 5 6 |          | 2 5 |
                     | 3 6 |
```

在注意力机制里，QK^T这种运算会经常出现，就是Q乘以K的转置。

### 3.6 单位矩阵和逆矩阵

**单位矩阵I**：对角线都是1，其他都是0。

```
I = | 1 0 0 |
    | 0 1 0 |
    | 0 0 1 |
```

任何矩阵乘以单位矩阵都等于它自己：A×I = A。

**逆矩阵A⁻¹**：满足 A×A⁻¹ = I 的矩阵。

不是所有矩阵都有逆矩阵。在去模糊（反卷积）时会用到逆矩阵的概念。

## 第4章：傅里叶变换——从三角函数到频域

这是整个教程第一个"硬骨头"，但也是最有用的工具之一。慢慢来，一定能懂。

### 4.1 一个神奇的事实：任何信号都可以拆成正弦波的叠加

先听一个故事：

19世纪初，法国数学家傅里叶在研究热传导时发现了一个惊人的事实：**任何周期性的函数，都可以表示成一系列正弦函数和余弦函数的和**。

比如，一个方波（看起来是方的），可以用很多正弦波叠加出来：

```
方波 ≈ sin(x) + (1/3)sin(3x) + (1/5)sin(5x) + (1/7)sin(7x) + ...
```

加的项越多，就越接近真正的方波。

这就像：任何颜色都可以用红、绿、蓝三种颜色调出来；任何声音都可以用不同频率的纯音叠加出来。

### 4.2 时域 vs 频域

- **时域**：我们平时看信号的方式——横轴是时间，纵轴是信号强度。
- **频域**：另一种看信号的方式——横轴是频率，纵轴是该频率的强度。

傅里叶变换就是把信号从"时域"转换到"频域"的工具。

打个比方：
- 时域就像听一首交响乐，你听到的是所有乐器混在一起的声音。
- 频域就像看乐谱，你能看到每个音符（频率）的强弱。

### 4.3 一维傅里叶变换

对于一个连续信号 f(x)，它的傅里叶变换 F(ω) 定义为：

```
F(ω) = ∫ f(x) · e^(-iωx) dx
```

其中：
- ω 是频率（角频率）
- e^(-iωx) = cos(ωx) - i·sin(ωx)（用欧拉公式展开）
- 积分的意思是：对每个频率ω，计算原信号和这个频率的正弦波的"相似度"

**直觉理解**：F(ω)的大小，表示原信号中频率为ω的成分有多少。

逆傅里叶变换（从频域变回时域）：

```
f(x) = (1/2π) ∫ F(ω) · e^(iωx) dω
```

意思是：把所有频率的成分按强度加起来，就还原了原信号。

### 4.4 二维傅里叶变换

图像是二维的，所以需要二维傅里叶变换：

```
F(u, v) = ∫∫ I(x, y) · e^(-i(ux + vy)) dx dy
```

其中：
- u 是x方向的频率
- v 是y方向的频率
- F(u, v) 表示图像中频率为(u, v)的成分有多少

**图像的频域是什么意思？**
- 低频（u, v接近0）：图像中变化缓慢的部分，比如大片的天空、墙壁
- 高频（u, v很大）：图像中变化剧烈的部分，比如边缘、纹理、噪声

**模糊的图像**：高频成分被削弱了（因为模糊就是把细节抹掉了）。
**清晰的图像**：高频成分丰富。

### 4.5 卷积定理（超级重要！）

傅里叶变换有一个非常有用的性质：

**时域的卷积 = 频域的乘法**

```
如果 I' = I * k（卷积，下一章讲）
那么 F(I') = F(I) · F(k)（频域直接相乘）
```

这意味着：
1. 复杂的卷积运算，可以转换成简单的乘法运算
2. 在频域分析图像退化和复原，会变得非常直观

比如图像模糊：
- 时域：清晰图 和 模糊核 做卷积
- 频域：清晰图的频谱 乘以 模糊核的频谱

去模糊（反卷积）：
- 频域：模糊图的频谱 除以 模糊核的频谱

### 4.6 离散傅里叶变换（DFT）和快速傅里叶变换（FFT）

计算机处理的是离散数据，所以用离散傅里叶变换（DFT）。

DFT的计算量是O(N²)，很慢。后来有人发明了快速傅里叶变换（FFT），计算量降到O(N log N)，快了很多。

在Python里，用numpy.fft.fft2()就可以对图像做二维FFT。

## 第5章：卷积——图像处理最核心的操作

卷积是图像处理中最基本、最重要的操作，也是CNN（卷积神经网络）名字的由来。

### 5.1 什么是卷积？

用一个通俗的例子：

假设你有一张图，还有一个小的"模板"（叫做卷积核/filter/kernel）。卷积就是：
1. 把模板放在图像的某个位置
2. 模板和图像对应位置的像素相乘，然后全部加起来
3. 得到一个新的像素值
4. 把模板在图像上滑动，每个位置都算一遍

这就是卷积。

### 5.2 一个具体的例子

假设图像是：

```
| 1 2 3 |
| 4 5 6 |
| 7 8 9 |
```

卷积核是：

```
| 1 0 |
| 0 1 |
```

计算左上角的输出：
```
1×1 + 2×0 + 4×0 + 5×1 = 1 + 0 + 0 + 5 = 6
```

计算右上角的输出：
```
2×1 + 3×0 + 5×0 + 6×1 = 2 + 0 + 0 + 6 = 8
```

计算左下角的输出：
```
4×1 + 5×0 + 7×0 + 8×1 = 4 + 0 + 0 + 8 = 12
```

计算右下角的输出：
```
5×1 + 6×0 + 8×0 + 9×1 = 5 + 0 + 0 + 9 = 14
```

所以卷积结果是：
```
|  6  8 |
| 12 14 |
```

### 5.3 常见的卷积核

不同的卷积核能实现不同的效果：

**平均模糊（均值滤波）**：
```
| 1/9 1/9 1/9 |
| 1/9 1/9 1/9 |
| 1/9 1/9 1/9 |
```
效果：把每个像素替换成周围9个像素的平均值，图像变模糊。

**高斯模糊**：
```
| 1/16 2/16 1/16 |
| 2/16 4/16 2/16 |
| 1/16 2/16 1/16 |
```
效果：也是模糊，但中间像素权重更大，更自然。这是最常用的模糊方式。

**边缘检测（Sobel）**：
```
| -1 0 1 |
| -2 0 2 |
| -1 0 1 |
```
效果：检测垂直方向的边缘。

**锐化**：
```
|  0 -1  0 |
| -1  5 -1 |
|  0 -1  0 |
```
效果：让图像更清晰。

### 5.4 卷积的数学定义

二维卷积的数学定义：

```
(I * k)(x, y) = ∫∫ I(u, v) · k(x-u, y-v) du dv
```

离散版本：

```
(I * k)(x, y) = ΣΣ I(u, v) · k(x-u, y-v)
```

其中I是图像，k是卷积核，*表示卷积。

### 5.5 卷积的性质

1. **线性**：(a·I1 + b·I2) * k = a·(I1*k) + b·(I2*k)
2. **交换律**：I * k = k * I
3. **结合律**：(I * k1) * k2 = I * (k1 * k2)
4. **卷积定理**：F(I * k) = F(I) · F(k)（时域卷积=频域乘法）

### 5.6 卷积和图像模糊

大气湍流造成的模糊，本质上就是清晰图像和一个"点扩散函数"（PSF）做卷积。

```
模糊图 = 清晰图 * PSF
```

PSF（Point Spread Function）描述了一个点光源经过大气后变成了什么样的光斑。

如果PSF是空间不变的（ everywhere都一样），就是普通卷积。
如果PSF是空间变化的（不同位置不一样），就是"空间变化卷积"，更复杂。

大气湍流造成的模糊通常是空间变化的，因为不同位置的湍流情况不一样。

## 第6章：概率论与随机过程基础

大气湍流是随机的，所以需要概率论来描述它。

### 6.1 随机变量和概率分布

**随机变量**：取值不确定的量。比如掷骰子的结果。

**概率分布**：描述随机变量取各个值的可能性。

- **离散分布**：比如掷骰子，每个面概率1/6
- **连续分布**：比如人的身高，用概率密度函数描述

### 6.2 高斯分布（正态分布）

最重要的概率分布，也叫正态分布，形状像一个钟。

概率密度函数：

```
f(x) = (1/√(2πσ²)) · e^(-(x-μ)²/(2σ²))
```

其中：
- μ 是均值（中心点）
- σ 是标准差（宽度，越大越分散）
- σ² 是方差

高斯分布无处不在，原因是**中心极限定理**：大量独立随机变量的和，近似服从高斯分布。

大气湍流的很多统计特性都可以用高斯分布描述。

### 6.3 期望、方差、协方差

- **期望（均值）E[X]**：随机变量的平均值
- **方差Var(X) = E[(X-E[X])²]**：随机变量偏离均值的程度
- **协方差Cov(X,Y) = E[(X-E[X])(Y-E[Y])]**：两个随机变量一起变化的程度

### 6.4 随机过程

**随机过程**：随时间变化的随机变量。比如：
- 每天的气温
- 股票价格
- 大气中某点的折射率

**平稳随机过程**：统计特性不随时间变化。

**各态历经性**：时间平均等于统计平均。简单说，观察一个样本很长时间，和观察很多样本同一时刻，统计特性一样。

### 6.5 自相关和功率谱

**自相关函数**：描述随机过程在两个不同时刻的相似程度。

```
R(τ) = E[X(t) · X(t+τ)]
```

如果τ=0，R(0) = E[X²]，就是信号的平均功率。

**功率谱密度（PSD）**：自相关函数的傅里叶变换。描述随机过程在各个频率上的功率分布。

```
S(ω) = F(R(τ))
```

这在Kolmogorov湍流理论中非常重要——大气湍流的功率谱有特定的形式。

### 6.6 白噪声

**白噪声**：功率谱是常数的随机过程。也就是说，所有频率的成分都一样多，就像白光包含所有颜色的光一样。

高斯白噪声：每个时刻的取值都服从高斯分布，且不同时刻独立。

在图像中，高斯噪声就是每个像素都加上一个独立的高斯随机数。

# 第二篇：大气湍流物理篇——为什么透过空气看东西会模糊？

## 第7章：生活中的湍流现象

### 7.1 你一定见过的现象

回想一下这些场景：
- 夏天中午，看远处的马路，路面上方的空气好像在"抖动"
- 看篝火上方的景物，会扭曲变形
- 星星会"眨眼"（闪烁）
- 透过热油锅上方看东西，模模糊糊的

这些都是**大气湍流**造成的。

### 7.2 什么是湍流？

流体（空气、水等）的流动有两种状态：
- **层流**：流体一层一层地、平稳地流动，互不混合。比如慢慢打开水龙头，水流很平顺。
- **湍流**：流体混乱地、不规则地流动，有很多漩涡。比如打开水龙头到最大，水花四溅。

大气通常处于湍流状态，因为：
1. 太阳照射地面，地面受热不均，造成空气对流
2. 风吹过建筑物、山丘，产生漩涡
3. 温度差异导致密度差异，引发流动

### 7.3 湍流的特点

1. **随机性**：湍流是混乱的、不可精确预测的，只能用统计学描述
2. **多尺度**：大漩涡里有小漩涡，小漩涡里有更小的漩涡，一直到分子尺度
3. **能量级联**：大漩涡的能量逐渐传递给小漩涡，最后变成热量
4. **时空变化**：湍流随时间和空间不断变化

这些特点决定了大气湍流对图像的影响是复杂的、随机的、时空变化的。

---

## 第8章：光的传播与折射

### 8.1 光沿直线传播？

初中物理说"光沿直线传播"，但这有个前提：**在均匀介质中**。

如果介质不均匀，光就会拐弯，这叫做**折射**。

最常见的例子：把筷子插入水中，看起来筷子"断了"。这就是因为水和空气的折射率不同，光在界面处发生了折射。

### 8.2 折射率

**折射率n**：描述光在介质中传播速度的物理量。

```
n = c / v
```

其中c是真空中的光速（约3×10⁸ m/s），v是光在介质中的速度。

- 真空：n = 1
- 空气：n ≈ 1.0003（接近1，但略大于1）
- 水：n ≈ 1.33
- 玻璃：n ≈ 1.5

折射率越大，光在其中传播越慢。

### 8.3 空气的折射率和什么有关？

空气的折射率不是固定的，它和以下因素有关：
1. **温度**：温度越高，空气密度越小，折射率越小
2. **气压**：气压越高，空气密度越大，折射率越大
3. **湿度**：水汽含量也会影响折射率

在大气中，温度的变化是影响折射率的主要因素。

**关键公式**（Gladstone-Dale关系）：

```
n - 1 = K · ρ
```

其中：
- n是折射率
- ρ是空气密度
- K是常数（约2.27×10⁻⁴ m³/kg）

所以：密度越大，折射率越大；温度越高，密度越小，折射率越小。

### 8.4 折射率随机波动如何影响光？

大气湍流造成温度的随机波动 → 密度的随机波动 → 折射率的随机波动。

折射率随机波动的结果：
1. 光在传播过程中，走的路径不是直线，而是弯弯曲曲的
2. 不同位置的光，偏转程度不一样
3. 到达相机时，光线的相位和方向都发生了随机变化

这就像：你透过一块凹凸不平的玻璃看东西，图像会扭曲变形。大气湍流就像一块"动态的、随机变化的凹凸玻璃"。

## 第9章：大气湍流如何让图像变形？

### 9.1 一个思想实验

想象你在看远处的一个点光源（比如一颗星星）。

如果没有大气湍流，这个点光源发出的光，经过相机镜头，会在传感器上形成一个完美的点（理想情况下）。

有了大气湍流呢？
1. 点光源发出的光，在传播过程中遇到折射率随机变化的空气
2. 不同光线的偏转程度不一样
3. 到达相机时，光线不再汇聚到同一个点
4. 结果：在传感器上形成一个模糊的光斑，而且这个光斑还在不断抖动

这就是**点扩散函数（PSF）**——一个点经过系统后变成了什么样。

### 9.2 两种效应：倾斜和模糊

大气湍流对图像的影响可以分成两种：

**1. 倾斜（Tilt）**：整幅图像或者局部区域发生平移/抖动
- 原因：大尺度的折射率波动，使整个波前发生倾斜
- 表现：图像在抖动，就像你拿着相机手在抖
- 特点：主要是几何畸变，不损失细节

**2. 模糊（Blur）**：图像细节丢失，变模糊
- 原因：小尺度的折射率波动，使波前发生高阶畸变
- 表现：图像变模糊，细节看不清
- 特点：损失了高频信息，无法通过简单平移恢复

**为什么要分开？** 因为这两种效应的性质完全不同，处理方法也不一样。TMT论文的核心思想之一就是"分而治之"——先去倾斜，后去模糊。

### 9.3 各向同性和各向异性

- **各向同性**：湍流的统计特性在各个方向都一样
- **各向异性**：不同方向的统计特性不一样

大气湍流通常假设是各向同性的（在水平方向上），这简化了数学处理。

### 9.4 等晕区（Isoplanatic Angle）

**等晕区**：在这个角度范围内，大气湍流的影响可以认为是一样的（PSF是空间不变的）。

等晕区的大小通常很小（约几个角秒），这意味着：
- 视场较大时，不同位置的PSF不一样
- 这就是"各向异性"（空间变化的模糊）
- 处理起来比空间不变的模糊困难得多

TMT论文处理的就是这种空间变化的湍流退化。

## 第10章：两种退化：几何畸变（倾斜）和模糊

### 10.1 倾斜（Tilt）的数学描述

倾斜就是像素的位移。对于图像中的每个位置(x, y)，都有一个位移量(u(x,y), v(x,y))。

退化模型：

```
I_turb(x, y) = I_clear(x + u(x,y), y + v(x,y))
```

意思是：湍流图在(x, y)处的像素，等于清晰图在(x+u, y+v)处的像素。

如果u和v是常数（整个图像平移一样多），就是全局倾斜。
如果u和v随位置变化，就是局部倾斜（空间变化的几何畸变）。

### 10.2 模糊（Blur）的数学描述

模糊就是卷积。

```
I_blur(x, y) = ∫∫ I_clear(u, v) · PSF(x-u, y-v) du dv
```

也就是：

```
I_blur = I_clear * PSF
```

如果PSF是空间不变的，就是普通卷积。
如果PSF随位置变化，就是空间变化卷积。

### 10.3 完整的湍流退化模型

TMT论文使用的退化模型是：

```
I(x, t) = [B ∘ T](J(x, t))
```

读作：先做倾斜变换T，再做模糊变换B。

展开写：

```
第一步（倾斜）：J_tilt(x, y, t) = J(x + u(x,y,t), y + v(x,y,t), t)
第二步（模糊）：I(x, y, t) = (J_tilt * PSF(x,y,t))(x, y)
```

其中：
- J是清晰图像
- T是倾斜变换（几何畸变）
- B是模糊变换（卷积）
- ∘表示复合运算（先T后B）
- I是湍流退化图像
- t是时间（视频的帧号）

### 10.4 为什么是"先倾斜后模糊"，而不是"先模糊后倾斜"？

这是一个物理问题，不是数学问题。

物理过程是：
1. 光从物体发出，先经过大气，发生折射（倾斜）
2. 然后大气中的小尺度湍流造成散射（模糊）
3. 最后到达相机

所以物理顺序是先倾斜后模糊。

而且，这两个操作**不可交换**：先倾斜后模糊 ≠ 先模糊后倾斜。

TMT论文引用了文献[18]专门讨论这个问题，证明了先倾斜后模糊的模型更符合物理实际。

### 10.5 为什么这个模型很重要？

因为这个模型决定了TMT的网络结构：
1. 既然退化分两步，那复原也分两步
2. 第一步：去倾斜（估计位移场，把像素移回去）
3. 第二步：去模糊（反卷积，恢复细节）

这就是TMT"两阶段设计"的物理基础。

## 第11章：Zernike多项式——给波前像差分类

### 11.1 什么是波前？

**波前（Wavefront）**：光传播过程中，相位相同的点组成的面。

理想情况下，点光源发出的光，波前是球面。经过理想透镜后，变成平面，然后完美聚焦到一个点。

如果有大气湍流，波前就会变形，不再是完美的平面/球面，这叫做**波前像差**。

### 11.2 为什么需要Zernike多项式？

波前像差是一个二维函数（描述每个位置的相位偏差）。我们需要一组"基函数"来描述它，就像用傅里叶级数描述周期函数一样。

**Zernike多项式**就是这样一组基函数，专门用来描述圆形孔径上的波前像差。

它的优点：
1. 正交性：不同模式之间互不干扰
2. 完备性：任何波前像差都可以用Zernike多项式的组合表示
3. 每个模式对应一种特定的像差，有明确的物理意义

### 11.3 低阶Zernike模式及其物理意义

前几个Zernike模式（按Noll编号）：

| 编号 | 名称 | 物理意义 |
|------|------|----------|
| 0 | 活塞（Piston） | 整体相位平移，不影响成像 |
| 1 | x方向倾斜（Tilt X） | 波前整体向x方向倾斜 |
| 2 | y方向倾斜（Tilt Y） | 波前整体向y方向倾斜 |
| 3 | 离焦（Defocus） | 像散焦一样，整体模糊 |
| 4 | 像散（Astigmatism） | 水平和垂直方向焦距不同 |
| 5 | 彗差（Coma） | 像彗星一样的拖尾 |
| 6 | 球差（Spherical） | 边缘和中心焦距不同 |
| 7+ | 更高阶像差 | 更复杂的畸变 |

### 11.4 关键洞察：前两阶就是倾斜！

注意看：
- Zernike模式1和2就是x方向和y方向的倾斜
- 模式3及以上是高阶像差（造成模糊）

这就是为什么大气湍流的影响可以分成"倾斜"和"模糊"两部分：
- **低阶Zernike（模式1、2）**→ 倾斜（几何畸变）
- **高阶Zernike（模式3+）**→ 模糊（高阶像差）

TMT论文的两阶段设计，本质上就是分别处理低阶和高阶Zernike模式造成的退化。

### 11.5 Zernike多项式的数学形式

Zernike多项式在极坐标(r, θ)下定义：

```
Z_n^m(r, θ) = R_n^m(r) · cos(mθ)   （m≥0）
Z_n^m(r, θ) = R_n^|m|(r) · sin(|m|θ)  （m<0）
```

其中径向部分：

```
R_n^m(r) = Σ_{s=0}^{(n-m)/2} (-1)^s · (n-s)! / [s! · ((n+m)/2 - s)! · ((n-m)/2 - s)!] · r^(n-2s)
```

看起来很复杂，但你不需要记住公式，只需要知道：
1. Zernike多项式是一组正交基
2. 低阶对应倾斜，高阶对应模糊
3. 任何波前像差都可以展开成Zernike多项式的和

### 11.6 波前像差和PSF的关系

波前像差和点扩散函数（PSF）之间有明确的数学关系：

```
PSF(x, y) = |F⁻¹[A(x, y) · e^(i·φ(x,y))]|²
```

其中：
- A是孔径函数（圆形孔径内为1，外为0）
- φ是波前像差（相位偏差）
- F⁻¹是逆傅里叶变换
- |·|²是取模平方

**直觉理解**：
- 波前越平（像差越小），PSF越集中，成像越清晰
- 波前越扭曲（像差越大），PSF越分散，成像越模糊

## 第12章：Kolmogorov湍流理论——大气的统计学规律

### 12.1 为什么需要统计学？

大气湍流是随机的，我们无法预测某一时刻某一位置的具体折射率。但我们可以研究它的**统计特性**——平均来说是什么样的。

Kolmogorov在1941年提出了湍流的统计学理论，这是大气光学的基础。

### 12.2 结构函数

**结构函数**描述空间中两点之间折射率的差异程度：

```
D_n(r) = E[(n(x) - n(x+r))²]
```

意思是：相距r的两个点，折射率差的平方的期望。

Kolmogorov理论给出：

```
D_n(r) = C_n² · r^(2/3)
```

其中：
- C_n²是大气折射率结构常数，描述湍流强度
- r是两点之间的距离
- 2/3是Kolmogorov幂律

**关键结论**：两点相距越远，折射率差异越大，而且是r^(2/3)的关系。

### 12.3 功率谱

对结构函数做傅里叶变换，得到折射率的功率谱：

```
Φ_n(κ) = 0.033 · C_n² · κ^(-11/3)
```

其中：
- κ是空间频率（波数）
- -11/3是Kolmogorov谱的幂律

**直觉理解**：
- 低频（大尺度）：功率大，能量多
- 高频（小尺度）：功率小，能量少
- 能量从大尺度向小尺度传递（能量级联）

### 12.4 Fried参数r0

**Fried参数r0**（也叫相干长度）是大气光学中最重要的参数之一。

它的物理意义：望远镜口径小于r0时，大气湍流的影响主要是倾斜；口径大于r0时，高阶像差开始显著。

r0的公式：

```
r0 = [0.423 · k² · sec(α) · ∫ C_n²(h) dh]^(-3/5)
```

其中：
- k = 2π/λ 是波数
- α是天顶角
- h是高度
- 积分是沿传播路径的

r0的特点：
- r0越大，大气越稳定，成像越好
- r0和波长有关：r0 ∝ λ^(6/5)，红外比可见光更容易成像
- 典型值：可见光下r0约5-20cm

### 12.5 格林伍德频率（Greenwood Frequency）

**格林伍德频率f_G**描述湍流随时间变化的快慢。

```
f_G = 2.31 · λ^(-6/5) · [sec(α) · ∫ C_n²(h) · v(h)^(5/3) dh]^(3/5)
```

其中v(h)是高度h处的风速。

物理意义：
- f_G越大，湍流变化越快
- 曝光时间小于1/f_G时，可以"冻结"湍流
- 典型值：约几十到几百Hz

### 12.6 外尺度和内尺度

Kolmogorov理论假设湍流是无限尺度的，但实际上：
- **外尺度L0**：最大的漩涡尺度，超过这个尺度，湍流不再是各向同性的
- **内尺度l0**：最小的漩涡尺度，小于这个尺度，粘性耗散起主导作用

在大多数大气光学问题中，外尺度约几米到几十米，内尺度约几毫米。

### 12.7 这些参数和图像质量的关系

| 参数 | 越大意味着 | 对图像的影响 |
|------|-----------|-------------|
| C_n² | 湍流越强 | 图像越模糊、抖动越厉害 |
| r0 | 大气越稳定 | 图像越清晰 |
| f_G | 湍流变化越快 | 需要更高帧率才能"冻结" |
| 传播距离 | 经过的大气越多 | 退化越严重 |

TMT论文的模拟器就是基于这些理论，生成不同强度、不同参数的湍流退化图像。

## 第13章：幸运成像——为什么多拍几张能变好？

### 13.1 一个有趣的观察

天文学家发现：在一系列短曝光照片中，偶尔会出现几张特别清晰的。这是为什么？

因为大气湍流是随机的，偶尔会出现湍流特别弱的瞬间，这时候拍的照片就特别清晰。

这就是**幸运成像（Lucky Imaging）**的基本思想。

### 13.2 幸运成像的原理

1. 拍摄大量短曝光图像
2. 对每张图像评分（比如用清晰度指标）
3. 选出最好的几张（比如前10%）
4. 把这些"幸运"的图像对齐后平均
5. 得到一张清晰的图像

### 13.3 为什么有效？

因为：
1. 湍流是随机的，总有一些瞬间湍流比较弱
2. 短曝光可以"冻结"湍流，避免运动模糊
3. 选出的清晰图像，信噪比更高
4. 多张平均可以进一步降低噪声

### 13.4 Fried 1978年的经典论文

TMT论文引用了Fried在1978年的论文《Probability of Getting a Lucky Short-Exposure Image》。

这篇论文计算了：在Kolmogorov湍流下，得到一张"幸运"图像的概率。

结论：
- 当望远镜口径D ≈ r0时，幸运成像的概率最大
- 口径越大，幸运概率越低（因为大口径受高阶像差影响更严重）
- 幸运成像可以显著提高图像分辨率

### 13.5 幸运成像的局限性

1. 需要大量图像（效率低，大部分图像被丢弃）
2. 对目标亮度要求高（短曝光需要足够的光）
3. 只能处理静态场景（目标不能动）
4. 提升有限（不能完全消除湍流影响）

### 13.6 从幸运成像到深度学习

幸运成像的思想启发了后来的很多方法：
1. 多帧融合：利用多帧信息复原图像
2. 选择最佳帧：不是简单平均，而是加权融合
3. 深度学习：用神经网络自动学习如何从多帧中提取信息

TMT论文就是用深度学习的方法，从一序列湍流图像中复原出清晰图像。它本质上也是在利用"多帧信息"，但比简单的幸运成像更强大。

# 第三篇：图像处理基础篇——传统方法怎么修图？

在深度学习出现之前，人们用传统的数学方法来处理图像退化。了解这些方法，能帮助你理解深度学习方法为什么有效、以及它解决了什么问题。

## 第14章：图像退化模型

### 14.1 一般退化模型

图像退化的一般模型：

```
g = f * h + n
```

其中：
- f 是清晰图像（我们想要的）
- h 是退化核（点扩散函数PSF）
- * 是卷积
- n 是噪声
- g 是退化图像（我们观测到的）

这是图像复原的基本方程。我们的目标是：已知g，估计f。

### 14.2 不同类型的退化

根据h的不同，退化可以分为：

1. **空间不变模糊**：h everywhere都一样，普通卷积
   - 例子：相机失焦、运动模糊
2. **空间变化模糊**：h随位置变化
   - 例子：大气湍流、广角镜头边缘
3. **几何畸变**：像素位置发生移动
   - 例子：湍流倾斜、镜头畸变
4. **噪声**：像素值被随机干扰
   - 例子：高斯噪声、泊松噪声

大气湍流是最复杂的情况：同时有空间变化模糊+几何畸变+噪声。

### 14.3 逆问题的病态性

图像复原是一个**逆问题**：已知输出g，求输入f。

逆问题通常是**病态的（ill-posed）**：
1. 解不唯一：多个f可能产生同一个g
2. 解不稳定：g的微小变化可能导致f的巨大变化
3. 可能无解：实际观测可能不完全符合模型

为什么会这样？因为模糊过程丢失了信息（高频成分被削弱了），丢失的信息无法完美恢复。

### 14.4 正则化

为了解决病态问题，需要引入**先验知识**，这叫做**正则化**。

常见的图像先验：
1. **平滑先验**：图像应该是平滑的（变化不大）
2. **稀疏先验**：图像的梯度（边缘）是稀疏的
3. **自然图像统计先验**：自然图像有特定的统计规律

正则化后的目标函数：

```
min_f ||g - f*h||² + λ·R(f)
```

其中：
- ||g - f*h||² 是数据项（要求复原结果和观测一致）
- R(f) 是正则项（要求复原结果符合先验）
- λ 是正则化参数，平衡两项的权重

---

## 第15章：图像去模糊：反卷积

### 15.1 什么是反卷积？

反卷积就是卷积的逆运算：已知模糊图g和模糊核h，求清晰图f。

### 15.2 直接逆滤波

最简单的方法：在频域直接相除。

```
F(f) = F(g) / F(h)
```

然后做逆傅里叶变换得到f。

**问题**：如果F(h)在某些频率接近0，除法会放大噪声，结果很差。

### 15.3 维纳滤波（Wiener Filter）

维纳滤波是逆滤波的改进，考虑了噪声：

```
F(f) = F(g) · F*(h) / (|F(h)|² + S_n/S_f)
```

其中：
- F*(h) 是F(h)的共轭
- S_n 是噪声功率谱
- S_f 是清晰图像功率谱

**直觉**：在h很小的频率（模糊严重的频率），降低增益，避免放大噪声。

维纳滤波是经典的去模糊方法，在已知模糊核和噪声统计时效果不错。

### 15.4 理查森-露西算法（Richardson-Lucy）

这是一种迭代的去模糊方法，基于贝叶斯估计。

迭代公式：

```
f^(k+1) = f^k · (g / (f^k * h)) * h_flip
```

其中h_flip是h的翻转。

特点：
1. 不需要知道噪声统计
2. 迭代次数越多，图像越锐利，但也可能出现噪声放大
3. 适合泊松噪声（如天文图像）

### 15.5 盲去卷积（Blind Deconvolution）

上面的方法都假设模糊核h已知。但实际中，h通常未知，这就是**盲去卷积**。

盲去卷积需要同时估计f和h，更困难。

常见方法：
1. 假设h的参数形式（如高斯模糊，估计方差）
2. 用自然图像先验约束f
3. 交替优化：固定h估计f，固定f估计h

### 15.6 大气湍流去模糊的特殊性

大气湍流的模糊是**空间变化**的，不同位置的PSF不一样，这比普通的空间不变模糊困难得多。

传统方法：
1. 把图像分成小块，假设每块内PSF不变（局部处理）
2. 用多帧信息估计空间变化的PSF
3. 结合图像配准和去模糊

这些方法计算量大，效果有限。深度学习方法（如TMT）就是为了解决这些问题。

---

## 第16章：图像配准：如何对齐两张图？

### 16.1 什么是图像配准？

图像配准就是找到两幅图像之间的对应关系，把它们对齐。

比如：你用手机拍了两张照片，手稍微抖了一下，两张图有点错位。配准就是把第二张图移动到和第一张图对齐。

### 16.2 配准的分类

根据变换的复杂度：

1. **平移**：只有x和y方向的位移（2个参数）
2. **刚体变换**：平移+旋转（3个参数）
3. **相似变换**：平移+旋转+缩放（4个参数）
4. **仿射变换**：线性变换+平移（6个参数）
5. **透视变换**：投影变换（8个参数）
6. **非刚性变换**：每个像素可以独立移动（光流）

大气湍流造成的倾斜通常是**非刚性变换**——不同位置的位移不一样。

### 16.3 基于块匹配的方法

最简单的配准方法：
1. 在第一张图中取一个小块
2. 在第二张图中搜索最相似的小块
3. 两块的位置差就是位移

相似度度量：
- 平方差之和（SSD）
- 绝对差之和（SAD）
- 归一化互相关（NCC）

### 16.4 基于相位相关的方法

利用傅里叶变换的平移性质：

如果f2(x,y) = f1(x-u, y-v)，那么：

```
F(f2) = F(f1) · e^(-i(ux+vy))
```

所以：

```
F(f2)/F(f1) = e^(-i(ux+vy))
```

相位相关就是利用这个性质来估计平移。

### 16.5 配准和去倾斜的关系

大气湍流的倾斜，本质上就是每帧图像都有一个空间变化的位移场。

去倾斜就是：
1. 估计每帧的位移场（配准）
2. 把像素移回去（重采样）

传统方法通常用光流来估计位移场，下一章详细讲。

---

## 第17章：光流：描述像素的运动

### 17.1 什么是光流？

**光流（Optical Flow）**：图像中每个像素的运动速度（位移）。

它是一个二维向量场：每个位置(x, y)都有一个速度向量(u(x,y), v(x,y))。

### 17.2 光流约束方程

光流的基本假设：**亮度恒定**——同一个物体点，在不同帧中的亮度不变。

数学表达：

```
I(x, y, t) = I(x+u, y+v, t+1)
```

对右边做泰勒展开（一阶近似）：

```
I(x+u, y+v, t+1) ≈ I(x,y,t) + I_x·u + I_y·v + I_t
```

其中：
- I_x = ∂I/∂x 是x方向梯度
- I_y = ∂I/∂y 是y方向梯度
- I_t = ∂I/∂t 是时间梯度

根据亮度恒定，左边等于右边，所以：

```
I_x·u + I_y·v + I_t = 0
```

这就是**光流约束方程**。

### 17.3 孔径问题

光流约束方程只有一个方程，但有两个未知数(u, v)，所以解不唯一。这叫做**孔径问题**。

直观理解：你透过一个小孔看一条移动的直线，只能看到垂直于直线方向的运动，看不到沿直线方向的运动。

### 17.4 Horn-Schunck方法

为了解决孔径问题，Horn和Schunck在1981年提出了一个经典方法，引入**平滑约束**：光流场应该是平滑的（相邻像素的运动相似）。

目标函数：

```
min_{u,v} ∫∫ [(I_x·u + I_y·v + I_t)² + α·(||∇u||² + ||∇v||²)] dx dy
```

其中：
- 第一项是光流约束（数据项）
- 第二项是平滑约束（正则项）
- α是正则化参数

这是一个变分问题，可以用欧拉-拉格朗日方程求解，或者迭代求解。

### 17.5 Lucas-Kanade方法

另一种经典方法，假设局部区域内光流是常数。

在一个小窗口内，所有像素满足同一个(u, v)，这样就有多个方程，可以用最小二乘求解。

### 17.6 深度学习光流

传统光流方法计算慢、精度有限。后来出现了基于深度学习的光流方法：
- FlowNet（2015）：第一个端到端的光流网络
- PWC-Net（2018）：金字塔、变形、代价体
- RAFT（2020）：当前最好的光流方法之一

TMT论文没有直接用光流，而是用3D卷积来同时处理多帧的对齐。但理解光流的概念，有助于理解去倾斜模块在做什么。

### 17.7 光流和去倾斜

去倾斜模块的本质就是估计光流（位移场），然后把像素移回去。

但TMT没有显式地估计光流，而是用3D U-Net直接输出去倾斜后的图像。这是一种隐式的方法，更鲁棒。

## 第18章：多帧图像融合

### 18.1 为什么要用多帧？

单帧图像的信息有限，很多信息在退化过程中丢失了。但如果有多帧图像，虽然每帧都退化了，但不同帧退化的方式不一样（因为湍流在变化），所以多帧合起来可能包含更多信息。

这就是多帧复原的基本思想。

### 18.2 简单平均

最简单的多帧融合：把所有帧对齐后取平均。

```
f_avg = (1/T) Σ I_t
```

优点：
- 简单
- 可以降低噪声（噪声平均后减小√T倍）

缺点：
- 如果对齐不准，平均会更模糊
- 不能恢复模糊丢失的细节
- 所有帧权重一样，没有利用"幸运帧"

### 18.3 加权平均

给不同帧不同的权重，清晰的帧权重大，模糊的帧权重小。

```
f_wavg = Σ w_t · I_t / Σ w_t
```

权重w_t可以根据图像清晰度来定。

这就是幸运成像的基本思想。

### 18.4 鲁棒融合

不是简单平均，而是用更鲁棒的统计量：
- 中位数：对异常值（特别差的帧）不敏感
- 截断平均：去掉最好和最差的，再平均

### 18.5 多帧超分辨率

如果多帧之间有亚像素位移，可以利用这些位移来恢复更高分辨率的图像。这叫做**多帧超分辨率**。

基本思想：
1. 多帧之间有微小位移
2. 这些位移提供了亚像素信息
3. 可以重建出比单帧分辨率更高的图像

### 18.6 多帧湍流复原

对于大气湍流，多帧复原尤其重要，因为：
1. 湍流随时间变化，不同帧退化不同
2. 可以利用时间维度的信息
3. 多帧平均可以降低随机抖动的影响

TMT论文就是处理12帧或20帧的输入，利用多帧信息来复原图像。

### 18.7 传统多帧方法的局限性

1. 依赖准确的配准（光流估计）
2. 对空间变化模糊处理困难
3. 计算量大
4. 效果有限

深度学习方法（如TMT）通过端到端学习，同时处理配准和去模糊，效果更好。

> **第三篇小结**
>
> 传统图像处理方法：
> 1. 图像退化模型：g = f*h + n，逆问题是病态的
> 2. 去模糊：反卷积、维纳滤波、RL算法、盲去卷积
> 3. 图像配准：对齐两张图，从平移到非刚性变换
> 4. 光流：描述像素运动，亮度恒定假设+平滑约束
> 5. 多帧融合：简单平均、加权平均、幸运成像
>
> 传统方法的问题：
> - 依赖准确的模型和参数估计
> - 对空间变化退化处理困难
> - 各步骤分开处理，误差累积
>
> 深度学习方法的优势：
> - 端到端学习，不需要显式建模
> - 可以处理复杂的空间变化退化
> - 数据驱动，从大量样本中学习规律
>

# 第四篇：深度学习基础篇——神经网络是怎么学习的？

## 第19章：什么是神经网络？（从一个神经元开始）

### 19.1 生物神经元的启发

人脑有大约860亿个神经元，每个神经元和其他神经元通过突触连接。神经元接收信号，处理后传递给下一个神经元。

人工神经网络就是受这个启发设计的。

### 19.2 一个人工神经元

一个人工神经元做三件事：
1. 接收输入 x1, x2, ..., xn
2. 每个输入乘以一个权重 w1, w2, ..., wn，加起来，再加上偏置b
3. 经过一个激活函数，输出

数学公式：

```
y = f(w1·x1 + w2·x2 + ... + wn·xn + b)
  = f(w·x + b)
```

其中：
- w是权重向量
- x是输入向量
- b是偏置（标量）
- f是激活函数
- y是输出

用矩阵写法更简洁：

```
y = f(Wx + b)
```

### 19.3 激活函数

激活函数给神经网络引入非线性。没有激活函数，多层网络就退化成一层线性变换。

常见激活函数：

**Sigmoid**：
```
f(x) = 1 / (1 + e^(-x))
```
输出在(0, 1)之间，适合表示概率。

**Tanh**：
```
f(x) = (e^x - e^(-x)) / (e^x + e^(-x))
```
输出在(-1, 1)之间。

**ReLU（Rectified Linear Unit）**：
```
f(x) = max(0, x)
```
负数变0，正数不变。最简单、最常用。

**GELU**：
```
f(x) = x · Φ(x)
```
其中Φ是标准正态分布的累积分布函数。比ReLU更平滑，在Transformer中常用。

### 19.4 多层神经网络

把很多神经元按层排列，就是多层神经网络。

- **输入层**：接收原始数据
- **隐藏层**：中间处理层，可以有很多层
- **输出层**：产生最终结果

**全连接层（Fully Connected Layer / Linear Layer）**：
每个输入和每个输出都相连。

```
y = Wx + b
```

其中W是权重矩阵，形状是(输出维度, 输入维度)。

### 19.5 神经网络能做什么？

**万能近似定理**：一个有足够多隐藏神经元的单隐藏层神经网络，可以近似任何连续函数。

这意味着：理论上，神经网络可以学会任何输入到输出的映射，只要给它足够多的神经元和数据。

图像复原就是一个映射：输入退化图像，输出清晰图像。神经网络可以学习这个映射。

### 19.6 神经网络怎么学习？——反向传播

神经网络的学习过程：

1. **前向传播**：输入数据，经过网络，得到输出
2. **计算损失**：比较输出和真实值，计算误差
3. **反向传播**：从输出层往回，计算每个参数对损失的梯度
4. **参数更新**：用梯度下降更新权重和偏置

重复这个过程很多次，网络就逐渐学会了正确的映射。

**反向传播的本质**：链式法则。损失对某层参数的梯度 = 损失对输出的梯度 × 输出对参数的梯度。

## 第20章：卷积神经网络（CNN）

### 20.1 为什么需要卷积？

全连接层处理图像有问题：
1. 参数太多：一张256×256的图有65536个像素，如果隐藏层也是65536，权重矩阵就是65536×65536，约40亿个参数
2. 没有利用空间结构：图像中相邻像素是相关的，全连接层忽略了这一点

卷积神经网络（CNN）用卷积代替全连接，解决了这些问题。

### 20.2 卷积层

卷积层就是用卷积核对输入做卷积（第5章讲过）。

关键概念：
- **卷积核（Kernel/Filter）**：小的权重矩阵，比如3×3
- **步长（Stride）**：卷积核每次移动多少像素
- **填充（Padding）**：在输入边缘补0，控制输出大小
- **输出通道（Output Channels）**：用多少个卷积核，每个核产生一个通道

输出大小计算：
```
输出大小 = (输入大小 - 核大小 + 2×填充) / 步长 + 1
```

### 20.3 卷积的优势

1. **参数共享**：同一个卷积核在整个图像上滑动，参数大大减少
2. **局部连接**：每个输出只和输入的局部区域有关，符合图像的局部相关性
3. **平移等变性**：输入平移，输出也相应平移

### 20.4 池化层（Pooling）

池化层降低特征图的大小，减少计算量，同时增加感受野。

**最大池化（Max Pooling）**：取窗口内的最大值
**平均池化（Average Pooling）**：取窗口内的平均值

比如2×2最大池化，步长2：把2×2的区域变成1个像素（取最大值），大小减半。

### 20.5 经典CNN结构

**LeNet（1998）**：最早的CNN之一，用于手写数字识别
**AlexNet（2012）**：深度学习爆发的标志，8层，ImageNet冠军
**VGG（2014）**：用连续的3×3卷积代替大卷积核，16-19层
**ResNet（2015）**：残差连接，解决深层网络退化问题，可以训练上百层

### 20.6 残差连接（Residual Connection）

ResNet的核心创新：

```
输出 = 输入 + F(输入)
```

其中F是卷积层的变换。

为什么有用？
1. 缓解梯度消失：梯度可以直接通过残差连接回传
2. 更容易训练：网络只需要学习"残差"（输入和输出的差），而不是完整的映射
3. 可以训练更深的网络

残差连接在几乎所有现代网络中都有，包括TMT。

### 20.7 归一化层

**Batch Normalization（BN）**：对每个batch的数据做归一化，加速训练，稳定分布。

**Layer Normalization（LN）**：对每个样本的特征做归一化，在Transformer中常用。

**Group Normalization（GN）**：把通道分组，每组内做归一化，对batch size不敏感。

## 第21章：U-Net结构——图像处理的万能骨架

### 21.1 U-Net是什么？

U-Net是2015年提出的，最初用于医学图像分割，现在几乎是所有图像到图像任务的标准骨架。

它的形状像字母"U"，所以叫U-Net。

### 21.2 U-Net的结构

U-Net由三部分组成：

1. **编码器（Encoder/下采样路径）**：
   - 逐步降低特征图的空间分辨率
   - 逐步增加通道数
   - 提取抽象的、高层的特征
   - 通常用卷积+池化/步长卷积实现

2. **瓶颈层（Bottleneck）**：
   - 最底层，分辨率最低，通道数最多
   - 最抽象的特征表示

3. **解码器（Decoder/上采样路径）**：
   - 逐步恢复空间分辨率
   - 逐步减少通道数
   - 用转置卷积或插值上采样
   - 和编码器对应层有**跳跃连接（Skip Connection）**

### 21.3 跳跃连接

U-Net的关键设计：编码器的每一层特征，直接拼接到解码器对应层。

```
解码器第i层 = 上采样(解码器第i+1层) ⊕ 编码器第i层
```

其中⊕是拼接（在通道维度）。

为什么有用？
1. 编码器的低层特征包含细节（边缘、纹理），解码器需要这些细节来恢复清晰图像
2. 缓解梯度消失
3. 保留多尺度信息

### 21.4 为什么U-Net适合图像复原？

图像复原是"输入图像，输出图像"的任务，需要：
1. 理解图像的整体内容（编码器的高层特征）
2. 恢复精细的细节（解码器+跳跃连接的低层特征）

U-Net正好满足这两点，所以成为图像复原（去模糊、去噪、超分）的标准骨架。

### 21.5 U-Net的变体

- **3D U-Net**：用3D卷积处理视频/体数据
- **U-Net++**：更复杂的跳跃连接
- **Attention U-Net**：在跳跃连接中加入注意力
- **Transformer U-Net**：用Transformer代替卷积

TMT的去倾斜模块用的是**3D U-Net**（处理多帧视频），去模糊模块用的是**U形Transformer**（U-Net结构+Transformer块）。

## 第22章：损失函数——告诉网络"哪里错了"

### 22.1 什么是损失函数？

损失函数（Loss Function）衡量网络输出和真实值之间的差距。

训练的目标就是**最小化损失函数**。

### 22.2 L1损失（平均绝对误差）

```
L1 = (1/N) Σ |y_pred - y_true|
```

特点：
- 对异常值不敏感
- 输出更鲁棒
- 梯度恒定，不会梯度消失

### 22.3 L2损失（均方误差）

```
L2 = (1/N) Σ (y_pred - y_true)²
```

特点：
- 对大误差惩罚更重
- 输出更平滑
- 梯度随误差减小而减小，可能梯度消失

### 22.4 L1 vs L2

| 特性 | L1 | L2 |
|------|----|----|
| 异常值鲁棒性 | 好 | 差 |
| 输出平滑度 | 较锐利 | 较平滑 |
| 梯度特性 | 恒定 | 随误差减小 |
| 解的唯一性 | 不唯一 | 唯一 |

在图像复原中，L1通常比L2效果好，因为L2容易产生过平滑的结果。

### 22.5 Charbonnier损失（重点！TMT用的就是这个）

Charbonnier损失是L1损失的平滑版本：

```
L_char = (1/N) Σ √((y_pred - y_true)² + ε²)
```

其中ε是一个小常数（比如1e-3）。

特点：
1. 在误差大的时候，近似L1损失（鲁棒）
2. 在误差接近0的时候，近似L2损失（平滑，可导）
3. 处处可导，没有L1在0点的不可导问题

这就是TMT论文使用的损失函数！它结合了L1和L2的优点。

### 22.6 感知损失（Perceptual Loss）

L1/L2只比较像素值，没有考虑语义内容。感知损失用预训练的VGG网络提取特征，在特征空间比较。

```
L_perceptual = ||VGG(y_pred) - VGG(y_true)||²
```

特点：
- 结果在视觉上更真实
- 可能引入伪影
- 计算量更大

### 22.7 对抗损失（Adversarial Loss）

用GAN的判别器来判断输出是真还是假，让生成器输出更真实的图像。

```
L_adv = -log(D(y_pred))
```

其中D是判别器。

### 22.8 SSIM损失

SSIM（结构相似性）是一种图像质量评估指标，也可以作为损失函数。

```
L_SSIM = 1 - SSIM(y_pred, y_true)
```

SSIM考虑亮度、对比度、结构三个方面，比L1/L2更符合人眼感知。

### 22.9 多尺度损失

TMT使用**多尺度损失**：在不同分辨率的特征图上都计算损失。

```
L_total = Σ γ_ℓ · L_char(Ĵ_ℓ, J̃_ℓ)
```

其中：
- ℓ是尺度（从粗到细）
- γ_ℓ是该尺度的权重
- Ĵ_ℓ是网络在该尺度的输出
- J̃_ℓ是清晰图在该尺度的下采样

TMT的权重设置：γ1=0.6, γ2=0.3, γ3=0.1（粗尺度权重更大）

为什么有用？
1. 粗尺度更容易学习，提供稳定的梯度
2. 细尺度学习细节
3. 保证不同尺度的一致性

## 第23章：优化器——网络怎么"改错"

### 23.1 梯度下降

最基本的优化方法：沿着损失函数的梯度反方向更新参数。

```
θ_new = θ_old - η · ∇L(θ)
```

其中：
- θ是参数
- η是学习率
- ∇L是损失对参数的梯度

### 23.2 随机梯度下降（SGD）

每次只用一个样本（或一个小batch）计算梯度，而不是全部数据。

优点：
- 计算快
- 随机性有助于跳出局部最优

### 23.3 动量（Momentum）

SGD的改进，加入"惯性"：

```
v_t = β · v_{t-1} + ∇L(θ_t)
θ_{t+1} = θ_t - η · v_t
```

其中β是动量系数（通常0.9）。

特点：
- 加速收敛
- 减少震荡

### 23.4 Adam（重点！TMT用的就是这个）

Adam是目前最常用的优化器，结合了动量和自适应学习率。

```
m_t = β1 · m_{t-1} + (1-β1) · ∇L  （一阶矩，类似动量）
v_t = β2 · v_{t-1} + (1-β2) · (∇L)²  （二阶矩，类似RMSprop）
m_hat = m_t / (1-β1^t)  （偏差修正）
v_hat = v_t / (1-β2^t)  （偏差修正）
θ_{t+1} = θ_t - η · m_hat / (√v_hat + ε)
```

默认参数：β1=0.9, β2=0.999, ε=1e-8

特点：
1. 每个参数有自适应的学习率
2. 收敛快
3. 对超参数不敏感

TMT论文使用的就是Adam优化器！

### 23.5 梯度的计算——反向传播

前面提到过，反向传播就是用链式法则计算损失对每个参数的梯度。

现代深度学习框架（PyTorch、TensorFlow）会自动计算梯度，你只需要定义前向传播，框架自动做反向传播。

---

## 第24章：学习率调度——让学习更高效

### 24.1 为什么需要学习率调度？

学习率太大：训练不稳定，损失震荡甚至发散
学习率太小：训练太慢，可能陷入局部最优

理想的学习率：开始大（快速收敛），后来小（精细调整）

### 24.2 常见的学习率调度

**StepLR**：每隔N个epoch，学习率乘以一个因子（比如0.1）

**CosineAnnealing**（余弦退火）：学习率按余弦函数从大到小变化

```
η_t = η_min + (η_max - η_min) · (1 + cos(π·t/T)) / 2
```

其中：
- η_max是初始学习率
- η_min是最小学习率
- t是当前迭代
- T是总迭代数

**Warmup**：训练开始时，学习率从很小逐渐增加到初始值，避免初期不稳定

### 24.3 TMT的学习率调度

TMT使用：
- 优化器：Adam
- 初始学习率：2e-4
- 最小学习率：1e-6
- 调度：余弦退火（SGDR，Stochastic Gradient Descent with Warm Restarts）

SGDR是余弦退火的变体，带有周期性重启：
- 每个周期，学习率从大到小余弦衰减
- 周期结束后，学习率重启到最大值
- 周期长度逐渐增加

这有助于跳出局部最优，找到更好的解。

### 24.4 分阶段训练

TMT采用分阶段训练：
1. **第一阶段**：训练去倾斜模块（400K迭代）
2. **第二阶段**：固定去倾斜模块，训练去模糊模块（600K迭代）

为什么分阶段？
1. 两阶段的目标不同，分开训练更稳定
2. 去倾斜是去模糊的前提，先学好去倾斜
3. 减少同时训练的参数量，降低难度

# 第五篇：Transformer基础篇——注意力机制的革命

Transformer是2017年提出的，最初用于自然语言处理，后来席卷了计算机视觉。TMT的核心就是Transformer的改进。

## 第25章：注意力机制的直觉（图书馆找书的比喻）

### 25.1 什么是注意力？

"注意力"这个词来自认知科学：人在看东西时，会把注意力集中在重要的部分，忽略不重要的部分。

比如你看一张人群照片，找你的朋友，你会把注意力集中在每张脸上，而不是背景的树木。

### 25.2 图书馆找书的比喻

想象你在图书馆找一本书：

1. **查询（Query）**：你心里想找"深度学习入门"这本书，这就是你的查询
2. **键（Key）**：每本书的书脊上都有书名，这就是键
3. **值（Value）**：书里面的内容，这就是值
4. **匹配**：你把你的查询和每本书的键（书名）比较，找到最匹配的那本
5. **读取**：你读取那本书的内容（值）

这就是注意力机制的基本思想！

### 25.3 注意力的数学表达

给定查询Q，以及一系列键值对(K, V)，注意力计算：

```
Attention(Q, K, V) = Σ α_i · V_i
```

其中α_i是第i个键和查询的相似度（注意力权重）：

```
α_i = softmax(score(Q, K_i))
```

score是相似度函数，最常用的是点积：

```
score(Q, K_i) = Q · K_i / √d
```

其中d是向量维度，除以√d是为了防止点积太大导致softmax饱和。

### 25.4 为什么注意力有用？

1. **动态权重**：每个输入的权重不是固定的，而是根据查询动态计算的
2. **全局感受野**：可以直接关注序列中任何位置，不像CNN只能看局部
3. **并行计算**：所有位置的注意力可以同时计算，不像RNN必须串行

---

## 第26章：自注意力的完整计算过程（四步法）

### 26.1 什么是自注意力？

自注意力（Self-Attention）就是Q、K、V都来自同一个输入序列。

比如输入是一个图像的特征序列，自注意力让每个位置都能关注到序列中所有其他位置。

### 26.2 四步法详解

假设输入是X，形状是(N, d)，其中N是序列长度，d是特征维度。

**第一步：生成Q、K、V**

用三个不同的线性变换（矩阵乘法）把输入变成Q、K、V：

```
Q = X · W_Q    形状：(N, d_k)
K = X · W_K    形状：(N, d_k)
V = X · W_V    形状：(N, d_v)
```

其中W_Q、W_K、W_V是可学习的权重矩阵。

直觉：
- Q是"我想找什么"
- K是"我有什么"
- V是"我的内容"

**第二步：计算注意力分数**

```
S = Q · K^T    形状：(N, N)
```

S[i, j]表示第i个查询和第j个键的相似度。

然后除以√d_k（缩放）：

```
S_scaled = S / √d_k
```

为什么要缩放？如果d_k很大，点积可能很大，softmax后梯度会很小（饱和）。除以√d_k可以缓解这个问题。

**第三步：Softmax归一化**

```
A = softmax(S_scaled, dim=1)    形状：(N, N)
```

对每一行做softmax，使得每行的和为1。

A[i, j]表示第i个位置对第j个位置的注意力权重。

**第四步：加权求和**

```
Output = A · V    形状：(N, d_v)
```

每个位置的输出是所有V的加权和，权重是注意力分数。

### 26.3 完整公式

把四步合起来：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) · V
```

这就是著名的**缩放点积注意力（Scaled Dot-Product Attention）**公式。

### 26.4 多头注意力（Multi-Head Attention）

单头注意力只有一组Q、K、V。多头注意力把特征分成h组，每组做一次注意力，最后拼起来。

```
MultiHead(Q, K, V) = Concat(head_1, head_2, ..., head_h) · W_O
```

其中每个head：

```
head_i = Attention(Q·W_Qi, K·W_Ki, V·W_Vi)
```

为什么多头？
1. 不同头可以关注不同的模式（比如一个头关注边缘，一个头关注纹理）
2. 增加模型的表达能力
3. 每个头的维度小，计算量可控

### 26.5 自注意力的复杂度

自注意力的计算量主要在QK^T，是O(N²·d)。

对于图像，如果把每个像素作为一个token，N = H×W，那么复杂度是O((HW)²·d)，非常大！

比如256×256的图，N=65536，N²≈43亿，根本算不动。

这就是为什么视觉Transformer需要各种优化（窗口注意力、下采样等），也是TMT提出TCJA的动机！

## 第27章：Transformer Block的完整结构

### 27.1 一个Transformer Block包含什么？

一个标准的Transformer Block有两个子层：

1. **多头自注意力（MHSA）**
2. **前馈网络（FFN）**

每个子层都有：
- 残差连接
- Layer Normalization

### 27.2 完整结构

```
输入 x
│
├─→ LayerNorm ─→ 多头自注意力 ─→ +（残差）─→ x1
│                                    │
└────────────────────────────────────┘
                                     │
├─→ LayerNorm ─→ 前馈网络 ─→ +（残差）─→ 输出
│                              │
└──────────────────────────────┘
```

用公式写：

```
x1 = x + MHSA(LN(x))
x_out = x1 + FFN(LN(x1))
```

这叫做**Pre-LN Transformer**（LayerNorm在子层前面）。

还有一种Post-LN：

```
x1 = LN(x + MHSA(x))
x_out = LN(x1 + FFN(x1))
```

现代Transformer通常用Pre-LN，因为训练更稳定。

### 27.3 前馈网络（FFN）

FFN就是两个全连接层，中间加激活函数：

```
FFN(x) = W2 · GELU(W1 · x + b1) + b2
```

通常中间层的维度是输入的4倍。

比如输入维度d=256，中间维度就是1024。

FFN的作用：对每个位置的特征做非线性变换，增加表达能力。

### 27.4 Layer Normalization

LayerNorm对每个样本的特征做归一化：

```
LN(x) = γ · (x - μ) / √(σ² + ε) + β
```

其中：
- μ是特征的均值
- σ²是特征的方差
- γ和β是可学习的参数（缩放和偏移）
- ε是小常数，防止除零

为什么用LayerNorm而不是BatchNorm？
- Transformer处理的序列长度可能不一样
- LayerNorm对每个样本独立归一化，不依赖batch size

### 27.5 位置编码（Positional Encoding）

自注意力本身是"置换不变"的——打乱输入顺序，输出也跟着打乱，但每个输出的值不变。

但序列的顺序很重要（比如图像的空间位置、语言的词序）。所以需要加入位置编码。

**正弦位置编码**（原始Transformer）：

```
PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
```

**可学习位置编码**：直接把位置编码作为可学习的参数。

**相对位置编码**：在注意力计算中加入相对位置信息。

现代视觉Transformer常用相对位置编码或可学习位置编码。

## 第28章：视觉Transformer（ViT）——把图像切成小块

### 28.1 ViT的基本思想

2020年提出的ViT（Vision Transformer）首次证明：纯Transformer也能做图像分类，而且效果很好。

基本思想：
1. 把图像切成固定大小的patch（比如16×16）
2. 每个patch拉平成一个向量
3. 加上位置编码
4. 输入标准Transformer编码器
5. 用 <[BOS_never_used_51bce0c785ca2f68081bfa7d91973934]> token的输出做分类

### 28.2 为什么要切patch？

因为如果每个像素是一个token，序列太长（256×256=65536），自注意力O(N²)算不动。

切成16×16的patch，256×256的图就变成16×16=256个token，N²=65536，就可以算了。

代价：patch内部的信息用线性投影处理，可能丢失细节。

### 28.3 ViT的结构

```
图像 (H×W×C)
    ↓ 切patch + 拉平
Patch序列 (N×(P²·C))
    ↓ 线性投影
Token序列 (N×D)
    ↓ 加位置编码 + <[BOS_never_used_51bce0c785ca2f68081bfa7d91973934]>
输入序列 ((N+1)×D)
    ↓ L层Transformer Block
输出序列 ((N+1)×D)
    ↓ 取<[BOS_never_used_51bce0c785ca2f68081bfa7d91973934]> token
分类头
    ↓
类别预测
```

### 28.4 ViT的优缺点

优点：
1. 全局感受野：每个token都能关注到所有其他token
2. 可扩展性：数据越多，效果越好
3. 统一架构：和NLP用一样的架构

缺点：
1. 需要大量数据：小数据集上不如CNN
2. 计算量大：自注意力O(N²)
3. 缺乏归纳偏置：不像CNN有局部性、平移等变性

### 28.5 ViT和图像复原

ViT主要用于分类。对于图像复原（需要输出图像），需要改造：
1. 不用<[BOS_never_used_51bce0c785ca2f68081bfa7d91973934]>，用所有token
2. 把token序列reshape回图像
3. 用U形结构（编码器-解码器）

后面的SwinIR、Restormer、VRT都是这样做的。

## 第29章：Swin Transformer——窗口注意力

### 29.1 为什么需要窗口注意力？

ViT把图像切成patch，但自注意力还是全局的，N²复杂度。如果patch小一点（比如4×4），N还是很大。

Swin Transformer（2021）提出**窗口注意力**：只在局部窗口内做自注意力。

比如窗口大小7×7，每个窗口内只有49个token，注意力复杂度大大降低。

### 29.2 滑动窗口机制

如果只在固定窗口内做注意力，窗口之间没有信息交互。Swin用**滑动窗口**解决：

1. 第1层：窗口在位置A
2. 第2层：窗口偏移半个窗口，在位置B
3. 这样相邻层的窗口有重叠，信息可以跨窗口传播

### 29.3 层级结构

Swin还有层级结构（类似CNN）：
1. 第1阶段：分辨率H/4×W/4
2. 第2阶段：分辨率H/8×W/8（下采样2倍）
3. 第3阶段：分辨率H/16×W/16
4. 第4阶段：分辨率H/32×W/32

每经过一个阶段，分辨率减半，通道数加倍。

这和CNN的下采样很像，提取多尺度特征。

### 29.4 SwinIR

SwinIR（2021）把Swin Transformer用于图像复原：
1. 浅层特征提取（卷积）
2. 深层特征提取（多个Swin Transformer Block + 残差）
3. 重建（卷积 + 上采样）

SwinIR在图像超分、去噪、去模糊上都取得了很好的效果。

### 29.5 窗口注意力的局限性

1. 窗口大小固定，不够灵活
2. 窗口边界可能有伪影
3. 跨窗口的信息传递需要多层

TMT的TCJA用了不同的思路：不在空间维度做注意力，而是在时间和通道维度做，完全避免了空间注意力的复杂度问题。

## 第30章：视频复原Transformer（VRT）

### 30.1 视频复原和图像复原的区别

视频复原处理的是多帧图像，需要：
1. 利用时间维度的信息
2. 处理帧间的运动
3. 保持时间一致性

### 30.2 VRT的结构

VRT（Video Restoration Transformer，2022）是视频复原的代表性工作。

结构：
1. **时间注意力**：在时间维度做自注意力，让每帧关注其他帧
2. **空间注意力**：在空间维度做窗口注意力
3. **变形对齐**：用可变形卷积对齐相邻帧
4. **多尺度结构**：类似U-Net的编码器-解码器

### 30.3 时间注意力

时间注意力就是把每一帧作为一个token，在时间维度做自注意力。

比如输入T帧，每帧的特征是H×W×C：
- 把每帧的特征平均池化，得到T个token
- 在T个token之间做自注意力
- 得到时间注意力后的特征

这样每帧都能利用其他帧的信息。

### 30.4 VRT的问题

VRT虽然效果好，但有一个问题：**计算量大**。

因为它同时有时间注意力和空间注意力，而且空间注意力是窗口注意力，还是有一定复杂度。

对于高分辨率视频，VRT的显存占用很大。

### 30.5 TMT和VRT的关系

TMT是在VRT之后提出的，针对VRT的问题做了改进：

1. **TCJA**：不在空间维度做注意力，只在时间和通道维度做，大大降低显存
2. **两阶段设计**：先去倾斜，后去模糊，物理驱动
3. **更多帧输入**：因为显存小了，可以输入更多帧（12帧甚至20帧）

TMT在论文中和VRT做了对比，效果更好，显存更小。

# 第六篇：TMT论文核心篇——这篇论文到底做了什么？

终于到了论文本身！前面五篇都是铺垫，现在我们来看看TMT（Turbulence Mitigation Transformer）的核心创新。

## 第31章：论文要解决什么问题？（研究动机）

### 31.1 大气湍流图像复原的挑战

回顾一下，大气湍流造成的退化有这些特点：
1. **空间变化**：不同位置的退化不一样（各向异性）
2. **时间变化**：每一帧的退化都不一样（湍流在动）
3. **两种退化混合**：既有倾斜（几何畸变），又有模糊（高阶像差）
4. **多帧信息**：视频有很多帧，需要利用时间维度

### 31.2 现有方法的问题

**传统方法**：
- 依赖准确的物理模型和参数估计
- 计算量大，速度慢
- 各步骤分开处理，误差累积

**深度学习方法（TMT之前）**：
- 大多是单阶段，同时处理倾斜和模糊，效果有限
- 用标准Transformer或CNN，显存占用大，只能输入少量帧
- 没有充分利用大气湍流的物理特性

### 31.3 TMT的三个核心贡献

论文提出了三个创新：

1. **物理驱动的两阶段设计**：
   - 把退化分解为倾斜和模糊，分别处理
   - 先去倾斜，后去模糊
   - 多尺度损失监督

2. **TCJA注意力机制**（Temporal-Channel Joint Attention）：
   - 时间-通道联合注意力
   - 不在空间维度做注意力，大大降低显存
   - 支持更多帧输入

3. **改进的湍流模拟器**：
   - Fourier采样器（密集场模拟）
   - 时间相关性（自回归模型）
   - 灵活核尺寸（9×9到33×33）

这三个创新加起来，让TMT在效果和效率上都超过了之前的方法。

---

## 第32章：核心思想1：两阶段设计（先去倾斜，后去模糊）

### 32.1 为什么要分两阶段？

回顾第二篇讲的退化模型：

```
I = [B ∘ T](J) = 模糊(倾斜(清晰图))
```

退化分两步：先倾斜，后模糊。

那么复原也应该分两步：
1. **第一步**：去倾斜（逆操作T⁻¹），把像素移回正确位置
2. **第二步**：去模糊（逆操作B⁻¹），恢复细节

这就是"分而治之"的思想。

### 32.2 单阶段 vs 两阶段

**单阶段**：一个网络直接从湍流图输出清晰图
- 问题：网络需要同时学习去倾斜和去模糊，任务太难
- 结果：容易顾此失彼，效果有限

**两阶段**：
- 阶段1：专门去倾斜，输出去倾斜后的图像
- 阶段2：专门去模糊，输入是去倾斜后的图像
- 优势：每个阶段任务明确，更容易学习

### 32.3 两阶段的物理基础

回顾Zernike多项式：
- 低阶模式（模式1、2）→ 倾斜
- 高阶模式（模式3+）→ 模糊

两阶段设计本质上就是分别处理低阶和高阶像差。

而且，倾斜主要是几何畸变（像素位移），模糊主要是卷积（细节丢失），两者的性质完全不同，用不同的网络处理更合理。

### 32.4 两阶段的训练策略

TMT采用分阶段训练：
1. **先训去倾斜模块**：400K迭代，batch size=4
2. **固定去倾斜模块，训去模糊模块**：600K迭代

为什么这样？
- 去倾斜是去模糊的前提，如果倾斜没去掉，去模糊也学不好
- 分开训练，每个阶段的优化目标更明确
- 减少同时训练的参数量，降低难度

### 32.5 消融实验验证

论文做了消融实验，证明两阶段比单阶段好：
- 两阶段比单阶段提升0.02~0.08 dB
- 这个提升虽然看起来不大，但在图像复原领域已经是显著提升了

## 第33章：去倾斜模块：轻量级3D U-Net

### 33.1 为什么用3D U-Net？

去倾斜需要处理多帧图像，而且需要估计空间变化的位移场。

**3D卷积**的优势：
1. 可以同时处理空间和时间维度
2. 不像光流只能两帧对齐，3D卷积可以同时对齐多帧
3. 端到端学习，不需要显式估计光流

**U-Net结构**的优势：
1. 编码器提取高层特征（理解全局运动）
2. 解码器恢复细节（精确的像素位移）
3. 跳跃连接保留多尺度信息

### 33.2 深度可分离3D卷积

普通3D卷积的参数量很大。TMT用**深度可分离3D卷积**来减少参数。

深度可分离卷积把普通卷积分成两步：
1. **深度卷积（Depthwise）**：每个通道单独做卷积
2. **逐点卷积（Pointwise）**：用1×1×1卷积混合通道

参数量对比：
- 普通3D卷积：K×K×K×C_in×C_out
- 深度可分离：K×K×K×C_in + C_in×C_out

对于典型参数（K=3, C_in=C_out=64）：
- 普通：3×3×3×64×64 = 110,592
- 深度可分离：3×3×3×64 + 64×64 = 1,728 + 4,096 = 5,824

参数减少了约19倍！

### 33.3 网络结构

去倾斜模块是一个轻量级的3D U-Net：
- 输入：T帧湍流图像，形状(B, 1, T, H, W)
- 编码器：3个下采样阶段，每个阶段有深度可分离3D卷积
- 解码器：3个上采样阶段，和编码器对应
- 输出：每个尺度的去倾斜图像估计

总参数量只有约63K（0.06M），非常轻量。

### 33.4 为什么去倾斜模块可以这么轻？

因为倾斜移除是一个相对简单的任务：
- 主要是几何变换（像素位移）
- 不需要恢复复杂的细节
- 多帧之间的运动有很强的相关性

所以用一个轻量级的网络就足够了，不需要复杂的Transformer。

### 33.5 多尺度输出

去倾斜模块在多个尺度上都有输出：
- 粗尺度（1/4分辨率）
- 中尺度（1/2分辨率）
- 细尺度（原始分辨率）

这是为了配合多尺度损失，下一章详细讲。

---

## 第34章：多尺度损失——粗到细的监督

### 34.1 为什么需要多尺度损失？

去倾斜是一个从粗到细的过程：
1. 先估计大的、全局的位移（粗尺度）
2. 再估计小的、局部的位移（细尺度）

如果只在细尺度监督，网络可能学不好，因为细尺度的位移太精细，容易出错。

多尺度损失在每个尺度都监督，让网络从粗到细逐步学习。

### 34.2 多尺度损失的公式

```
L_tilt = Σ_{ℓ=1}^{L} γ_ℓ · L_char(Ĵ_ℓ, J̃_ℓ)
```

其中：
- ℓ是尺度索引（从粗到细）
- γ_ℓ是该尺度的权重
- Ĵ_ℓ是网络在该尺度的输出
- J̃_ℓ是清晰图在该尺度的下采样
- L_char是Charbonnier损失

### 34.3 权重设置

TMT的权重设置：
- γ1 = 0.6（粗尺度，权重最大）
- γ2 = 0.3（中尺度）
- γ3 = 0.1（细尺度，权重最小）

为什么粗尺度权重更大？
1. 粗尺度的位移更结构化、更容易学习
2. 粗尺度学好了，细尺度才有好的基础
3. 避免网络过度关注细尺度的噪声

### 34.4 多尺度损失的好处

1. **梯度更稳定**：粗尺度提供稳定的梯度信号
2. **逐步求精**：从粗到细，符合人类学习的规律
3. **尺度一致性**：保证不同尺度的输出是一致的
4. **缓解梯度消失**：多层都有梯度回传

## 第35章：核心创新：TCJA注意力机制（时间-通道联合注意力）

这是TMT最重要、最核心的创新！一定要搞懂。

### 35.1 问题：标准自注意力太费显存

回顾第五篇讲的，标准自注意力的复杂度是O(N²·d)。

对于视频复原，输入是T帧，每帧H×W个像素，总token数N = T×H×W。

比如T=12, H=W=256：
- N = 12 × 256 × 256 = 786,432
- N² ≈ 6.18 × 10¹¹，这根本算不动！

即使下采样到H=W=64：
- N = 12 × 64 × 64 = 49,152
- N² ≈ 2.4 × 10⁹，还是太大

VRT等方法用窗口注意力缓解，但还是有复杂度问题，而且只能输入少量帧。

### 35.2 TMT的洞察：空间维度用卷积就够了

TMT的作者观察到：
1. **空间维度**：图像的局部相关性很强，用卷积就可以很好地处理局部交互
2. **时间维度**：湍流是随机变化的，需要全局的时间连接（所有帧之间都要交互）
3. **通道维度**：不同通道代表不同的特征，需要通道间的交互

所以，TMT的策略是：
- **空间维度**：纯用卷积（高效、局部感受野足够）
- **时间+通道维度**：用自注意力（全局交互）

这就是TCJA（Temporal-Channel Joint Attention）的核心思想！

### 35.3 TCJA的输入形状

假设输入特征形状是：(B, C, T, H, W)
- B：batch size
- C：通道数
- T：帧数
- H, W：空间高度和宽度

TCJA把空间维度H×W作为"batch"，在时间和通道维度做注意力。

也就是说，对于每个空间位置(h, w)，都有一个(C, T)的特征图，在这个特征图上做自注意力。

### 35.4 变体a：TMTa（分离时间和通道）

TMTa是比较简单的变体：

1. **时间注意力**：在时间维度做自注意力
   - 把每个通道的T帧作为token序列
   - Q, K, V形状：(B×H×W, C, T)
   - 注意力在T维度计算，复杂度O(T²·C)

2. **通道线性投影**：在通道维度做线性变换（不是注意力）
   - 用1×1卷积混合通道
   - 复杂度O(C²)

这样，总复杂度是O(T²·C + C²)，和空间维度H×W无关！

对比标准自注意力的O((T·H·W)²·C)，减少了(H·W)²倍！

比如H=W=256，减少了256⁴ ≈ 43亿倍！

### 35.5 变体b：TMTb（分组+通道混洗+联合注意力）

TMTb是更复杂、效果更好的变体，灵感来自ShuffleNet。

步骤：

1. **通道分组**：把C个通道分成G组，每组C/G个通道
2. **组内时间-通道联合注意力**：
   - 在每组内，把时间和通道维度合并，做自注意力
   - token数 = (C/G) × T
   - 复杂度O((C/G)²·T²)，因为分组了，所以可控
3. **通道混洗（Channel Shuffle）**：
   - 把不同组的通道打乱混合
   - 让信息在组间流动

### 35.6 通道混洗的作用

如果只分组不混洗，不同组之间没有信息交互，相当于多个独立的小网络。

通道混洗把通道重新排列，让下一层的每个组包含上一层不同组的通道，这样信息就跨组流动了。

这是ShuffleNet的核心思想，TMTb借用了这个设计。

论文实验表明，通道混洗带来了0.02~0.03 dB的提升。

### 35.7 TCJA的物理合理性

为什么TCJA有效？从物理角度看：

1. **空间局部性**：大气湍流的模糊是局部的（等晕区内PSF近似不变），所以卷积的局部感受野就够了
2. **时间全局性**：湍流是零均值随机过程，需要所有帧的信息来平均掉随机噪声，所以时间维度需要全局连接
3. **通道交互**：不同通道代表不同的特征（边缘、纹理、低频、高频等），需要通道间的交互来融合信息

TCJA的设计完全符合这些物理特性！

### 35.8 显存对比

论文给出了显存对比：
- 12帧256×256输入，标准自注意力需要约2304 GB显存（不可能）
- TCJA只需要约36 MB显存

减少了约65536倍！

这就是为什么TMT可以输入更多帧（12帧甚至20帧），而之前的方法只能输入4-8帧。

### 35.9 更多帧=更好效果

因为显存小了，TMT可以输入更多帧。

论文实验表明：
- 4帧 → 8帧 → 12帧 → 20帧，PSNR持续提升
- 20帧比4帧提升约0.5 dB

这是因为更多帧提供了更多信息，可以更好地平均掉随机湍流的影响。

## 第36章：去模糊模块：U形Transformer

### 36.1 整体结构

去模糊模块是一个U形结构（类似U-Net），但基本单元是Transformer Block（TCJA + Gated FFN）。

结构：
1. **浅层特征提取**：用卷积把输入映射到高维特征
2. **编码器**：多个Transformer Block + 下采样
3. **瓶颈层**：最底层的Transformer Block
4. **解码器**：多个Transformer Block + 上采样 + 跳跃连接
5. **重建层**：用卷积把特征映射回图像

### 36.2 空间维度纯用卷积连接

注意：在整个去模糊模块中，**空间维度的下采样和上采样都是用卷积实现的**，不是用注意力。

- 下采样：步长为2的卷积
- 上采样：转置卷积或插值+卷积
- 跳跃连接：直接拼接

只有Transformer Block内部用TCJA（时间+通道注意力），空间维度的信息流动靠卷积。

### 36.3 为什么这样设计？

1. **卷积处理空间局部交互**：高效、参数少、符合图像的局部相关性
2. **TCJA处理时间和通道全局交互**：捕捉湍流的动态变化和特征间的关系
3. **两者结合**：局部+全局，效率+效果

这就是TMT的设计哲学：**用对的工具做对的事**。

### 36.4 全时间连接

TCJA在时间维度是全连接的——所有帧之间都有注意力连接。

这很重要，因为大气湍流是一个零均值的随机过程：
- 每一帧的退化都是随机的
- 但平均起来，随机部分会抵消
- 全时间连接让网络可以利用所有帧的信息来"平均"掉随机噪声

这和幸运成像的思想是一致的，但TMT用注意力机制自动学习如何加权融合，比简单平均更强大。

### 36.5 参数量

TMTb的总参数量是26.04M，在图像复原网络中属于中等大小。

对比：
- VRT：约16M（但只能输入少量帧）
- SwinIR：约11M
- Restormer：约26M

## 第37章：Gated FFN——带门控的前馈网络

### 37.1 普通FFN的问题

普通的前馈网络（FFN）：

```
FFN(x) = W2 · GELU(W1 · x + b1) + b2
```

它对所有特征一视同仁，没有选择机制。

### 37.2 Gated FFN的结构

Gated FFN加入了门控机制：

```
GatedFFN(x) = (W1 · x) ⊙ GELU(W2 · x)
```

其中⊙是逐元素相乘。

直觉：
- W1·x 是"内容"路径
- GELU(W2·x) 是"门控"路径，决定哪些内容通过
- 两者相乘，门控控制内容的流量

### 37.3 为什么Gated FFN有用？

1. **动态选择**：不同输入、不同通道，门控的值不一样，可以动态选择重要的特征
2. **非线性更强**：门控引入了额外的非线性，增加表达能力
3. **训练更稳定**：门控可以防止梯度爆炸/消失

Gated FFN在很多现代Transformer中都有应用，比如Google的PaLM、Meta的LLaMA等大语言模型。

### 37.4 TMT中的Gated FFN

TMT的Transformer Block结构：

```
x1 = x + TCJA(LN(x))
x_out = x1 + GatedFFN(LN(x1))
```

和标准Transformer Block的区别就是把普通FFN换成了Gated FFN。

## 第38章：湍流模拟器改进（Fourier采样器+时间相关性+灵活核尺寸）

### 38.1 为什么需要好的模拟器？

深度学习需要大量训练数据，但真实的湍流图像很难获取（需要特定的拍摄条件、距离、天气）。

所以通常用**模拟器**生成合成的湍流退化图像，用合成数据训练网络。

模拟器的质量直接决定了网络的性能——如果模拟器和真实湍流不符，网络在真实数据上效果就差。

TMT对之前的湍流模拟器做了三点改进。

### 38.2 改进1：Fourier-based采样器

之前的方法：
- 用Zernike多项式模拟波前
- 问题：Zernike是稀疏的，需要插值才能得到密集的相位场，可能有混叠

TMT的方法：
- 直接在频域（Fourier域）采样
- 用Kolmogorov谱作为功率谱，生成随机相位屏
- 得到密集的相位场，不需要插值

优势：
1. 密集场模拟，更准确
2. 没有插值带来的混叠问题
3. 计算效率高

### 38.3 改进2：时间相关性

之前的方法：
- 每一帧的相位屏都是独立生成的
- 问题：真实湍流是有时间相关性的，帧与帧之间不是完全独立的

TMT的方法：
- 用自回归模型生成有时间相关性的相位屏：

```
w_t = α · w_{t-1} + √(1-α²) · z_t
```

其中：
- w_t是第t帧的相位屏（Fourier系数）
- α是相关系数（0.2~0.95）
- z_t是独立的高斯噪声

直觉：
- α越大，时间相关性越强，湍流变化越慢
- α越小，时间相关性越弱，湍流变化越快
- 这个公式保证了w_t的方差不变（平稳过程）

优势：
1. 更符合真实湍流的时间特性
2. 网络可以学习到时间相关性，更好地利用多帧信息

### 38.4 改进3：灵活核尺寸

之前的方法：
- PSF的核尺寸固定为33×33
- 问题：不同场景需要不同的核尺寸

TMT的方法：
- 核尺寸可以从9×9到33×33灵活选择
- 重新生成更高分辨率的基函数，避免混叠

为什么核尺寸重要？
- **静态场景**：窄视场，湍流影响范围大，需要大核（33×33）
- **动态场景**：宽视场，湍流影响范围小，需要小核（9×9）

灵活的核尺寸让模拟器可以适应不同场景。

### 38.5 模拟器的参数设置

TMT模拟器的参数：
- 湍流强度：弱/中/强三档，D/r0从0.001到0.2
- 传播距离：50~2000米
- 时间相关性：α从0.2到0.95
- 核尺寸：9×9到33×33
- 静态场景：核尺寸固定33，弱/中/强比例20%/40%/40%
- 动态场景：核尺寸9~33随机，弱/中/强比例33%/33%/33%

这些参数都是根据真实大气湍流的统计特性设置的。

### 38.6 好数据的重要性

TMT的成功，很大程度上归功于好的模拟器。

深度学习领域有句话："Garbage in, garbage out."（垃圾进，垃圾出）

如果训练数据的退化模式和真实情况不符，网络再强大也学不好。

TMT的模拟器改进，保证了训练数据的质量，这是它效果好的重要原因之一。

- 适合测试多帧复原的能力

## 第40章：训练策略（分阶段训练+数据增强）

### 40.1 分阶段训练

回顾一下，TMT采用分阶段训练：

**第一阶段：训练去倾斜模块**
- 迭代次数：400K
- Batch size：4
- 输入：T帧湍流图像
- 输出：去倾斜后的图像
- 损失：多尺度Charbonnier损失
- 优化器：Adam
- 学习率：2e-4 → 1e-6（余弦退火）

**第二阶段：训练去模糊模块**
- 迭代次数：600K
- Batch size：4
- 输入：去倾斜后的图像（固定去倾斜模块的参数）
- 输出：最终清晰图像
- 损失：Charbonnier损失
- 优化器：Adam
- 学习率：2e-4 → 1e-6（余弦退火）

### 40.2 数据增强

为了增加数据多样性，防止过拟合，TMT使用了多种数据增强：

1. **随机Gamma校正**：随机调整图像的Gamma值，改变对比度
2. **随机饱和度**：随机调整彩色图像的饱和度
3. **随机裁剪**：从图像中随机裁剪一块（训练时用小patch，测试时用全图）
4. **随机翻转**：水平/垂直翻转
5. **随机旋转**：90度、180度、270度旋转
6. **加噪声**：高斯噪声 N(0, βI)，β~uniform(0, 0.0004)

这些增强让网络见过更多样的图像，泛化能力更强。

### 40.3 输入帧数

训练时输入帧数：
- 静态场景：12帧
- 动态场景：12帧

测试时也可以用20帧，效果更好。

### 40.4 硬件要求

- GPU：NVIDIA RTX 3090（24GB显存）或更好
- 训练时间：约几天到一周
- 我们用的是RTX 3060 Laptop（12GB显存），可以跑测试，但训练可能比较慢

## 第41章：评估指标（PSNR、SSIM、LPIPS）

### 41.1 为什么需要多个指标？

图像质量评估是主观的，但我们需要客观指标来比较不同方法。

没有一个指标能完美反映人眼感知，所以通常用多个指标综合评估。

### 41.2 PSNR（峰值信噪比）

**最常用的图像质量指标**。

计算：
```
MSE = (1/N) Σ (y_pred - y_true)²
PSNR = 10 · log10(MAX² / MSE)
```

其中MAX是像素最大值（通常255）。

特点：
- 单位：dB（分贝）
- 越高越好
- 30dB以上：人眼几乎看不出区别
- 25-30dB：有可见差异，但质量尚可
- 20-25dB：质量较差
- 低于20dB：很差

优点：
- 简单、计算快
- 有明确的数学意义

缺点：
- 和人眼感知不完全一致
- 对平移、旋转敏感

### 41.3 SSIM（结构相似性）

**更符合人眼感知的指标**。

SSIM从三个方面比较图像：
1. **亮度（Luminance）**：均值的相似度
2. **对比度（Contrast）**：标准差的相似度
3. **结构（Structure）**：归一化后的相关性

公式：
```
SSIM = (2μ_xμ_y + C1)(2σ_xy + C2) / ((μ_x² + μ_y² + C1)(σ_x² + σ_y² + C2))
```

特点：
- 范围：0~1，越高越好
- 1表示完全相同
- 比PSNR更符合人眼感知

### 41.4 LPIPS（学习感知图像块相似度）

**基于深度学习的感知指标**。

用预训练的VGG/AlexNet提取特征，在特征空间计算距离。

特点：
- 越低越好（距离）
- 更符合人眼的感知相似度
- 计算量比PSNR/SSIM大

### 41.5 TMT用的指标

TMT论文用了三个指标：
- PSNR（越高越好）
- SSIM（越高越好）
- LPIPS（越低越好）

我们复现测试时也计算了这三个指标。

class TMT(nn.Module):
    def __init__(self, num_frames=12, channels=64):
        super().__init__()
        self.num_frames = num_frames
        
        # 阶段1：去倾斜模块（3D U-Net）
        self.tilt_removal = TiltRemoval(num_frames, channels)
        
        # 阶段2：去模糊模块（U形Transformer）
        self.deblur = DeblurUNet(num_frames, channels)
    
    def forward(self, x):

        # 阶段1：去倾斜
        x_tilt, multi_scale = self.tilt_removal(x)
        # x_tilt形状: (B, T, H, W)
        
        # 阶段2：去模糊
        out = self.deblur(x_tilt)
        # out形状: (B, H, W)
        
        return out, multi_scale

### 47.2 去倾斜模块（TiltRemoval）

```python
class TiltRemoval(nn.Module):
    def __init__(self, num_frames, channels):
        super().__init__()
        
        # 编码器（下采样）
        self.enc1 = DepthwiseSeparableConv3d(1, channels, kernel_size=3, padding=1)
        self.enc2 = DepthwiseSeparableConv3d(channels, channels*2, kernel_size=3, stride=2, padding=1)
        self.enc3 = DepthwiseSeparableConv3d(channels*2, channels*4, kernel_size=3, stride=2, padding=1)
        
        # 瓶颈层
        self.bottleneck = DepthwiseSeparableConv3d(channels*4, channels*4, kernel_size=3, padding=1)
        
        # 解码器（上采样）
        self.dec3 = nn.ConvTranspose3d(channels*4, channels*2, kernel_size=2, stride=2)
        self.dec2 = nn.ConvTranspose3d(channels*2, channels, kernel_size=2, stride=2)
        self.dec1 = nn.Conv3d(channels, 1, kernel_size=3, padding=1)
        
        # 多尺度输出头
        self.out3 = nn.Conv3d(channels*2, 1, kernel_size=1)
        self.out2 = nn.Conv3d(channels, 1, kernel_size=1)
    
    def forward(self, x):
        # x: (B, T, H, W) -> (B, 1, T, H, W)
        x = x.unsqueeze(1)
        
        # 编码器
        e1 = self.enc1(x)       # (B, C, T, H, W)
        e2 = self.enc2(e1)      # (B, 2C, T, H/2, W/2)
        e3 = self.enc3(e2)      # (B, 4C, T, H/4, W/4)
        
        # 瓶颈
        b = self.bottleneck(e3) # (B, 4C, T, H/4, W/4)
        
        # 解码器 + 跳跃连接
        d3 = self.dec3(b) + e2  # (B, 2C, T, H/2, W/2)
        d2 = self.dec2(d3) + e1 # (B, C, T, H, W)
        d1 = self.dec1(d2)      # (B, 1, T, H, W)
        
        # 多尺度输出
        out3 = self.out3(d3).squeeze(1)  # 粗尺度
        out2 = self.out2(d2).squeeze(1)  # 中尺度
        out1 = d1.squeeze(1)             # 细尺度
        
        return out1, [out3, out2, out1]
```

### 47.3 深度可分离3D卷积

```python
class DepthwiseSeparableConv3d(nn.Module):
    def __init__(self, in_channels, out_channels, kernel_size, stride=1, padding=0):
        super().__init__()
        # 深度卷积：每个通道单独卷积
        self.depthwise = nn.Conv3d(in_channels, in_channels, kernel_size, 
                                   stride=stride, padding=padding, groups=in_channels)
        # 逐点卷积：1x1x1卷积混合通道
        self.pointwise = nn.Conv3d(in_channels, out_channels, kernel_size=1)
    
    def forward(self, x):
        x = self.depthwise(x)
        x = self.pointwise(x)
        return x
```

### 47.4 TCJA（Temporal-Channel Joint Attention）

这是最核心的模块！

```python
class TCJA(nn.Module):
    def __init__(self, channels, num_frames, num_groups=4):
        super().__init__()
        self.channels = channels
        self.num_frames = num_frames
        self.num_groups = num_groups
        
        # TMTb：分组 + 通道混洗
        self.group_norm = nn.GroupNorm(num_groups, channels)
        
        # QKV投影
        self.qkv = nn.Conv2d(channels, channels * 3, kernel_size=1)
        
        # 输出投影
        self.proj = nn.Conv2d(channels, channels, kernel_size=1)
    
    def forward(self, x):
        # x形状: (B, C, T, H, W) -> 把空间作为batch
        B, C, T, H, W = x.shape
        
        # reshape: (B*H*W, C, T)
        x = x.permute(0, 3, 4, 1, 2).reshape(B*H*W, C, T)
        
        # 通道混洗
        x = self.channel_shuffle(x, self.num_groups)
        
        # 生成QKV
        qkv = self.qkv(x.unsqueeze(-1)).squeeze(-1)  # (B*H*W, 3C, T)
        q, k, v = qkv.chunk(3, dim=1)  # 每个都是 (B*H*W, C, T)
        
        # 时间-通道联合注意力
        # 把C和T合并作为token序列
        N = C * T
        q = q.reshape(B*H*W, N, 1)
        k = k.reshape(B*H*W, N, 1)
        v = v.reshape(B*H*W, N, 1)
        
        # 缩放点积注意力
        scale = N ** -0.5
        attn = (q @ k.transpose(-2, -1)) * scale  # (B*H*W, N, N)
        attn = attn.softmax(dim=-1)
        out = attn @ v  # (B*H*W, N, 1)
        
        # reshape回去
        out = out.reshape(B*H*W, C, T)
        out = self.proj(out.unsqueeze(-1)).squeeze(-1)
        
        # reshape回原始形状
        out = out.reshape(B, H, W, C, T).permute(0, 3, 4, 1, 2)  # (B, C, T, H, W)
        
        return out
    
    def channel_shuffle(self, x, groups):
        # x: (N, C, T)
        N, C, T = x.shape
        x = x.reshape(N, groups, C // groups, T)
        x = x.transpose(1, 2).reshape(N, C, T)
        return x
```

### 47.5 Gated FFN

```python
class GatedFFN(nn.Module):
    def __init__(self, channels, expansion=4):
        super().__init__()
        hidden = channels * expansion
        self.fc1 = nn.Conv2d(channels, hidden, kernel_size=1)
        self.fc2 = nn.Conv2d(channels, hidden, kernel_size=1)
        self.fc3 = nn.Conv2d(hidden, channels, kernel_size=1)
        self.act = nn.GELU()
    
    def forward(self, x):
        # x: (B, C, T, H, W)
        # 把T和空间合并做2D卷积
        B, C, T, H, W = x.shape
        x = x.reshape(B, C, T*H, W)
        
        # Gated FFN
        gate = self.act(self.fc1(x))
        content = self.fc2(x)
        out = self.fc3(gate * content)
        
        # reshape回去
        out = out.reshape(B, C, T, H, W)
        return out
```

### 47.6 Transformer Block

```python
class TransformerBlock(nn.Module):
    def __init__(self, channels, num_frames):
        super().__init__()
        self.norm1 = nn.LayerNorm(channels)
        self.attn = TCJA(channels, num_frames)
        self.norm2 = nn.LayerNorm(channels)
        self.ffn = GatedFFN(channels)
    
    def forward(self, x):
        # x: (B, C, T, H, W)
        # Pre-LN
        x = x + self.attn(self.norm1(x))
        x = x + self.ffn(self.norm2(x))
        return x
```

### 47.7 去模糊模块（DeblurUNet）

```python
class DeblurUNet(nn.Module):
    def __init__(self, num_frames, channels):
        super().__init__()
        
        # 浅层特征提取
        self.shallow = nn.Conv2d(num_frames, channels, kernel_size=3, padding=1)
        
        # 编码器
        self.enc1 = TransformerBlock(channels, num_frames)
        self.down1 = nn.Conv2d(channels, channels*2, kernel_size=3, stride=2, padding=1)
        
        self.enc2 = TransformerBlock(channels*2, num_frames)
        self.down2 = nn.Conv2d(channels*2, channels*4, kernel_size=3, stride=2, padding=1)
        
        # 瓶颈
        self.bottleneck = TransformerBlock(channels*4, num_frames)
        
        # 解码器
        self.up2 = nn.ConvTranspose2d(channels*4, channels*2, kernel_size=2, stride=2)
        self.dec2 = TransformerBlock(channels*2, num_frames)
        
        self.up1 = nn.ConvTranspose2d(channels*2, channels, kernel_size=2, stride=2)
        self.dec1 = TransformerBlock(channels, num_frames)
        
        # 重建
        self.recon = nn.Conv2d(channels, 1, kernel_size=3, padding=1)
    
    def forward(self, x):
        # x: (B, T, H, W)
        
        # 浅层特征
        feat = self.shallow(x)  # (B, C, H, W)
        
        # 编码器
        e1 = self.enc1(feat)
        e2 = self.down1(e1)
        e2 = self.enc2(e2)
        e3 = self.down2(e2)
        
        # 瓶颈
        b = self.bottleneck(e3)
        
        # 解码器 + 跳跃连接
        d2 = self.up2(b) + e2
        d2 = self.dec2(d2)
        d1 = self.up1(d2) + e1
        d1 = self.dec1(d1)
        
        # 重建
        out = self.recon(d1).squeeze(1)  # (B, H, W)
        
        return out
```

## 第48章：训练代码解读

### 48.1 训练去倾斜模块

```python
def train_tilt(model, dataloader, optimizer, scheduler, num_epochs):
    model.train()
    for epoch in range(num_epochs):
        for batch_idx, (imgs, gt) in enumerate(dataloader):
            imgs = imgs.cuda()  # (B, T, H, W)
            gt = gt.cuda()      # (B, H, W)
            
            # 前向传播
            _, multi_scale = model.tilt_removal(imgs)
            
            # 多尺度损失
            loss = 0
            weights = [0.6, 0.3, 0.1]  # 粗到细
            for i, (pred, weight) in enumerate(zip(multi_scale, weights)):
                # gt下采样到对应尺度
                gt_scaled = F.interpolate(gt.unsqueeze(1), size=pred.shape[-2:]).squeeze(1)
                # Charbonnier损失
                loss += weight * charbonnier_loss(pred, gt_scaled)
            
            # 反向传播
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            scheduler.step()
            
            if batch_idx % 100 == 0:
                print(f"Epoch {epoch}, Batch {batch_idx}, Loss: {loss.item():.4f}")
```

### 48.2 Charbonnier损失

```python
def charbonnier_loss(pred, target, eps=1e-3):
    return torch.mean(torch.sqrt((pred - target) ** 2 + eps ** 2))
```

### 48.3 训练去模糊模块

```python
def train_deblur(model, dataloader, optimizer, scheduler, num_epochs):
    # 固定去倾斜模块
    for param in model.tilt_removal.parameters():
        param.requires_grad = False
    
    model.train()
    for epoch in range(num_epochs):
        for batch_idx, (imgs, gt) in enumerate(dataloader):
            imgs = imgs.cuda()
            gt = gt.cuda()
            
            # 前向传播（去倾斜模块不更新梯度）
            with torch.no_grad():
                x_tilt, _ = model.tilt_removal(imgs)
            
            out = model.deblur(x_tilt)
            
            # Charbonnier损失
            loss = charbonnier_loss(out, gt)
            
            # 反向传播（只更新去模糊模块）
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            scheduler.step()
```

### 48.4 优化器和学习率调度

```python
optimizer = torch.optim.Adam(model.parameters(), lr=2e-4)

# 余弦退火学习率调度
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer, T_max=total_iters, eta_min=1e-6
)
```

def calculate_psnr(pred, target):
    mse = torch.mean((pred - target) ** 2)
    if mse == 0:
