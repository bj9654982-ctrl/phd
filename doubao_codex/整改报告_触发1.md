### 1. S1-A：实验不是盲复原，存在同场景清晰真值泄漏

**问题**："图像特定查找表"由待测图像的清晰图建立，再用同一清晰图合成模糊图并估计长度，属于循环验证和数据泄漏，不是真正盲复原。

**整改**：
- `项目总结.md`：全面重写，明确区分"已完成"和"原型/待验证"，撤回所有"0误差""严格单调""已验证创新"的表述，明确指出同图查表存在数据泄漏
- `06_实验与论文写作\论文大纲.md`：全面重写，在开头添加重要声明，Abstract/贡献/结论中所有结论标注"待独立实验验证"，明确区分"已观察"和"待验证假设"

### 2. S1-C：运动PSF长度定义不正确，"亚像素"声明不实

**问题**：原实现先把端点round为整数再调cv2.line，"亚像素抗锯齿"声明不实；整数舍入使奇数长度呈交替偏差；PSF实现变更后旧实验结果未全量重跑。

**整改**：
- `01_退化模型与评价指标\degradation_template.py`：`motion_blur_psf`函数改用**8倍超采样+平均池化下采样**方案。在8倍分辨率上画线段（LINE_8），再用8x8平均池化下采样，提供稳定的亚像素精度，所有角度一致，质心居中。长度明确定义为"线段两端点之间的几何距离（像素）"。
- 新增 `01_退化模型与评价指标\test_psf.py`：PSF单元测试，包含7项测试（能量守恒、质心居中、水平运动长度、运动方向、散焦PSF、高斯PSF、非法输入），**全部通过**。
- 新增 `01_退化模型与评价指标\regenerate_synthetic_blur.py`：用修复后的PSF重新生成所有12张合成模糊图，**已执行完成**。

**验证结果**：
```
✓ 能量守恒测试通过（所有PSF和为1）
✓ 质心居中测试通过
✓ 水平运动长度测试通过（非零支撑约等于请求长度）
✓ 运动方向测试通过（0°水平，90°垂直）
✓ 散焦模糊PSF测试通过
✓ 高斯模糊PSF测试通过
✓ 非法输入测试通过
```

### 3. S1-D：查找表插值建立在不存在的单调性上，含潜在未赋值错误

**问题**：`estimate_length_by_width`和`estimate_length_by_grad`假定序列单调，若非单调且测量值不落入任何区间，`estimated_length`可能未赋值即返回；`blind_restoration_template.py`中静默返回最短长度。

**整改**：
- `04_PSF估计\psf_estimation_template.py`：
  - 新增 `check_monotonic()` 函数，检查序列单调性并统计违例数
  - `estimate_length_by_width()`：添加单调性检查（verbose模式打印警告），初始化默认值防止未赋值，非单调时自动回退到最近邻估计
  - `estimate_length_by_grad()`：同样修复
- `05_完整盲复原流程\blind_restoration_template.py`：
  - `estimate_length_from_grad()`：添加单调性检查，非单调时回退到最近邻（不再静默返回最短长度）

### 4. S2-新增：浮点估计长度被int截断

**问题**：`blind_deblur`中用`int(estimated_length)`截断浮点估计长度，与"亚像素估计"表述不符，造成额外向下偏差。

**整改**：
- `05_完整盲复原流程\blind_restoration_template.py`：`blind_deblur`函数去掉`int()`截断，直接将浮点`estimated_length`传给`motion_blur_psf`（8倍超采样PSF支持亚像素浮点长度）。`kernel_size`改用`ceil(estimated_length)*2+1`。

### 5. S1-E：边缘方向理论写反

**问题**：`04_PSF估计\01_知识点.md`中写成"沿运动方向的边缘最宽，最宽边缘方向就是运动方向"。正确关系：过渡宽度由运动向量在**边缘法线**上的投影决定，边缘切线与运动垂直时过渡最宽。

**整改**：
- `04_PSF估计\01_知识点.md`：2.2节和2.3节全面重写，给出正确的几何关系公式 $L_{\text{eff}} = L \cdot |\cos(\alpha)|$，明确两种极端情况（平行/垂直），修正角度估计原理（最宽边缘的法线方向=运动方向），添加"原文档错误已修正"的说明。

### 6. S1-F：论文与项目状态过度陈述

**问题**：项目总结把00-06全部标记为完成，但真实模糊数据为空、阶段04结果为空、阶段06只有大纲无论文正文；论文大纲图像尺寸写455×539（实际512×512）。
