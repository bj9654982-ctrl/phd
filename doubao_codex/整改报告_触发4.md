## 一、已修复的问题

### 1. N4-02｜项目总结与实际实现状态不一致

**问题**：项目总结第113行仍写留一图像验证"未完成"，但实现文件和CSV已于随后生成。

**整改**：
- 项目总结P0列表第3项标记为✅已完成
- 添加留一验证结果：3场景、18退化条件、成功率33.3%、平均PSNR增益-1.62dB
- 添加结论：全局平均梯度特征不具备跨场景PSF可辨识性，降级为负面基线
- P0列表新增第8项：生成脚本失败时抛异常（已完成）

### 2. N4-01｜"真正独立验证"的措辞过强

**问题**：留一图像确实比循环验证严格，但方法设计、阈值和复原参数均可能受这3个场景启发，且没有外部锁定测试集。

**整改**：
- `psf_estimation_template.py`中所有"真正独立验证"改为"留一场景诊断性交叉验证 (Scene-wise Leave-One-Out)"
- 函数docstring和打印输出明确标注：场景级样本量仅为3，18个退化条件不独立，不宜称为最终独立验证
- `__main__`中调用措辞同步修正

### 3. N4-06｜"成功"定义过于宽松

**问题**：`better_than_input`仅比较是否大于0，forest长度4的+0.1087 dB被计为成功。

**整改**：
- `leave_one_image_out(success_threshold_db=0.5)`：新增成功阈值参数，默认+0.5dB
- 同时报告两种成功定义：`success_any_gain`（>0）和`success_gain_gt_0.5db`（>+0.5dB）
- 汇总统计新增PSNR增益分布：均值、中位数、标准差、最小、最大
- 新增分场景统计：每个场景的均值增益、中位数、通过数
- 验证结果：通过率（>+0.5dB）= 27.8%（5/18），比之前33.3%（>0）更严格

### 4. S1-05｜固定反卷积参数K=0.02使估计误差与复原器误差混杂

**问题**：无法判断PSNR下降是PSF估计错误、Wiener参数不适合，还是两者共同作用。

**整改**：
- `leave_one_image_out`新增真值PSF复原上界（oracle）：用真实PSF做维纳滤波，分离核估计损失与反卷积损失
- CSV新增字段：`oracle_psnr`、`oracle_ssim`、`oracle_gain`、`estimation_loss_db`
- **关键发现**：
  - 真值PSF上界平均增益：**+3.33 dB**（反卷积器本身有效）
  - 核估计平均损失：**4.95 dB**（PSF估计错误是质量下降主因）
  - 长度估计平均误差：6.51 px
- 结论：反卷积器没问题，问题全在PSF估计，进一步证实需要改用ESF/LSF方法

### 5. N4-03｜结果CSV缺少复现实验所需的关键字段

**问题**：LOO CSV缺角度真值/估计值、核相似度、真值PSF复原上界、SSIM、K的来源、随机种子等。

**整改**：
- CSV从11列扩展到28列，新增：
  - `true_angle`、`estimated_angle`、`angle_error`
  - `input_ssim`、`restored_ssim`、`ssim_gain`
  - `oracle_psnr`、`oracle_ssim`、`oracle_gain`、`estimation_loss_db`
  - `K_wiener`、`K_source`、`gradient_ratio`
  - `success_any_gain`、`success_gain_gt_0.5db`
- 注：运行ID、配置文件、输入哈希、代码版本等仍需建立不可覆盖的运行目录（列入P1）

### 6. S1-02｜论文题目中的"边缘过渡区/ESF-LSF"尚未成为可运行算法

**问题**：当前代码仍以整幅图像全局梯度统计为核心，未见完整的边缘方向估计、法向剖面配准、ESF聚合、LSF去噪/微分、PSF参数拟合链路。

**整改**：
- 新建 `04_PSF估计/esf_lsf_estimation.py`，实现ESF/LSF最小可行算法(MVP)框架：
  1. `detect_edges()`：Canny边缘检测
  2. `estimate_edge_orientation()`：Sobel梯度方向估计切线/法线
  3. `select_quality_edges()`：边缘质量筛选（梯度幅值+连通域长度）
  4. `sample_normal_profile()`：沿法线双线性插值采样剖面
  5. `aggregate_esf()`：亚像素对齐+稳健中位数聚合得到ESF
  6. `compute_lsf()`：中心差分+Tikhonov正则化平滑得到LSF
  7. `estimate_length_from_lsf()`：从LSF支撑范围/FWHM估计运动长度投影
  8. `esf_lsf_pipeline()`：完整流水线
  9. `test_on_synthetic()`：合成数据测试
- 验证：在building图上测试长度5/10/15/20，流水线运行成功，使用99个边缘段、500个剖面
- **MVP局限**：当前长度估计精度不足（投影宽度未随真实长度单调变化），需要按边缘方向分组+多方向联合估计，这是下一步改进重点
- 创新点空间：边缘质量筛选算法、亚像素ESF对齐、稳健聚合、正则化微分、多方向融合

## 二、留一验证改进后的完整结果

### 总体统计
| 指标 | 值 |
|------|-----|
| 退化条件总数 | 18（场景级样本量=3，不独立） |
| 失败数（增益<=0） | 12 |
| 失败数（增益<=+0.5dB） | 13 |
| 通过率（增益>+0.5dB） | **27.8%** |
| PSNR增益均值 | -1.62 dB |
| PSNR增益中位数 | -0.10 dB |
| PSNR增益标准差 | 4.54 dB |
| 真值PSF上界平均增益 | **+3.33 dB** |
| 核估计平均损失 | **4.95 dB** |
| 长度估计平均误差 | 6.51 px |

### 分场景统计
| 场景 | 均值增益 | 中位数 | 通过(>+0.5dB) |
|------|---------|--------|---------------|
| building | +1.24 dB | +1.74 dB | 4/6 |
| forest | -0.11 dB | -0.07 dB | 0/6 |
| professors | -5.99 dB | -6.61 dB | 1/6 |

### 核心诊断结论
1. **反卷积器有效**：真值PSF上界+3.33dB，说明维纳滤波+正确PSF可以显著提升质量
2. **PSF估计是瓶颈**：核估计平均损失4.95dB，说明质量下降全因PSF估计错误
3. **全局梯度不可辨识**：forest和professors完全失败，说明全局梯度特征受图像内容控制
4. **需要ESF/LSF**：局部边缘观测量可以分离图像内容与模糊核，是正确的技术方向
