## 常见问题

**Q: 运动模糊的线段画出来不对怎么办？**
A: 注意 x 和 y 的对应关系。在numpy数组中，第一个维度是行（y方向/垂直），第二个维度是列（x方向/水平）。角度0度应该是水平线。

**Q: SSIM算出来大于1或小于0怎么办？**
A: 检查C1和C2的计算，以及局部方差是否出现了负数（浮点误差）。可以用 np.maximum(sigma1_sq, 0) 确保非负。

**Q: PSNR算出来是inf怎么办？**
A: 两张图完全相同时MSE=0，PSNR为无穷大。代码里应该判断 if mse==0: return 100.0。

**Q: 卷积后图像边缘有黑边怎么办？**
A: 用 cv2.filter2D 时设置 borderType=cv2.BORDER_REFLECT 或 cv2.BORDER_REPLICATE。
