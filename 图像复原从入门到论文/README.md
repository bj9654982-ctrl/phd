## 核心方法（对应教材第6章）

```
模糊图 → 过渡区提取 → 清晰边缘预测 → PSF估计 → 非盲反卷积 → 清晰图
```

研究目标：只从图像边缘过渡区估计PSF，而非全图盲反卷积。当前状态：ESF/LSF方法原型已实现，解析测试和自然图像验证仍在进行中，方法有效性尚未最终确立。

3. 跑通后做小实验，记录结果
4. 每周结束写一段总结（遇到的问题、解决方法、下一步）
