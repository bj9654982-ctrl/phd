## Abstract（约250字，待独立实验验证后填写）
运动模糊是图像降质的常见原因，准确估计模糊核（PSF）是图像复原的关键。本文探索基于边缘过渡区特征的运动模糊参数估计方法，通过提取边缘法线方向的边缘扩散函数（ESF）和线扩散函数（LSF），建立边缘特征与PSF参数之间的映射关系。当前原型在3张测试图像（512×512）上的初步观察表明，在有同场景清晰参考的条件下，基于平均梯度的查找表法可以较准确地估计固定角度运动模糊的长度；但在无参考的通用场景下，方法对图像内容敏感，泛化能力不足。本文分析了该局限性的原因，并提出沿边缘法线采样ESF/LSF、多方向投影联合估计等改进方向。**（注：上述结论为原型观察，需独立测试验证后方可进入摘要）**

**关键词**：运动模糊；PSF估计；边缘扩散函数；图像复原；维纳滤波

## 1. Introduction
- 1.1 图像复原的背景和意义（医学影像、监控、摄影等应用）
- 1.2 盲图像复原的挑战（PSF未知、病态问题、解不唯一）
- 1.3 现有方法分类：
  - 基于迭代优化的盲反卷积（如RL盲反卷积、TV正则化盲复原）
  - 基于PSF估计的两阶段方法（先估计PSF再非盲反卷积）
  - 端到端深度学习方法（如DeblurGAN、SRN等）
- 1.4 本文动机：传统迭代方法收敛慢、易陷入局部最优；深度学习方法需要大量训练数据且可解释性差。基于边缘过渡区的方法具有计算简单、可解释性强的优势。
- 1.5 本文贡献（待独立实验验证后确认）：
  1. 探索基于过渡区特征的运动模糊长度估计方法（原型阶段）
  2. 分析全局梯度查表法的局限性：图像内容依赖、单调假设不成立、同图查表数据泄漏
  3. 提出改进方向：沿边缘法线采样ESF/LSF、多方向投影联合估计参数化运动核
  4. 实现完整的端到端复原流程（原型，待独立验证）

## 3. Methodology
### 3.1 退化模型
$$g(x,y) = f(x,y) * h(x,y) + n(x,y)$$
其中 g 是模糊图，f 是清晰图，h 是PSF，n 是噪声，* 是卷积。

### 3.2 过渡区提取（当前原型方法，待改进）
- 定义：图像中灰度从一个区域逐渐过渡到另一个区域的像素集合
- 当前提取方法：计算图像梯度幅值，梯度大于 max_gradient × ratio 的像素标记为过渡区
- 特征量化：
  - 过渡区宽度 W：过渡区内像素到最近非过渡区的平均距离 × 2
  - 过渡区平均梯度 Ḡ：过渡区内所有像素梯度的平均值
- **局限性**：全局阈值方法受纹理、对比度、边缘数量影响，不是逐边缘的ESF宽度

### 3.3 改进方向：逐边缘法线 ESF/LSF 提取（拟实现）
- 检测近似直、孤立、无遮挡、无饱和的边缘段，估计切线与法线方向
- 沿法线对齐采样并做亚像素binning，得到单调ESF
- 对ESF求导得到LSF，使用稳健拟合与质量评分
- 理想阶跃边缘经二维PSF模糊后，其LSF对应PSF沿边缘切线方向积分得到的一维投影（Radon投影）

### 3.4 基于平均梯度的PSF估计（当前原型，待验证）
- 核心假设（待验证）：运动模糊越重，过渡区平均梯度越小
- **当前观察**：该假设在部分图像上近似成立，但在所有测试图像上非严格单调
- 查找表法：
  1. 对已知清晰图，生成不同运动长度的模糊图
  2. 测量每张模糊图的过渡区平均梯度
  3. 建立"平均梯度 → 运动长度"的查找表
- 估计时：测量未知模糊图的平均梯度，在查找表中线性插值得到估计长度
- **数据泄漏问题**：图像特定查找表用待测图像的清晰图建立，不是真正盲复原

### 3.5 非盲反卷积
- 选择维纳滤波：
  $$\hat{F}(u,v) = \frac{H^*(u,v)}{|H(u,v)|^2 + K} G(u,v)$$
- 原因：维纳滤波对PSF估计误差鲁棒，计算效率高
- 参数：K≈0.009（同图调参，存在测试集调参问题），反射边界扩展消除振铃

### 3.6 完整复原流程
```
模糊图 → 过渡区提取 → 平均梯度测量 → 查找表估计PSF长度 → 生成PSF → 维纳滤波 → 复原图
```

### 4.7 局限性讨论
- 全局梯度查表法对图像内容敏感，不能分离内容与模糊核
- 核心单调假设在所有图像上不成立
- 同图查表存在数据泄漏，不是真正盲复原
- 仅支持固定角度运动模糊，未实现角度估计
- 数据规模小（3张图），泛化能力未验证
- 无真实模糊数据实验
- 缺少统计检验和置信区间

## 5. Conclusion（待独立实验验证后填写）
- 本文探索了基于过渡区平均梯度的运动模糊参数估计方法（原型阶段）
- **当前观察**：同图查表下估计精度较高，但存在数据泄漏；通用场景下方法对图像内容敏感，泛化能力不足
- 分析了局限性的原因：全局梯度统计无法分离内容与模糊核，单调假设不成立
- **未来工作**：
  1. 改用逐边缘法线ESF/LSF提取，建立PSF Radon投影模型
  2. 多方向边缘联合估计运动长度和角度
  3. 扩展到公开数据集和真实模糊数据，完成leave-one-image-out验证
  4. 添加基线对比、消融实验和统计检验
  5. 扩展到散焦模糊和复合模糊
