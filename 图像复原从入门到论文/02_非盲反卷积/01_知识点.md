# 第二阶段：非盲反卷积

> 学习目标：已知模糊核（PSF）时，掌握 3 种经典复原方法，能把第一阶段生成的模糊图恢复回来

---

## 一、什么是非盲反卷积？

### 1.1 回顾退化模型

$$g = f \otimes h + n$$

- $g$：模糊图像（已知）
- $h$：模糊核 PSF（**已知**，这就是"非盲"的含义）
- $f$：清晰图像（未知，要求解）
- $n$：噪声（未知）

**非盲反卷积**：已知 $g$ 和 $h$，求 $f$。

对比：
- **非盲反卷积**：PSF 已知 → 问题适定，有唯一解
- **盲反卷积**：PSF 未知 → 问题病态，解不唯一（这是第四阶段的内容）

### 1.2 为什么不能直接"反卷积"？

看起来很简单：$f = g \oslash h$（反卷积），但实际有两个致命问题：

1. **频域零点问题**：PSF 的傅里叶变换 $H(u,v)$ 在某些频率处可能为 0 或接近 0，直接除以 $H$ 会除以零或放大噪声
2. **噪声放大**：$G/H = F + N/H$，噪声 $N$ 被 $1/H$ 放大，高频噪声会被放得极大

所以必须加**正则化**（约束），在"拟合数据"和"解的合理性"之间找平衡。

## 二、方法一：维纳滤波（Wiener Filter）

### 2.1 原理

维纳滤波是**最小均方误差**意义下的最优线性复原。它在频域求解：

$$\hat{F}(u,v) = \left[ \frac{1}{H(u,v)} \cdot \frac{|H(u,v)|^2}{|H(u,v)|^2 + K} \right] G(u,v)$$

简化为：

$$\hat{F}(u,v) = \frac{H^*(u,v)}{|H(u,v)|^2 + K} \cdot G(u,v)$$

其中：
- $H(u,v)$：PSF 的傅里叶变换
- $H^*(u,v)$：$H$ 的复共轭
- $|H(u,v)|^2 = H \cdot H^*$：功率谱
- $K$：噪声信号比（NSR），正则化参数，控制噪声抑制强度

### 2.2 直观理解

看括号里的两项：
- $\frac{1}{H}$：直接反卷积（恢复模糊）
- $\frac{|H|^2}{|H|^2 + K}$：**抑制因子**，在 $H$ 小的频率（噪声容易放大的地方）压低增益

当 $K=0$ 时，抑制因子=1，退化为直接反卷积（噪声极大）
当 $K$ 很大时，抑制因子≈0，输出几乎为0（过度平滑）

**$K$ 的典型取值**：0.001 ~ 0.05，需要根据噪声水平调整。

### 2.3 优缺点

| 优点 | 缺点 |
|------|------|
| 计算快（一次FFT+一次IFFT） | $K$ 需要手动调，不同图最优值不同 |
| 有解析解，稳定 | 对强噪声效果有限 |
| 是其他方法的基线 | 可能过度平滑，丢失细节 |

## 三、方法二：Richardson-Lucy（RL）反卷积

### 3.1 原理

RL 反卷积是基于**最大似然估计**的迭代方法，假设噪声服从泊松分布（适合天文、荧光显微镜等光子计数成像）。

迭代公式：

$$f^{(k+1)} = f^{(k)} \cdot \left[ \frac{g}{f^{(k)} \otimes h} \otimes h^* \right]$$

其中 $h^*$ 是翻转后的 PSF（相关运算）。

### 3.2 迭代过程直观理解

1. 用当前估计 $f^{(k)}$ 和 PSF 卷积，得到"预测的模糊图"
2. 计算真实模糊图 $g$ 和预测模糊图的比值（相对误差）
3. 把这个比值反卷积（和翻转PSF相关），得到修正量
4. 用修正量乘以当前估计，得到新的估计 $f^{(k+1)}$

**核心思想**：每次迭代都让"预测模糊图"更接近"真实模糊图"，从而让 $f$ 更接近真实清晰图。

### 3.3 关键参数

- **迭代次数**：10~50次。太少复原不足，太多会放大噪声和振铃
- **初始值**：通常用模糊图本身或均匀灰度作为初始估计
- **PSF**：必须准确，PSF错了结果会很差

### 3.4 优缺点

| 优点 | 缺点 |
|------|------|
| 不需要手动调正则化参数 | 迭代慢（每次要2次卷积） |
| 非负约束天然满足（乘积形式） | 迭代次数需要调 |
| 对泊松噪声效果好 | 迭代过多会放大噪声 |
| 细节恢复比维纳滤波好 | 可能产生振铃伪影 |

## 四、方法三：总变分（TV）正则化反卷积

### 4.1 原理

TV 正则化的思想：**清晰图像的总变分（梯度绝对值之和）应该比较小**，因为清晰图大部分区域是平坦的，只有边缘处梯度大。

优化目标：

$$\min_f \|f \otimes h - g\|^2 + \lambda \cdot \text{TV}(f)$$

其中：
- 第一项：数据保真项（让复原图卷积后接近模糊图）
- 第二项：TV 正则项（惩罚总变分，鼓励分段平坦）
- $\lambda$：正则化权重，控制平滑强度

TV 的定义：

$$\text{TV}(f) = \sum_{x,y} \sqrt{(f_{x+1,y}-f_{x,y})^2 + (f_{x,y+1}-f_{x,y})^2}$$

### 4.2 为什么 TV 能保持边缘？

- 在**平坦区域**：梯度≈0，TV 惩罚小，允许平滑去噪
- 在**边缘区域**：梯度大，TV 惩罚是线性的（不像L2正则是二次的），不会过度惩罚边缘

所以 TV 正则化能在**去噪的同时保持边缘锐利**，这是它比维纳滤波好的地方。

### 4.3 求解方法

TV 优化问题没有解析解，通常用迭代方法求解：
- 梯度下降
- 分裂Bregman（Split Bregman）
- 交替方向乘子法（ADMM）
- Chambolle-Pock 算法

本阶段我们用 scikit-image 或 scipy 的现成实现，不自己推导优化算法。

## 五、振铃效应（Ringing Artifact）

### 5.1 什么是振铃？

反卷积后，图像边缘附近出现的**周期性条纹或振荡伪影**，像钟声的余振一样，所以叫振铃。

### 5.2 成因

1. **频域截断**：PSF 的高频分量被抑制，相当于理想低通滤波，阶跃边缘会产生 Gibbs 振荡
2. **PSF 不准确**：PSF 估计有误差，反卷积不能完全补偿
3. **边界不连续**：图像边界处灰度跳变，反卷积后边界处产生振荡

### 5.3 抑制方法

1. **边界扩展**：对图像四周做镜像/复制扩展，反卷积后裁掉边界（第一阶段代码已经用了 `BORDER_REFLECT`）
2. **正则化**：维纳滤波的 $K$、TV 的 $\lambda$ 都能抑制振铃
3. **迭代次数控制**：RL 反卷积不要迭代太多次
4. **PSF 精确估计**：PSF 越准，振铃越轻（第四阶段的内容）

## 六、三种方法对比

| 维度 | 维纳滤波 | RL反卷积 | TV正则化 |
|------|----------|----------|----------|
| 原理 | 最小均方误差 | 最大似然（泊松噪声） | 数据保真+TV正则 |
| 计算速度 | 快（1次FFT） | 中（迭代，每次2次卷积） | 慢（迭代优化） |
| 参数调节 | K（噪声比） | 迭代次数 | λ（正则权重） |
| 细节恢复 | 一般 | 好 | 好（边缘保持） |
| 噪声抑制 | 好 | 一般（迭代多了放大噪声） | 好 |
| 振铃 | 中等 | 较明显 | 较轻 |
| 适用场景 | 通用基线、快复原 | 天文、荧光显微 | 自然图像、文字 |
