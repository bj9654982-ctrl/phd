# 第五阶段：完整盲复原流程

> 这是整个项目的"收官"阶段。把前面四个阶段的所有模块串起来，实现端到端的盲图像复原：输入一张模糊图（PSF未知），输出复原图像。

---

## 一、完整盲复原流程

### 1.1 流程图

```
模糊图 g(x,y)
    │
    ▼
┌─────────────────────┐
│  第三阶段：过渡区提取  │  计算平均梯度 G_mean
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  第四阶段：PSF 估计    │  从 G_mean 查映射表 → 估计运动长度 L_est
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  第二阶段：非盲反卷积  │  用估计的 PSF 做维纳滤波/RL 反卷积
└─────────┬───────────┘
          │
          ▼
    复原图 f_est(x,y)
```

### 1.2 每个步骤的输入输出

| 步骤 | 输入 | 输出 | 对应阶段 |
|------|------|------|---------|
| 过渡区提取 | 模糊图 | 平均梯度 G_mean | 第三阶段 |
| PSF 估计 | G_mean + 查找表 | 估计的运动长度 L_est | 第四阶段 |
| 反卷积 | 模糊图 + 估计的PSF | 复原图像 | 第二阶段 |

### 1.3 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| gradient_ratio | 0.05 | 过渡区梯度阈值比例（第四阶段验证的最优值） |
| 估计方法 | 平均梯度法 | 比宽度法更鲁棒（第四阶段验证） |
| 反卷积方法 | 维纳滤波 | K=0.02，速度快、效果稳定 |
| 运动角度 | 固定 25° | 当前简化，后续可扩展角度估计 |

## 二、盲复原 vs 非盲复原

### 2.1 对比

| | 非盲复原 | 盲复原（本阶段） |
|---|---------|----------------|
| PSF 是否已知 | 已知 | 未知，需要估计 |
| 流程 | 模糊图 + PSF → 反卷积 → 复原 | 模糊图 → 估计PSF → 反卷积 → 复原 |
| 误差来源 | 只有反卷积误差 | PSF估计误差 + 反卷积误差 |
| 适用场景 | 实验室、PSF可标定 | 真实场景（手机拍照、监控等） |
| 复原效果上限 | 高（PSF准确） | 略低（PSF估计有误差） |

### 2.2 性能差距

盲复原的效果通常比非盲复原差一些，差距来自 PSF 估计误差：

$$\text{PSNR}_{\text{盲}} = \text{PSNR}_{\text{非盲}} - \Delta\text{PSNR}$$

其中 $\Delta\text{PSNR}$ 是 PSF 估计误差导致的 PSNR 下降。

- $\Delta\text{PSNR} < 0.5$ dB：估计非常准确，人眼几乎看不出区别
- $\Delta\text{PSNR} < 1$ dB：估计良好，区别很小
- $\Delta\text{PSNR} < 2$ dB：估计可用，有轻微区别
- $\Delta\text{PSNR} > 2$ dB：估计误差较大，需要改进

## 三、误差来源分析

### 3.1 PSF 估计误差

| 误差来源 | 原因 | 影响 |
|---------|------|------|
| 查找表离散化 | 查找表只有整数长度，估计值在两个条目之间插值 | 小（<0.5像素） |
| 图像内容差异 | 不同图像的过渡区特征不同，查找表不通用 | 中（需要通用查找表） |
| 梯度阈值选择 | threshold 太大或太小都会影响特征测量 | 小（0.05是经验值） |
| 噪声 | 噪声会干扰梯度测量 | 中（高噪声下误差增大） |

### 3.2 反卷积误差

| 误差来源 | 原因 | 影响 |
|------|------|------|
| 频域零点 | PSF的傅里叶变换有零点，信息永久丢失 | 大（无法恢复） |
| 噪声放大 | 反卷积会放大高频噪声 | 中（K参数控制） |
| 边界效应 | 图像边界的周期性假设导致振铃 | 小（反射padding缓解） |
| PSF不匹配 | 估计的PSF和真实PSF有差异 | 中（本阶段主要关注） |

## 四、评价方法

### 4.1 定量评价

| 指标 | 公式 | 含义 |
|------|------|------|
| PSNR | $10\log_{10}(255^2/\text{MSE})$ | 复原图和清晰图的峰值信噪比 |
| SSIM | 结构相似性 | 复原图和清晰图的结构相似度 |
| PSNR 下降 | $\text{PSNR}_{\text{非盲}} - \text{PSNR}_{\text{盲}}$ | PSF估计误差导致的性能损失 |

### 4.2 定性评价

- 人眼观察复原图是否清晰
- 边缘是否锐利
- 是否有振铃、伪影
- 和非盲复原对比，人眼能否看出区别

### 4.3 对比实验

| 对比项 | 说明 |
|--------|------|
| 模糊图 vs 盲复原 | 验证复原是否有效 |
| 盲复原 vs 非盲复原（真实PSF） | 量化PSF估计误差的影响 |
| 不同反卷积方法（维纳 vs RL） | 比较哪种方法更适合盲复原 |
| 不同图像 | 验证方法的泛化能力 |

## 六、方法的局限性

1. **只支持运动模糊**：当前只估计运动长度，散焦模糊和高斯模糊需要扩展
2. **角度固定**：当前运动角度固定为25°，真实场景需要估计角度
3. **查找表图像特定**：查找表是用特定清晰图建立的，对其他图像可能有偏差
4. **无噪声假设**：当前假设模糊图无噪声，有噪声时梯度测量会受影响
5. **单一尺度**：当前只在原始分辨率下估计，多尺度方法可能更鲁棒

---

## 七、改进方向（论文创新点潜力）

1. **通用查找表**：用大量图像的平均特征建立通用查找表，提高泛化能力
2. **角度估计**：从各向异性估计运动角度，实现完整的2参数PSF估计
3. **模糊类型判断**：自动判断是运动模糊、散焦模糊还是高斯模糊
4. **多尺度估计**：在不同分辨率下估计，提高鲁棒性
5. **迭代优化**：先用估计的PSF复原，再从复原图重新估计PSF，迭代收敛
6. **深度学习辅助**：用CNN预测过渡区特征和PSF参数的映射（但这就不是传统方法了）

## 九、关键公式速查

| 概念 | 公式 |
|------|------|
| 盲复原流程 | $g \xrightarrow{\text{过渡区}} G_{\text{mean}} \xrightarrow{\text{查映射表}} L_{\text{est}} \xrightarrow{\text{反卷积}} \hat{f}$ |
| PSNR下降 | $\Delta\text{PSNR} = \text{PSNR}_{\text{非盲}} - \text{PSNR}_{\text{盲}}$ |
| 维纳滤波 | $\hat{F} = \frac{H^*}{|H|^2 + K} G$ |
| 平均梯度 | $\bar{G} = \frac{1}{N}\sum_{(x,y)\in TZ} \sqrt{G_x^2 + G_y^2}$ |
