# 环境配置说明

## 已有环境

你已经配置好了 GPU 版 PyTorch 环境：

- **环境名**：torch-gpu
- **路径**：`C:\Users\Administrator\miniconda3\envs\torch-gpu`
- **Python**：3.11.15
- **PyTorch**：2.5.1+cu121
- **显卡**：RTX 3060 Laptop 12GB
- **已安装**：numpy, opencv-python, scipy

## 在 PyCharm 中配置本项目

1. 打开 PyCharm → `File` → `Open` → 选择 `J:\phd\图像复原从入门到论文`
2. `File` → `Settings` → `Project: 图像复原从入门到论文` → `Python Interpreter`
3. 点击齿轮 → `Add` → `Conda Environment` → `Existing environment`
4. Interpreter 选择：`C:\Users\Administrator\miniconda3\envs\torch-gpu\python.exe`
5. 点击 OK

## 验证环境

在 PyCharm 终端运行：

```python
import torch
import cv2
import numpy as np

print("PyTorch:", torch.__version__)
print("CUDA可用:", torch.cuda.is_available())
print("OpenCV:", cv2.__version__)
print("NumPy:", np.__version__)
```

预期输出：
```
PyTorch: 2.5.1+cu121
CUDA可用: True
OpenCV: 5.x.x
NumPy: 2.x.x
```
