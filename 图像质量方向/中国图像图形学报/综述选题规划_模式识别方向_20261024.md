# 面向《中国图象图形学报》的综述选题规划：图像与模式识别细分方向

整理日期：2026-10-24。约束：2—3个月，系统读文献并做少量对比实验；不限定IQA；以夯实基础和完成有投稿竞争力的综述为目标。

本文是选题预筛，不是完整的系统检索报告。推荐顺序依据题目边界、学习收益、实验可控性和与已有综述的区分空间，不代表录用概率。2—3个月指完成初稿、实验和修改的工作周期，不是审稿或见刊周期。下列实验均为建议，尚未下载数据、运行代码或核实全部模型权重。

**先给判断**

优先试选“视觉单目标跟踪中的模板更新与记忆机制综述”；第二选择为“低标注成本红外小目标检测研究进展”。如果导师能够提供地基云图的数据、代码和已有研究问题，云图方向可以升到第一梯队。红外—可见光鲁棒检测值得考虑，但已有综述覆盖较多，必须先证明新增内容。测试时自适应检测适合进一步研究，作为第一次综述、限时两三个月则不优先。

| 顺序 | 拟题 | 打基础的主要内容 | 两三个月完成的主要条件 | 最大风险 |
|---|---|---|---|---|
| 1 | 视觉单目标跟踪中的模板更新与记忆机制综述 | 特征匹配、Siamese、Transformer、时序建模、在线更新 | 有3—4个可运行的公开模型，先做推理评测 | 写成另一篇泛化的目标跟踪综述 |
| 2 | 低标注成本红外小目标检测研究进展 | 分割、弱监督、半监督、伪标签、检测评价 | 可统一数据划分与监督设置，至少跑通一种弱监督方法 | 直接相关文献不足，或不同标注成本不可比 |
| 3 | 非理想输入条件下红外与可见光目标检测研究进展 | 检测、配准、跨模态融合、鲁棒性 | 找到权重及适合做退化实验的成对数据 | 和既有跨模态检测、低质量融合综述重叠 |
| 4（有组内资源可前移） | 地基云图细粒度识别与分割研究进展 | 分类、分割、细粒度识别、弱监督、跨域泛化 | 导师能明确研究问题，数据及标签体系可用 | 题目退化为普通云图分割方法汇总 |
| 5 | 分布偏移下二维目标检测的测试时自适应研究进展 | 域偏移、伪标签、在线优化、持续适应 | 已掌握检测基础，能严格控制实验协议 | 协议复杂，复现投入超出预期 |

**与导师研究积累的关系**

洪汉玉老师的学校公开资料列有运动平台成像复原与识别等研究积累；叶亮老师的资料列有地基云图识别、细粒度云检测、云属分割及少量或不完整标注下的自训练工作。这些是选择“检测/跟踪”“成像退化”“云图分析”“低标注学习”的依据，但不能据此假定组内目前一定有可用数据、GPU或完整代码。

资料：[洪汉玉教师主页](https://eie.wit.edu.cn/info/1091/4829.htm)、[叶亮教师主页](https://eie.wit.edu.cn/info/1093/5739.htm)。教师主页发布时间较早，本文只用其确认公开研究经历，不据此判断现任职称或当前项目安排。

你提供的[夜间无人机航拍图像目标检测与跟踪方法研究进展](https://www.cjig.cn/en/article/doi/10.11834/jig.250459/)署名中已有叶亮、洪汉玉。因此可以借鉴这篇文章的问题组织和实验方式，但不宜再做主题相近、仅更新年份的综述。

**方向1：视觉单目标跟踪中的模板更新与记忆机制——首选试题**

直观问题：首帧框出目标后，目标会转身、变形、被遮挡。跟踪器什么时候应该学习新的外观，什么时候应该保留旧记忆，怎样避免把背景或相似物体当作目标记住？

建议限定RGB图像、边界框单目标跟踪。多目标身份关联、视频目标分割和多模态跟踪仅在边界说明中提及，不纳入主线。

组织方式应围绕机制，而不是按CNN、Transformer等网络名称逐篇罗列：

1. 记什么：图像模板、特征模板、目标状态、历史token等。
2. 何时写入：固定间隔、置信度门控、不确定性判断、学习得到的更新决策。
3. 如何保留与遗忘：短期与长期记忆、样本选择、容量管理、初始模板保护。
4. 如何读取与融合：相似度匹配、注意力读取、多模板融合。
5. 为什么失效：模板污染、错误更新累积、外观适应滞后、遮挡后的身份漂移。

入门文献可以依次读[UpdateNet，ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/html/Zhang_Learning_the_Model_Update_for_Siamese_Trackers_ICCV_2019_paper.html)、[STMTrack，CVPR 2021](https://arxiv.org/abs/2104.00324)、[UncTrack，TIP 2025](https://doi.org/10.1109/TIP.2025.3559796)、[MUTrack，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/38052)。它们可作为文献追溯入口，不是已经验证可复现的最终实验清单。

少量实验：优先挑选3—4个有权重、评测代码和清楚训练说明的跟踪器，使用一个公开基准的官方测试划分，报告成功率曲线/AUC、精度与速度，并分析遮挡、形变和相似目标干扰等属性。如果代码支持，再在同一模型内比较固定/动态更新或记忆容量；不能仅比较不同架构的最终分数就把差异归因于记忆机制。训练数据、骨干网络、硬件和实现差异需要列明。

综述贡献应是“统一机制分类＋失效原因解释＋有限但可核查的评测”。已有[Visual object tracking: Review and challenges（2025）](https://www.sciencedirect.com/science/article/abs/pii/S156849462500451X)等宽范围综述，不能宣称模板更新从未被讨论。需要在第一周补查最近综述对记忆机制的实际覆盖深度。

继续条件：能建立清楚的机制分类，并跑通至少两种不同路线的模型。若代码依赖和权重获得占用过多时间，及时调整实验对象，而不是无限修旧环境。

**方向2：低标注成本红外小目标检测——适合从综述接后续方法研究**

直观问题：红外小目标通常难以精确描边，能否只点一下目标位置、只标一部分训练图像，或利用未标注数据进行学习？“目标小”和“标注少”是不同概念，题目应围绕后者展开。

建议先限定单帧红外小目标检测，明确许多方法实际输出像素掩码。主线包含点等弱标注、少量完整标注与大量未标注数据、伪标签生成与迭代校正；边界框或图像级监督只有在直接文献充分时才独立成类。不要为了凑分类把普通全监督网络都纳入主线，也不要把“弱小目标”误当作“弱监督”。

入门入口：[LESPS，CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/papers/Ying_Mapping_Degeneration_Meets_Label_Evolution_Learning_Infrared_Small_Target_Detection_CVPR_2023_paper.pdf)、[MCLC](https://arxiv.org/abs/2304.04442)、[LimitIRSTD竞赛报告](https://arxiv.org/abs/2408.09615)。LimitIRSTD明确包含弱监督赛道，可以追溯方法与协议，但竞赛方法不能不加区分地当作独立正式论文计数。PAL可作为后续检索词；不能仅根据名称中的active learning就断定其测量了人工查询标注成本。

必须面对的重叠：[单帧红外图像多尺度小目标检测技术综述（2024）](https://cjig.cn/zh/article/doi/10.11834/jig.230788/)已经介绍弱监督网络。新综述要把监督信息、伪标签误差和成本—性能关系作为贯穿全文的主轴，不能只是扩写原综述的一小节。

少量实验：在一个已核实划分的公开数据集上，选2—3种可运行路线，比较固定监督条件下的结果；再做点标注偏移或完整标注比例变化中的一项。报告IoU以及定义清楚的检测概率/虚警指标。点标注与完整掩码的成本不能只用“图像数量”比较；没有计时或其他依据时，只报告监督形式，不虚构人工成本倍率。模型选择只能使用训练/验证数据。

继续条件：直接文献可以支撑多条有实质区别的方法路线，而且至少一种弱监督方法能完成训练。若只找到少量单点论文，应保持“低标注成本”范围，而不是硬写“单点监督综述”；也不要无边界扩张为所有数据高效视觉学习。

**方向3：非理想输入下的红外—可见光目标检测——与真实部署问题结合**

直观问题：两路相机拍到的位置没有完全对齐，一路图像很差，或一路数据暂时丢失时，检测器还能否利用另一模态？

只讨论检测任务，重点比较空间失配、质量不平衡/退化、模态缺失三类条件。区分训练时已知只部署单模态与测试时突然缺失传感器；区分数据缺失、标签缺失和真实视差，不把它们放进一个模糊的“缺失”类别。

已有[红外—可见光跨模态的行人检测综述（2023）](https://www.cjig.cn/zh/article/doi/10.11834/jig.220670/)明确覆盖未对准问题；[Multimodal fusion on low-quality data: A comprehensive survey（2026）](https://www.sciencedirect.com/science/article/pii/S1566253526003179)又覆盖更广泛的低质量多模态数据。因此，“实际场景有困难”本身不能构成新贡献。

可切入的差异是：统一整理各方法依赖的配准假设、训练时是否见过退化/缺失、测试时可用模态、性能下降幅度与推理代价。初读可从[Translation, Scale and Rotation: Cross-Modal Alignment Meets RGB-Infrared Vehicle Detection，ECCV 2022](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136690501.pdf)等配准与检测工作开始。

少量实验：选一个成对数据集和3个可获得权重的模型，分别施加可控空间偏移、单模态质量退化，得到强度—性能曲线。模态缺失只对适用模型单独评测。明确边界框属于哪一路坐标，不能移动标注参考图却保持标签不变。人工扰动测试只能说明对该扰动的敏感性，不能代替真实传感器故障或真实视差验证。

这个题的实验图比较容易形成，但查重叠和控制评测条件的负担比看上去大，因此排第三。

**方向4：地基云图细粒度识别与分割——导师资源驱动的候选**

叶亮老师的公开成果包含DeepCloud、细粒度云检测识别、CCAD-Net和少量/不完整标注下的自训练。因此这一方向有明确的学术积累依据，见[教师论文列表](https://eie.wit.edu.cn/info/1093/5739.htm)。

建议范围：天空相机拍摄的地基云图；围绕云类别混合、薄云与边界、局部与全局表征、少量标注、跨设备或站点泛化展开。不延伸到卫星云去除、天气预报和光伏功率预测全链条。

已有云图分割综述，例如[Review of Cloud Image Segmentation Based on Machine Learning（2025）](https://castjournals.cast.org.cn/joweb/kxjsygc/EN/1156264149266060193)，不能假定“小众方向就没有综述”。选题需要明确细粒度云类、识别与分割之间的关系，以及相较二值云/天空分割的新增分析。公开数据线索可从[地基天空图像开放数据集综述](https://arxiv.org/abs/2211.14709)查起。

少量实验：优先使用组内已经整理的数据和可复现代码，比较类别不平衡处理或少量标注设置。如果做跨数据集实验，先确认类别定义可对应；无法建立合理对应关系就不强做跨库排名。分类的macro-F1和分割的mIoU应分开，不混成一个性能榜。

若导师能够提供明确任务、已有基线和数据，这个方向可升到第一梯队；如果全部从零采集、标注和整理，则不适合本轮两三个月计划。其优势是可获得的专业指导，不是可以证明的较高录用率。

**方向5：分布偏移下二维目标检测的测试时自适应——有价值但投入较大**

直观问题：模型在一个环境训练，部署到另一个环境后，能否利用没有标签的测试图像自行调整？

建议限定二维、闭集目标检测；分清测试时数据增强、测试时自适应、无源域适应以及持续测试时自适应。主线可围绕分类置信度与定位质量、伪标签确认偏差、记忆与遗忘、更新代价组织，不直接扩张到所有视觉基础模型。

入门例子：[Fully Test-time Adaptation for Object Detection，CVPR Workshops 2024](https://openaccess.thecvf.com/content/CVPR2024W/MAT/papers/Ruan_Fully_Test-time_Adaptation_for_Object_Detection_CVPRW_2024_paper.pdf)、[Test-time adaptation for object detection via Dynamic Dual Teaching（2025）](https://www.sciencedirect.com/science/article/abs/pii/S0262885625003282)。

少量实验也有较高协议负担：必须说明是否访问源数据、是否每个域重置模型、样本顺序、批大小、更新步数、测试标签是否完全隔离、额外时间开销。不能将不同协议下的数值直接比较。对刚建立检测基础的人，这个题容易把时间消耗在协议和环境上，因此仅列备选。

**10周执行安排与定题检查**

- 第1周：只对排名前两项做试读。每项建立一份核心论文表和“最相近综述”对照表；优先检查代码、权重、数据权限与运行条件。周末确定一个主题，另一个保留为备选。
- 第2—3周：阅读经典方法和关键后续工作，记录每篇的假设、输入输出、机制、训练监督、评价协议与局限，画出第一版方法分类图。
- 第4周：写出引言、与已有综述的差异表、任务定义和实验协议；与导师确认题目边界。先写这一部分，避免读到最后仍无法说明文章贡献。
- 第5—6周：运行有限的对比实验并开始写方法部分。只回答一两个清楚的问题，不追求堆模型数量。
- 第7—8周：完成主体初稿、数据集与指标整理、失效案例和趋势讨论。把论文报告值与自己的复现值清楚区分。
- 第9—10周：补查近期文献，核验参考文献，统一图表，与导师修改。若按三个月安排，剩余两周留给实验失败、补充分析和投稿前修改。

定题必须能回答三件事：已有综述已经覆盖到哪里；本文新增的分类、证据或评测是什么；这些新增内容是否能在现有时间与资源下完成。不要用“首次”“全面”“最新”代替可核查的区别，也不要把引文篇数当成综述质量目标。

对当前目标最实际的选择：先试读跟踪中的模板更新与记忆机制，同时用一周检查低标注成本红外小目标检测的文献与复现条件。若导师能直接提供成熟云图资源，则优先比较云图题目与这两项的实际启动成本。
