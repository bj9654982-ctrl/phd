# 《中国图象图形学报》投稿规范核对与现稿修改清单

核对日期：2026年10月27日。核对对象：2026年10月25日生成的 v2／300篇文献阅读稿。本文记录核对结果，尚未把现稿转换为投稿版。

当前稿件可作为阅读和继续写作的基础，但不能直接视为按本刊模板完成的投稿稿。必须优先处理英文长摘要、作者—年份引文、双栏版式、双语图表题、三线表、可编辑公式和书目完整性。

## 已确认的要求与现稿差异

| 项目 | 官方依据及要求 | 现稿核对结果与处理 |
|---|---|---|
| 中文题名 | 撰稿网页一般不超过20个汉字 | 现题《视觉单目标跟踪中的模板更新与记忆机制综述》恰好20字，符合一般建议，不需要因长度强行改题。 |
| 中文摘要 | 2026模板明确说明综述可不按四要素撰写 | 现摘要为连续段落，439个汉字、含标点477字符。结构可保留，重点加强综述发现，减少常识背景。 |
| 英文摘要 | 2026模板要求约1000词，可与中文不完全对应 | 现稿219词（连字符词按1词计），明显不足。应扩展范围、分类依据、比较发现、评价边界和研究展望。 |
| 英文摘要结构 | 2026模板英文栏仍列四要素，未再次明确写综述豁免 | 不能把中文栏的豁免直接宣称为英文栏的硬性规则。下一版可按 Objective、Method、Result、Conclusion 组织综述内容；Result 写文献综合发现，不虚构本研究实验。 |
| 关键词 | 模板要求5—8个，中英对应，以分号分隔 | 现有6个，中英对应，可保留并统一排法。 |
| 正文排版 | 模板规定双栏，正文五号宋体；引言编号0 | 现稿是单栏阅读版。引言0已符合；正文、标题、跨栏图表需整体套入官方模板。 |
| 文内引文 | 采用作者—年份制，引文与论述准确对应 | 现稿仍用[1]、[2]等数字编号，需全文转换；同一作者同年文献还需区分a、b等。 |
| 文后参考文献 | 按英文作者字母顺序排列；中文条目提供英文对照 | 现稿按编号排序，需重排并补齐中文条目对译、刊会名称和出版信息。 |
| 作者著录 | 2026模板：不超过6人全部列出，超过6人列前6人后加等／et al | 2021著录说明部分位置写“全体作者”；本次拟按较新的2026模板处理，不能机械沿用旧说明。 |
| 图与表 | 双语题名；表格使用三线表 | 现稿图表题主要为中文，11张表均为Table Grid。需要补英文题名、改表线并复核双栏后的可读性。 |
| 图像质量 | 模板要求300 dpi以上位图或清晰矢量图 | 5幅主图文件标记约220 dpi，但在现有Word的6.5英寸宽度下有效分辨率约321—388 dpi，不能仅据元数据判为不合格。重排时仍须按最终尺寸检查；已有SVG源图可用于清晰输出。 |
| 公式 | 应使用可编辑公式；模板建议MathType | 现稿6个公式图像，Word内没有OMML公式。应换成可编辑公式，统一编号、变量体例及首次释义。 |
| 首页及作者信息 | 作者、单位、基金、简介和分类号等按模板填写 | 现稿未正式填写。必须据实际贡献和资助信息补充；不能自动把导师姓名、项目或作者顺序填入。 |

注意：通用撰稿网页的摘要篇幅说明与2026附件不同，后续不能再按通用网页的“500字左右”制作英文摘要。中文综述无需四要素的依据来自2026附件，已经核实。

## 300篇参考文献应怎样处理

官网给出的通用数量门槛是15篇以上，近10年占60%以上；没有要求综述达到300篇。本次检查的文件中也没有找到综述的参考文献数量上限、统一篇幅上限或固定页数上限。未发现上限不等于编辑部承诺接受任意长度。

当前文献库共有300条；按2017—2026年这10个自然年统计，有225条，占75%，满足上述新近文献比例。采用其他截止年份时应重新统计。

300条中52条已填写DOI，248条的DOI字段为空。这表示“尚待查找或确认”，不表示这248篇没有DOI。已生成独立待核实清单；应优先匹配正式出版页，确无DOI的条目记录核查结果，不猜写DOI。

文献库中300条均未标记为完成全文精读。此前的书目核验、摘要筛选与全文阅读是不同工作。官网要求使用作者亲自读过并在文中引用的文献，因此下一版需要逐条建立“论点—文献—原文依据”的关系。尤其第4.6节和表9中的主题分组与集中编号，不能代替逐项论证。

可保留300篇研究文献库；最终稿是否全部收入，应根据相关性与真实引用情况决定。当前任务未删除任何条目，也未把未精读文献改记为已读。对只有预印本或电子版本的条目，应查正式版本，确需引用电子文献时按本刊电子文献体例补发布日期、访问日期与网址。

## 下一版的具体修改顺序

1. 保留现有题目、中文摘要基本结构和6个关键词；把英文摘要扩展到约1000词，突出这篇综述自己的分类、比较和结论。
2. 建立作者—年份引文映射，处理同作者同年文献；逐段拆分笼统引文，形成具体论点对应具体出处的叙述。
3. 核查248条空缺DOI及其出版信息，补充中文参考文献的英文对照，按2026模板统一作者著录后再排序。
4. 套用官方双栏模板，将6个公式改为可编辑对象，为5幅主图和11张表补齐双语题名，改成三线表并逐页检查。
5. 完成作者、单位、基金与分类号等真实信息；再复核稿件长度、阅读质量及必要的补充材料。

这些是修改计划，不代表已经完成。现有35页阅读版的页数不能直接当作期刊排版页数。

## 投稿附件及容易误解的事项

官方投稿指南要求初投上传版权声明及保密审查证明电子版；初投无稿号可留空，盖章纸质原件可在录用后寄送。实际签署、作者确认和单位审查须由相关人员办理，本次只下载了空白文件。

2025版声明中含数据／算法源代码或永久访问地址的承诺。对于当前文献分析稿，可预先整理文献索引、统计脚本和已发表数值的出处；这不等于证明本综述必须另做算法实验，也不等于已满足编辑部对具体附件的全部要求。

“选题信息表”里的字段包括召集编委、专题编委会、征稿方向及组约稿篇数，属于专题组织语境；不能把它直接当作普通综述作者投稿前必须填写的表格。本次官方文件未找到普通综述必须先获选题审批的明确要求。

本次只完成规范核对、原始附件保存和差异清单，未投稿、未签署任何声明，也未覆盖v2稿件。
